# СПЕЦИФИКАЦИЯ ПАТЧА P4.1.6 (L5)

**ID:** P4.1.6  
**Контейнер:** C4.1 (Project Dashboard)  
**Название:** Логирование в BR18 и локальный файл

## 1. Цель
Добавить отправку логов о запросах и ошибках в BR18, а также запись в локальный файл.

## 2. Технические параметры
- **Модифицируемые файлы:** `BR4/C4.1/main.py`, `BR4/C4.1/services.py`
- **Локальный лог:** файл `01_ЦЕХ/01_ЖУРНАЛЫ/dashboard.log` (создаётся автоматически).
- **Отправка в BR18:** использовать `BackgroundTasks` для асинхронной отправки.
- **Формат лога (BR18):** `{ "timestamp": "...", "service": "C4.1", "event_type": "api_call|error", "details": { "method": "...", "path": "...", "status_code": 200, "response_time_ms": 12 } }`
- **Адрес BR18:** из переменной окружения `BR18_URL` (по умолчанию `http://br18:8080/api/logs`).

## 3. Требования к коду
- [ ] Добавить middleware или явные вызовы в каждом эндпоинте.
- [ ] Логировать метод, путь, статус, время выполнения.
- [ ] При ошибках отправлять лог с `event_type: "error"` и деталями.
- [ ] Использовать стандартный модуль `logging` для записи в локальный файл.

## 4. Тесты
- [ ] Юнит-тест: проверка, что функция отправки лога вызывается (мок).
- [ ] Интеграционный тест: проверка, что при запросе лог записывается в файл.

## 5. Критерии приёмки (DoD)
- [ ] Локальный файл `dashboard.log` создаётся и содержит записи.
- [ ] В логах контейнера видны отправки в BR18.
- [ ] При недоступности BR18 ошибка не влияет на ответ.
