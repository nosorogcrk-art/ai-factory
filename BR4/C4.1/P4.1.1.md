### 1. Цель
Создать базовое FastAPI-приложение для дашборда, которое будет предоставлять эндпоинт `/api/status` с заглушечными данными и `/health`. Подготовить структуру для фронтенда.

### 2. Технические параметры
- **Модифицируемые файлы:** `BR4/C4.1/main.py`, `BR4/C4.1/requirements.txt`, `BR4/C4.1/Dockerfile`
- **Добавляемые эндпоинты:**
  - `GET /health` – возвращает `{"status": "ok"}`
  - `GET /api/status` – возвращает JSON с фиктивными метриками
- **Переменные окружения:** `PORT` (по умолчанию 8094)

### 3. Требования к коду
- [ ] **Структура:** разделение на `main.py`, `services.py` (пока заглушка), `models.py`
- [ ] **Типизация:** аннотации типов
- [ ] **Docstring:** для всех эндпоинтов
- [ ] **Логирование:** запросы логируются в `01_ЦЕХ/01_ЖУРНАЛЫ/dashboard.log`
- [ ] **Обработка ошибок:** при ошибке возвращать 500
