**ID:** P4.1.7  
**Контейнер:** C4.1 (Project Dashboard)  
**Название:** Юнит-тесты

## 1. Цель
Написать юнит-тесты для бизнес-логики в `services.py`.

## 2. Технические параметры
- **Тестируемые функции:** `fetch_metrics()`, `aggregate_data()`, `load_branches_from_registry()` (или аналогичные).
- **Минимум 3 сценария:**
  1. Успешное выполнение – возврат корректных данных.
  2. Ошибка при вызове BR18 – возврат заглушки.
  3. Ошибка при вызове C0.4 – возврат заглушки.
- **Инструменты:** `pytest`, `pytest-mock`.

## 3. Требования к коду
- [ ] Тесты размещены в `BR4/C4.1/tests/test_services.py`.
- [ ] Использовать моки для внешних вызовов (`httpx`, `requests`).
- [ ] Проверять, что при ошибке возвращается fallback-данные.

## 4. Критерии приёмки (DoD)
- [ ] Все тесты проходят.
