### **C4.1: Project Dashboard**

**Ветка-родитель:** BR4 | **ID:** C4.1 | **Ответственный:** АРХИ / ГЕФЕСТ

**1. ФУНКЦИОНАЛЬНОЕ ПРЕДНАЗНАЧЕНИЕ**  
Веб-интерфейс для отображения ключевых метрик завода: статус патчей, затраты токенов, прогресс веток, состояние реестра BR0. Получает данные из BR18 (Metrics Dashboard, Cost Tracker) и напрямую из системных файлов. Используется как единая точка входа для владельца.

**2. ТЕХНИЧЕСКАЯ ЛОГИКА (МЕХАНИКА)**  
- **Архитектура:** бэкенд на FastAPI, фронтенд на React (статические файлы).  
- **Источники данных:**  
  – BR18: через API C18.2 (Metrics Dashboard) и C18.5 (Cost Tracker).  
  – BR0: через C0.4 (Registry Manager) для получения списка веток.  
- **API:**  
  – `GET /api/status` – агрегированные метрики (кешируются, обновление раз в 10 секунд).  
  – `GET /health` – проверка работоспособности (используется для healthcheck).  
- **Логирование:** все запросы логируются в BR18 и локальный файл `dashboard.log`.

**3. ВХОДЫ И ВЫХОДЫ (INTERFACES)**  
- **Input:** HTTP-запросы к API.  
- **Output:** JSON с метриками, HTML-страница.

**4. ИНТЕГРАЦИИ**  
- **BR18 (C18.2, C18.5):** получение метрик.  
- **BR0 (C0.4):** получение информации о ветках.  
- **BR4 (C4.3, C4.4):** часть единого портала.

**5. СТЕК ТЕХНОЛОГИЙ**

- HTTP-клиент (`httpx`).  
- Docker.
