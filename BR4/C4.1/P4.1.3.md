### 1. Цель
Создать React-приложение для отображения метрик, которое будет получать данные из API и обновлять их в реальном времени. Собрать статические файлы и встроить их в бэкенд.

### 2. Технические параметры
- **Модифицируемые файлы:** `BR4/C4.1/frontend/` (новая папка)
- **Инструменты:** Vite или Create React App, Chart.js
- **Эндпоинты:** `GET /` отдаёт `index.html`
- **Сборка:** `npm run build` копирует статику в `BR4/C4.1/static/`

### 3. Требования к коду
- [ ] **Структура:** компоненты: `MetricsBoard`, `Chart`, `Table`
- [ ] **Обновление:** каждые 10 секунд опрос `/api/status`
- [ ] **Отображение:** графики (затраты, успешность), таблица веток

### 4. Тесты
- [ ] Юнит-тесты (Jest) для компонентов
- [ ] Сквозной тест (Cypress) – загрузка страницы, появление данных
