# СПЕЦИФИКАЦИЯ ПАТЧА P4.1.8 (L5)

**ID:** P4.1.8  
**Контейнер:** C4.1 (Project Dashboard)  
**Название:** Интеграционные тесты

## 1. Цель
Написать интеграционные тесты для эндпоинтов `/api/status` и `/health`.

## 2. Технические параметры
- **Тестируемые эндпоинты:** `GET /health`, `GET /api/status`
- **Сценарии:**
  1. Успешный ответ (200, структура JSON).
  2. Ошибка BR18 (мок) – возврат 200 с заглушкой.
  3. Ошибка C0.4 (мок) – возврат 200 с заглушкой.
- **Инструменты:** `fastapi.testclient.TestClient`, мокирование внешних вызовов.

## 3. Требования к коду
- [ ] Тесты размещены в `BR4/C4.1/tests/test_api.py`.
- [ ] Использовать `mocker.patch` для подмены вызовов `httpx`.
- [ ] Проверить, что при ошибках возвращается 200 с заглушкой (или 503, если так решено – должно быть единообразно).

## 4. Критерии приёмки (DoD)
- [ ] Все тесты проходят.
- [ ] Эндпоинты возвращают ожидаемую структуру.
