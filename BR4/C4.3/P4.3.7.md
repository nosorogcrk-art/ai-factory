# СПЕЦИФИКАЦИЯ ПАТЧА P4.3.7 (L5)

**ID:** P4.3.7  
**Контейнер:** C4.3 (Command Console)  
**Название:** Логирование в BR18 и локальный файл

## 1. Цель
Добавить отправку логов о командах, результатах и ошибках в BR18, а также запись в локальный файл.

## 2. Технические параметры
- **Модифицируемые файлы:** `BR4/C4.3/main.py`
- **Локальный лог:** файл `01_ЦЕХ/01_ЖУРНАЛЫ/console.log` (создаётся автоматически).
- **Отправка в BR18:** использовать `BackgroundTasks` для асинхронной отправки.
- **Формат лога (BR18):** `{ "timestamp": "...", "service": "C4.3", "event_type": "command_executed|error", "details": { "command": "...", "success": true, "output": "..." } }`
- **Адрес BR18:** из переменной окружения `BR18_URL` (по умолчанию `http://br18:8080/api/logs`).

## 3. Требования к коду
- [ ] В эндпоинте `/api/command` после обработки команды записывать лог в файл и отправлять в BR18.
- [ ] При ошибках отправлять лог с `event_type: "error"` и деталями.
- [ ] Использовать стандартный модуль `logging` для записи в файл.

## 4. Тесты
- [ ] Юнит-тест: проверка, что функция отправки лога вызывается (мок).
- [ ] Интеграционный тест: проверка, что при команде лог записывается в файл.

## 5. Критерии приёмки (DoD)
- [ ] Локальный файл `console.log` создаётся и содержит записи.
- [ ] В логах контейнера видны отправки в BR18.
- [ ] При недоступности BR18 ошибка не влияет на ответ.
