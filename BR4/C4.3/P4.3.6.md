# СПЕЦИФИКАЦИЯ ПАТЧА P4.3.6 (L5)

**ID:** P4.3.6  
**Контейнер:** C4.3 (Command Console)  
**Название:** Документирование и типизация

## 1. Цель
Добавить docstring для всех функций и эндпоинтов (`/health`, `/api/command`), дополнить аннотации типов.

## 2. Технические параметры
- **Модифицируемые файлы:** `BR4/C4.3/main.py`
- **Эндпоинты:** `GET /health`, `POST /api/command`
- **Docstring:** в формате Google или reStructuredText с описанием, параметрами, возвращаемым значением, возможными исключениями.
- **Типизация:** все аргументы функций и возвращаемые значения должны быть аннотированы.

## 3. Требования к коду
- [ ] В `main.py` для каждого эндпоинта добавить docstring.
- [ ] В функциях обработки команд (`handle_command`, `call_handover`) добавить docstring.
- [ ] Все функции аннотированы типами.

## 4. Критерии приёмки (DoD)
- [ ] `mypy` не выдаёт ошибок.
- [ ] `ruff` не выдаёт ошибок.
- [ ] Все эндпоинты продолжают работать (ручная проверка).
