
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P4.3.3 (LEVEL 5)

**ID:** P4.3.3  
**Контейнер:** C4.3 (Command Console)  
**Название:** Логирование в BR18

**Зависимости:** P4.3.2

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить отправку логов обо всех выполненных командах в центральный лог-агрегатор BR18 (C18.1). Это обеспечит наблюдаемость действий оператора и позволит анализировать использование консоли.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Формат лога:**  
  ```json
  {
    "timestamp": "ISO 8601",
    "service": "C4.3",
    "event_type": "command_executed",
    "details": {
      "user": "admin",  // пока заглушка
      "command": "deploy BR1",
      "target_service": "BR20",
      "success": true,
      "output": "Deployment started",
      "execution_time_ms": 250
    }
  }
  ```  
- **Асинхронность:** отправка не блокирует основной поток (использовать фоновые задачи).  
- **Адрес BR18:** переменная окружения `BR18_URL`.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- В эндпоинте `/api/command` после выполнения команды и получения результата создавать задачу на отправку лога.  
- Реализовать функцию `send_log_to_br18`.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При каждой команде в BR18 отправляется соответствующий лог.  
- Лог содержит все обязательные поля.  
- При недоступности BR18 ошибка логируется локально, но не влияет на ответ пользователю.
