# СПЕЦИФИКАЦИЯ ПАТЧА P4.3.8 (L5)

**ID:** P4.3.8  
**Контейнер:** C4.3 (Command Console)  
**Название:** Юнит-тесты

## 1. Цель
Написать юнит-тесты для логики обработки команд и вызовов handover.

## 2. Технические параметры
- **Тестируемые функции:** `handle_command(command)`, `call_handover(method, endpoint, data)`
- **Минимум 3 сценария:**
  1. Успешная команда `take` – проверка вызова handover и возврата успеха.
  2. Неизвестная команда – возврат ошибки.
  3. Ошибка handover (HTTP 404) – возврат ошибки.
- **Инструменты:** `pytest`, `pytest-mock`.

## 3. Требования к коду
- [ ] Тесты размещены в `BR4/C4.3/tests/test_services.py`.
- [ ] Использовать моки для `httpx.AsyncClient`.
- [ ] Проверять, что при ошибке возвращается корректное сообщение.

## 4. Критерии приёмки (DoD)
- [ ] Все тесты проходят.
- [ ] Покрытие ключевых функций не менее 80%.
