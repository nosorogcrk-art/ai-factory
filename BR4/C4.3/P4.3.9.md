# СПЕЦИФИКАЦИЯ ПАТЧА P4.3.9 (L5)

**ID:** P4.3.9  
**Контейнер:** C4.3 (Command Console)  
**Название:** Интеграционные тесты

## 1. Цель
Написать интеграционные тесты для эндпоинта `/api/command`.

## 2. Технические параметры
- **Тестируемые эндпоинты:** `POST /api/command`, `GET /health`
- **Сценарии:**
  1. Успешная команда `take` – возврат `{"success": true, "new_status": "IN_PROGRESS"}`.
  2. Неизвестная команда – `{"success": false, "output": "Unknown command"}`.
  3. Ошибка handover (мок) – `{"success": false, "output": "..."}`.
- **Инструменты:** `fastapi.testclient.TestClient`, мокирование `httpx`.

## 3. Требования к коду
- [ ] Тесты размещены в `BR4/C4.3/tests/test_api.py`.
- [ ] Использовать `mocker.patch` для подмены вызовов.

## 4. Критерии приёмки (DoD)
- [ ] Все тесты проходят.
- [ ] Эндпоинты возвращают ожидаемую структуру.
