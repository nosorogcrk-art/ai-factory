
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P4.2.2 (LEVEL 5)

**ID:** P4.2.2  
**Контейнер:** C4.2 (Graph Visualizer)  
**Название:** REST API для графа  
**Зависимости:** P4.2.1  

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Создать FastAPI-приложение, которое предоставляет эндпоинт для получения данных графа, построенного в P4.2.1. API будет использоваться фронтендом (React SPA) для визуализации. На данном этапе API возвращает только один тип графа – семантический (связи между документами).  

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  
- **Фреймворк:** FastAPI.  
- **Порт:** 19009 (или другой, не конфликтующий с другими сервисами).  
- **Эндпоинты:**  
  - `GET /api/graph` – возвращает содержимое файла `links_graph.json`. Если файл отсутствует, возвращает `{"nodes": [], "edges": []}`.  
  - `GET /health` – проверка работоспособности.  
- **Кэширование:** данные загружаются из файла при каждом запросе (или можно кэшировать в памяти с проверкой времени модификации).  
- **Логирование:** запросы логируются в `01_ЦЕХ/01_ЖУРНАЛЫ/graph_api.log`.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  
- Создать файл `agents/tools/graph_api.py`.  
- Определить эндпоинты с помощью FastAPI.  
- Добавить функцию чтения графа из файла с обработкой ошибок.  
- Запустить сервер через uvicorn.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  
- Приложение запускается на указанном порту.  
- При запросе `GET /api/graph` возвращается корректный JSON.  
- Если файл графа отсутствует, возвращается пустой граф.  
- Эндпоинт `/health` возвращает `{"status": "ok"}`.  
- Логирование работает.
