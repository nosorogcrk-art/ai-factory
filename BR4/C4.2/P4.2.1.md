### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P4.2.1 (LEVEL 5)

**ID:** P4.2.1  
**Контейнер:** C4.2 (Graph Visualizer)  
**Название:** Базовый генератор графа (парсинг ссылок)  
**Зависимости:** отсутствуют  

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Создать скрипт `graph_builder.py`, который сканирует все документы в папках `00_КАНОН/` и `01_ЦЕХ/`, извлекает из них ссылки вида `[[ID]]` и строит JSON-структуру графа (узлы и рёбра). Этот граф будет использоваться для визуализации связей между смыслами, документами и задачами.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  
- **Область сканирования:** рекурсивно все файлы с расширением `.md` в директориях `00_КАНОН/` и `01_ЦЕХ/`.  
- **Извлечение ссылок:** регулярное выражение `\[\[([A-Z0-9\-_]+)\]\]` (как в существующих документах).  
- **Выходной файл:** `01_ЦЕХ/ГРАФ/links_graph.json`. Папка `ГРАФ` создаётся автоматически.  
- **Структура JSON:**  
  ```json
  {
    "nodes": [
      { "id": "ID_сущности", "label": "имя файла или ID", "type": "doc | task" },
      ...
    ],
    "edges": [
      { "source": "ID1", "target": "ID2" },
      ...
    ]
  }
  ```  
  Узлы могут быть двух типов: `task` (если ID соответствует задаче из реестра) и `doc` (обычный документ). Для идентификации задач необходимо загружать `task_registry.json`.  
- **Интеграция с реестром задач:** если файл `01_ЦЕХ/ТЕКУЩИЕ_ЗАДАЧИ/task_registry.json` существует, то узлы, чьи ID присутствуют в реестре, помечаются типом `task`.  
- **Логирование:** скрипт записывает в лог `01_ЦЕХ/01_ЖУРНАЛЫ/graph_builder.log` количество найденных узлов и ссылок.  
- **Запуск:** может выполняться по расписанию (например, раз в 15 минут) или вручную.

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  
- Создать файл `agents/tools/graph_builder.py`.  
- Определить функции:  
  - `load_task_ids()` – загружает ID задач из реестра.  
  - `extract_links(file_path)` – извлекает ссылки из файла.  
  - `build_graph()` – основной цикл сканирования и построения графа.  
- Использовать `pathlib` для обхода директорий.  
- Сохранять результат в JSON.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  
- Скрипт создаёт файл `01_ЦЕХ/ГРАФ/links_graph.json` после запуска.  
- JSON содержит все найденные ссылки и узлы.  
- Если есть `task_registry.json`, узлы с ID задач помечаются типом `task`.  
- Скрипт не падает при отсутствии папок или файлов (только логирует предупреждения).  
- Лог-файл создаётся и содержит информацию о количестве узлов/связей.
