### **C4.2: Graph Visualizer (Визуализатор графов)** – ИСПРАВЛЕННАЯ ВЕРСИЯ

**Ветка-родитель:** BR4 | **ID:** C4.2 | **Ответственные:** АРХИ / ГЕФЕСТ

**1. ФУНКЦИОНАЛЬНОЕ ПРЕДНАЗНАЧЕНИЕ**  
Интерактивная визуализация связей между ключевыми сущностями завода: документами Вики-Вселенной (BR2), навыками (BR17) и патчами (BR1/BR7). Позволяет Владельцу и агентам исследовать структуру знаний, зависимости навыков и граф выполнения задач, быстро переходить к исходным документам и получать контекстную информацию. Поддерживает переключение между различными типами графов для удобства анализа.

**2. ТЕХНИЧЕСКАЯ ЛОГИКА (МЕХАНИКА)**  

- **Архитектура:**  
  – Микросервис, состоящий из бэкенда (FastAPI) и фронтенда (React SPA).  
  – Бэкенд агрегирует данные из специализированных источников и преобразует их в единый формат узлов и рёбер, понятный фронтенду.  
  – Фронтенд отображает интерактивный граф с поддержкой панорамирования, масштабирования, кликов и подсказок.

- **Типы графов и источники данных:**  
  – **Граф смыслов (семантический):**  
    * Отображает документы Вики-Вселенной (MD-файлы) и ссылки `[[ID]]` между ними.  
    * **Базовый граф** строится с помощью генератора (P4.2.1), который сканирует все документы в `00_КАНОН/` и `01_ЦЕХ/` и извлекает взаимные ссылки.  
    * **Семантический поиск (C2.3)** используется для обогащения графа метаданными (заголовки, даты, типы), а также для поиска узлов при центрировании или фильтрации.  
  – **Граф навыков:**  
    * Отображает навыки из BR17 и их зависимости (из C17.3 Skill Graph).  
    * Узлы обогащаются метаданными: статус, версия, флаг `allowed_for_swarm`.  
  – **Граф патчей:**  
    * Отображает патчи (L4) и их зависимости. Источник – граф зависимостей, хранящийся в `GRAPH_DEPENDENCIES.json` (доступен через API BR1 или прямое чтение файла).  

- **Бэкенд (API):**  
  – Эндпоинт `GET /graph?type={semantic|skills|patches}`:  
    * Для графа смыслов: запрашивает у генератора предварительно построенную структуру (или строит на лету с использованием индексатора BR2).  
    * Для графа навыков: обращается к C17.3.  
    * Для графа патчей: получает данные из файла зависимостей (или через API BR1).  
    * Все результаты преобразуются в единый JSON-формат.  
  – Эндпоинт `GET /node/{id}` – возвращает детальную информацию об узле (используется для модального окна).  
  – Кэширование: результаты запросов кэшируются на короткое время (например, 1 минуту) для снижения нагрузки на источники.

- **Фронтенд (React SPA):**  
  – Отдельная страница `/graph`.  
  – Использует библиотеку визуализации (Cytoscape.js или D3.js) для отрисовки графа.  
  – Панель управления: переключатель типа графа, поле поиска узлов, фильтры по типу/статусу.  
  – При клике на узел:  
    * Если узел имеет URL (документ) – открывается соответствующая страница (например, в Obsidian).  
    * Иначе – модальное окно с метаданными (описание, версия, статус, связанные сущности).  
  – При наведении – всплывающая подсказка с краткой информацией.

- **Логирование:**  
  – Каждый вызов API логируется в BR18 (C18.1) через middleware. Формат лога аналогичен C4.1.  

**3. ВХОДЫ И ВЫХОДЫ (INTERFACES)**  

- **Бэкенд API (для фронтенда):**  
  – `GET /graph?type=semantic` – возвращает JSON с графом смыслов.  
  – `GET /graph?type=skills` – возвращает граф навыков.  
  – `GET /graph?type=patches` – возвращает граф патчей.  
  – `GET /node/{id}` – возвращает детальную информацию об узле.  

- **Формат ответа (пример):**  
  ```json
  {
    "nodes": [
      { "id": "doc-001", "label": "Замысел проекта", "type": "doc", "url": "/docs/...", "size": 10, "color": "#4caf50" }
    ],
    "edges": [
      { "source": "doc-001", "target": "doc-002", "type": "reference" }
    ]
  }
  ```

- **Выход для пользователя:** HTML-страница с React-приложением, доступная по маршруту `/graph`.

**4. ИНТЕГРАЦИИ**  

- **BR2 (Memory):**  
  – **Генератор (P4.2.1)** использует данные индексатора (C2.2) или прямое сканирование файлов для построения графа связей.  
  – **C2.3 (Semantic Search)** – для поиска узлов по запросу и получения расширенных метаданных.  
- **BR17 (Skills):**  
  – **C17.3 Skill Graph** – получение графа зависимостей навыков.  
- **BR1/BR7 (Patches):** доступ к графу зависимостей патчей (например, через чтение `GRAPH_DEPENDENCIES.json` или API).  
- **BR18 (Monitoring):** отправка логов обращений.  

**5. СТЕК ТЕХНОЛОГИЙ**  

- **Бэкенд:** Python + FastAPI + Uvicorn.  
- **Фронтенд:** React (созданный через Vite) + Cytoscape.js (или D3.js).  
- **Контейнеризация:** Docker (образ включает бэкенд и собранный фронтенд).  
- **HTTP-клиент:** `httpx` для асинхронных запросов к другим сервисам.
