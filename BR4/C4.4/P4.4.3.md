# СПЕЦИФИКАЦИЯ ПАТЧА P4.4.3 (L5)

**ID:** P4.4.3  
**Контейнер:** C4.4 (Dialogue Console)  
**Название:** Интеграция с C9.4  
**Статус:** выполнена

---

### 1. Цель
Реализовать отправку сообщений в C9.4 и отображение ответов ассистента. При отправке сообщения отправляется POST-запрос на `/api/dialog` с `project_id` и `message`, ответ добавляется в чат.

### 2. Технические параметры
- **Модифицируемые файлы:** `BR4/C4.4/static/script.js`, `BR4/C4.4/static/index.html`
- **API C9.4:** `POST /api/dialog` с телом `{ "project_id": "...", "message": "..." }`
- **Новые функции:**
  - `sendMessage()` – отправляет сообщение, добавляет сообщение пользователя в чат, затем ответ ассистента
  - Обновление истории после отправки (вызов `loadMessages()`)

### 3. Требования к коду
- [ ] **Асинхронность:** использование `async/await` или `fetch` с then
- [ ] **Обработка ошибок:** при ошибке отображать сообщение и не очищать поле ввода
- [ ] **Блокировка поля ввода** во время отправки

### 4. Тесты
- [ ] Ручное тестирование: отправка сообщения, появление ответа
- [ ] Проверка, что при выборе другого проекта история перезагружается

### 5. Критерии приёмки (DoD)
- [ ] Поле ввода активно только при выбранном проекте
- [ ] Отправка сообщения добавляет сообщение пользователя в чат
- [ ] Ответ ассистента отображается
- [ ] После отправки поле очищается и получает фокус
- [ ] При ошибке – уведомление
