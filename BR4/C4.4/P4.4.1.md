## 📄 Спецификация патча P4.4.1 (L5)

**ID:** P4.4.1  
**Контейнер:** C4.4 Dialogue Console (затрагиваются C2.6 Project Memory, C9.4 Dialogue Manager)  
**Название:** Веб‑интерфейс диалога с выбором проекта  
**Статус:** выполнена

### 1. Цель

Создать веб‑интерфейс для ведения диалога с системой, позволяющий:

- выбирать существующий проект из C2.6;
    
- создавать новые проекты;
    
- отправлять сообщения в C9.4 с привязкой к проекту;
    
- отображать историю сообщений проекта (из C2.6).
    

### 2. Технические параметры

**C2.6 Project Memory**

- Добавлен CORS (`allow_origins=["*"]`).
    
- Используемые эндпоинты:
    
    - `GET /projects`
        
    - `POST /projects`
        
    - `GET /projects/{id}/messages?limit=50`
        
    - `POST /projects/{id}/messages` (уже существовал)
        
- Внутренний порт: `8090`, внешний (хостовый): `8108`.
    

**C9.4 Dialogue Manager**

- Добавлен CORS.
    
- Изменён входной формат: принимает `project_id` вместо `session_id`.
    
- Сохраняет сообщения пользователя и ассистента в C2.6 через `POST /projects/{id}/messages`.
    
- Использует `project_id` как идентификатор сессии (один диалог на проект).
    
- Внутренний порт: `8099`, внешний: `8111`.
    

**C4.4 Dialogue Console**

- Статический сайт (HTML, CSS, JS).
    
- Взаимодействует с хостовыми портами `8108` и `8111`.
    
- Функции: загрузка списка проектов, создание проекта, загрузка истории, отправка сообщения с `project_id`, обновление истории после отправки.
    
- Внутренний порт: `8112`, внешний: `8112`.
    

### 3. Требования к коду

- **Структура** – C2.6 и C9.4 разделены на `models.py`, `repositories.py`, `services.py`, `main.py`; C4.4 – отдельные `.html`, `.css`, `.js`.
    
- **Типизация** – аннотации типов для всех функций.
    
- **Docstring** – все функции и эндпоинты документированы.
    
- **Логирование** – INFO для успешных операций, ERROR для ошибок.
    
- **Обработка ошибок** – корректные HTTP‑статусы (400, 404, 409, 500, 503).
    
- **Валидация** – Pydantic для входных данных.
