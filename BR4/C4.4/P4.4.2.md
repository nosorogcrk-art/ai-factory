# СПЕЦИФИКАЦИЯ ПАТЧА P4.4.2 (L5)

**ID:** P4.4.2  
**Контейнер:** C4.4 (Dialogue Console)  
**Название:** Интеграция с C2.6 (проекты)  
**Статус:** выполнена

---

### 1. Цель
Добавить в веб-интерфейс возможность получения списка проектов из C2.6 и создания нового проекта. Реализовать JavaScript-код для работы с API C2.6.

### 2. Технические параметры
- **Модифицируемые файлы:** `BR4/C4.4/static/index.html`, `BR4/C4.4/static/script.js`
- **API C2.6:** 
  - `GET /projects` – получить список проектов
  - `POST /projects` – создать новый проект
- **Новые функции в JS:**
  - `loadProjects()` – загружает список и заполняет `<select>`
  - `createNewProject()` – вызывает `POST /projects` с именем, затем перезагружает список и выбирает новый проект

### 3. Требования к коду
- [ ] **Структура:** отдельные функции в `script.js`
- [ ] **Обработка ошибок:** показывать сообщение пользователю при сбое API
- [ ] **Логирование:** ошибки в консоль браузера

### 4. Тесты
- [ ] Ручное тестирование: загрузка страницы, появление списка проектов
- [ ] Ручное тестирование: создание нового проекта, появление в списке и автоматический выбор

### 5. Критерии приёмки (DoD)
- [ ] Список проектов отображается в выпадающем списке
- [ ] Кнопка «Новый проект» открывает диалог, после ввода имени проект создаётся
- [ ] После создания новый проект автоматически выбирается
- [ ] При ошибках отображается уведомление
