# СПЕЦИФИКАЦИЯ ПАТЧА P4.4.5 (L5)

**ID:** P4.4.5  
**Контейнер:** C4.4 (Dialogue Console)  
**Название:** Улучшения UX  
**Статус:** выполнена

---

### 1. Цель
Добавить обязательный выбор проекта перед отправкой сообщения, блокировку поля ввода при отсутствии проекта, уведомления об ошибках и статусную строку.

### 2. Технические параметры
- **Модифицируемые файлы:** `BR4/C4.4/static/index.html`, `BR4/C4.4/static/script.js`, `BR4/C4.4/static/style.css`
- **Новые элементы:**
  - Строка статуса (`#status`) для отображения текущего проекта и ошибок
  - Блокировка/разблокировка поля ввода и кнопки отправки
- **Функциональность:**
  - При загрузке страницы, если проектов нет, поле ввода заблокировано, кнопка неактивна
  - При выборе проекта поле разблокируется, кнопка становится активной
  - При ошибках API в статусной строке появляется сообщение, исчезающее через 5 секунд

### 3. Требования к коду
- [ ] **CSS:** статусная строка имеет отдельный класс, сообщения об ошибках выделены цветом
- [ ] **JavaScript:** функция `updateUI()` обновляет состояние элементов управления в зависимости от наличия выбранного проекта

### 4. Тесты
- [ ] Ручное тестирование: при отсутствии проектов поле ввода заблокировано
- [ ] При выборе проекта поле разблокируется
- [ ] При ошибке отображается сообщение

### 5. Критерии приёмки (DoD)
- [ ] Поле ввода и кнопка отправки активны только при выбранном проекте
- [ ] Статусная строка показывает название текущего проекта
- [ ] Сообщения об ошибках отображаются и автоматически исчезают
- [ ] Дизайн адаптирован под мобильные устройства
