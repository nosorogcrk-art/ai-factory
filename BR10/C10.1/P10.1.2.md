
### **P10.1.2: Автоматическая сборка** (LEVEL 5)

**ID:** P10.1.2  
**Контейнер:** C10.1 (Интегратор)  
**Название:** `build.py` – запуск сборочных команд после интеграции

#### 1. ЗАМЫСЕЛ ПАТЧА
Расширение функциональности интегратора: после успешного применения патчей и создания коммита автоматически запускается процесс сборки продукта (компиляция, сборка статики, подготовка артефактов). Это обеспечивает быструю обратную связь о том, что код собирается корректно.

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Зависимости:** P10.1.1, наличие сборочных инструментов (make, npm, pip и т.д.) в окружении.
- **Входные данные:** конфигурационный файл `build_config.json` в директории репозитория или параметры командной строки.
- **Выходные данные:** логи сборки, код возврата.
- **Алгоритм:**
  1. После успешного выполнения `integrator.py` (или в составе общего процесса) вызывается скрипт `build.py`.
  2. Загружает конфигурацию сборки (команды, переменные окружения).
  3. Последовательно выполняет команды сборки, логируя stdout/stderr.
  4. При успешном выполнении всех команд возвращает код 0, иначе 1.
- **Интеграция:** может быть вызван как отдельный шаг или встроен в `integrator.py` как опция.

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
build.py – автоматическая сборка продукта после интеграции.
"""

import json
import subprocess
import sys
import logging
from pathlib import Path

REPO_PATH = Path("02_ПРОДУКТ/РЕПО")
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/build.log")
CONFIG_FILE = REPO_PATH / "build_config.json"

LOG_FILE.parent.mkdir(parents=True, exist_ok=True)

logging.basicConfig(
    filename=LOG_FILE,
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

def load_config():
    if not CONFIG_FILE.exists():
        logging.error(f"Build config not found: {CONFIG_FILE}")
        return None
    with open(CONFIG_FILE, "r", encoding="utf-8") as f:
        return json.load(f)

def run_command(cmd, cwd=REPO_PATH):
    logging.info(f"Running: {cmd}")
    try:
        result = subprocess.run(
            cmd,
            cwd=cwd,
            shell=True,  # для простоты, но можно и списком
            capture_output=True,
            text=True,
            check=True
        )
        logging.info(f"Output: {result.stdout}")
        return True
    except subprocess.CalledProcessError as e:
        logging.error(f"Command failed: {e.stderr}")
        return False

def main():
    config = load_config()
    if not config:
        sys.exit(1)

    commands = config.get("build_commands", [])
    if not commands:
        logging.warning("No build commands defined.")
        sys.exit(0)

    for cmd in commands:
        if not run_command(cmd):
            sys.exit(1)

    logging.info("Build completed successfully.")
    sys.exit(0)

if __name__ == "__main__":
    main()
```

**Пример `build_config.json`:**
```json
{
  "build_commands": [
    "npm install",
    "npm run build"
  ]
}
```

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)
- Скрипт `build.py` создан и размещён в `agents/tools/`.
- При наличии конфигурационного файла выполняются указанные команды.
- Логирование всех шагов ведётся.
- При ошибке любой команды скрипт завершается с кодом 1.
- Может быть вызван после интегратора (вручную или по расписанию).
