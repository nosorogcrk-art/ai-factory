### **P10.1.1: Базовый интегратор** (LEVEL 5)

**ID:** P10.1.1  
**Контейнер:** C10.1 (Интегратор)  
**Название:** `integrator.py` – базовый интегратор патчей в репозиторий

#### 1. ЗАМЫСЕЛ ПАТЧА
Создание скрипта, который принимает список готовых патчей (файлов с изменениями, созданных на основе выполненных задач), последовательно применяет их к репозиторию продукта с помощью `git apply`, разрешает простые конфликты (если возможно) и фиксирует результат в виде коммита. Это первый шаг к автоматической сборке продукта из атомарных изменений.

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Зависимости:** 
  - Git (установлен в системе, доступен через командную строку).
  - Библиотека GitPython (опционально, для более удобной работы).
  - Доступ к репозиторию продукта (предполагается, что репозиторий находится в `02_ПРОДУКТ/РЕПО/` или аналогичной папке).
- **Входные данные:** 
  - JSON-файл со списком патчей (пути к файлам `.patch` или `.diff`), которые необходимо применить.
  - Опционально: идентификатор задачи (для привязки коммита).
- **Выходные данные:** 
  - Код возврата (0 – успех, иначе ошибка).
  - Лог-файл с результатами применения каждого патча.
- **Алгоритм:**
  1. Загружает список патчей из входного JSON.
  2. Для каждого патча выполняет `git apply --check` для проверки возможности применения.
  3. Если все проверки успешны, применяет патчи последовательно через `git apply`.
  4. При возникновении конфликта логирует ошибку и прекращает процесс.
  5. После успешного применения всех патчей создаёт коммит с сообщением, содержащим идентификатор задачи (если передан) и список применённых патчей.
  6. Логирует все действия в `integrator.log`.

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
integrator.py – базовый интегратор патчей в репозиторий продукта.
"""

import json
import sys
import subprocess
import logging
from pathlib import Path

# Конфигурация
REPO_PATH = Path("02_ПРОДУКТ/РЕПО")  # путь к репозиторию продукта
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/integrator.log")
LOG_FILE.parent.mkdir(parents=True, exist_ok=True)

logging.basicConfig(
    filename=LOG_FILE,
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

def run_git(cmd, cwd=REPO_PATH):
    """Выполняет git-команду в репозитории."""
    try:
        result = subprocess.run(
            ["git"] + cmd,
            cwd=cwd,
            capture_output=True,
            text=True,
            check=True
        )
        return result.stdout.strip()
    except subprocess.CalledProcessError as e:
        logging.error(f"Git command failed: {e.stderr}")
        return None

def apply_patch(patch_path, check_only=False):
    """Применяет патч (или проверяет)."""
    cmd = ["apply", "--check" if check_only else "", str(patch_path)]
    # убираем пустые аргументы
    cmd = [c for c in cmd if c]
    return run_git(cmd) is not None

def main():
    data = json.load(sys.stdin)
    patches = data.get("patches", [])
    task_id = data.get("task_id", "unknown")

    if not patches:
        logging.error("No patches provided")
        sys.exit(1)

    # Шаг 1: проверка всех патчей
    for patch in patches:
        if not apply_patch(Path(patch), check_only=True):
            logging.error(f"Patch {patch} cannot be applied (conflicts).")
            sys.exit(1)

    # Шаг 2: последовательное применение
    applied = []
    for patch in patches:
        if apply_patch(Path(patch), check_only=False):
            applied.append(patch)
            logging.info(f"Applied {patch}")
        else:
            logging.error(f"Failed to apply {patch} during actual apply.")
            sys.exit(1)

    # Шаг 3: коммит
    commit_msg = f"Integrate patches for task {task_id}\n\nPatches:\n" + "\n".join(applied)
    if run_git(["commit", "-m", commit_msg]):
        logging.info(f"Committed changes for task {task_id}")
    else:
        logging.error("Commit failed")
        sys.exit(1)

    print(json.dumps({"status": "ok", "applied": applied}))

if __name__ == "__main__":
    main()
```

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)
- Скрипт `integrator.py` создан и размещён в `agents/tools/`.
- При передаче JSON со списком корректных патчей они применяются к репозиторию и создаётся коммит.
- При наличии конфликта скрипт завершается с ошибкой и ничего не коммитит.
- Логирование ведётся.
- Скрипт возвращает JSON-отчёт о выполненной работе.
