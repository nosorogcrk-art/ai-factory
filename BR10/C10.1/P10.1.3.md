
### **P10.1.3: Версионирование артефактов** (LEVEL 5)

**ID:** P10.1.3  
**Контейнер:** C10.1 (Интегратор)  
**Название:** `versioning.py` – автоматическое тегирование и архивация

#### 1. ЗАМЫСЕЛ ПАТЧА
После успешной сборки продукта необходимо зафиксировать версию и создать дистрибутив. Скрипт автоматически создаёт Git-тег на основе версии (например, из конфига или по дате), а также архивирует исходный код/бинарные файлы для последующего распространения.

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Зависимости:** P10.1.2, Git.
- **Входные данные:** 
  - Версия (строка) может быть передана аргументом или взята из файла `version.txt` в репозитории.
  - Путь к артефактам (по умолчанию репозиторий целиком).
- **Выходные данные:** 
  - Git-тег в репозитории.
  - Архив (`.tar.gz` или `.zip`) в папке `02_ПРОДУКТ/РЕЛИЗЫ/`.
- **Алгоритм:**
  1. Определяет версию (приоритет: аргумент -> файл version.txt -> дата).
  2. Создаёт Git-тег с именем `v<version>`.
  3. Создаёт архив репозитория (или указанной директории) с именем `product-<version>.tar.gz`.
  4. Сохраняет архив в `02_ПРОДУКТ/РЕЛИЗЫ/`.
  5. Логирует все действия.

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
versioning.py – тегирование версий и архивация продукта.
"""

import sys
import subprocess
import tarfile
import logging
from pathlib import Path
from datetime import datetime

REPO_PATH = Path("02_ПРОДУКТ/РЕПО")
RELEASES_DIR = Path("02_ПРОДУКТ/РЕЛИЗЫ")
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/versioning.log")
VERSION_FILE = REPO_PATH / "version.txt"

RELEASES_DIR.mkdir(parents=True, exist_ok=True)
LOG_FILE.parent.mkdir(parents=True, exist_ok=True)

logging.basicConfig(
    filename=LOG_FILE,
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

def run_git(cmd, cwd=REPO_PATH):
    try:
        subprocess.run(["git"] + cmd, cwd=cwd, check=True, capture_output=True)
        return True
    except subprocess.CalledProcessError as e:
        logging.error(f"Git error: {e.stderr.decode()}")
        return False

def get_version(args):
    if len(args) > 1:
        return args[1]
    if VERSION_FILE.exists():
        with open(VERSION_FILE, "r") as f:
            return f.read().strip()
    return datetime.now().strftime("%Y%m%d-%H%M%S")

def create_tag(version):
    tag_name = f"v{version}"
    if run_git(["tag", tag_name]):
        logging.info(f"Created tag {tag_name}")
        return True
    return False

def create_archive(version):
    archive_name = f"product-{version}.tar.gz"
    archive_path = RELEASES_DIR / archive_name
    with tarfile.open(archive_path, "w:gz") as tar:
        tar.add(REPO_PATH, arcname=REPO_PATH.name)
    logging.info(f"Created archive {archive_path}")
    return archive_path

def main():
    version = get_version(sys.argv)
    if not create_tag(version):
        sys.exit(1)
    archive = create_archive(version)
    print(json.dumps({"version": version, "archive": str(archive)}))

if __name__ == "__main__":
    import json
    main()
```

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)

- При запуске с версией (или без) создаётся Git-тег и архив.

- Логирование ведётся.
