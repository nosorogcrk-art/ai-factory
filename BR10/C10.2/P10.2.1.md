### **P10.2.1: Базовый стенд** (LEVEL 5)

**ID:** P10.2.1  
**Контейнер:** C10.2 (Стенд Приемки)  
**Название:** `test_stand.py` – запуск тестов продукта в изолированной среде

#### 1. ЗАМЫСЕЛ ПАТЧА
Создание скрипта, который запускает изолированное окружение (Docker-контейнер) с собранным продуктом, выполняет заданный набор тестов и сохраняет результаты. Это обеспечивает автоматизированную проверку качества продукта перед релизом.

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Зависимости:** Docker (должен быть установлен и доступен), тестовый фреймворк (pytest, предполагается для Python-проекта).
- **Входные данные:** JSON-файл или аргументы командной строки, содержащие:
  - `product_path` – путь к собранному продукту (например, `02_ПРОДУКТ/РЕПО`).
  - `test_suite` – путь к тестам (по умолчанию `tests/` внутри продукта).
  - `image` – Docker-образ, в котором запускать (по умолчанию `python:3.11-slim`).
- **Выходные данные:** JSON-файл с результатами тестов (количество пройденных/упавших, детали ошибок), сохраняемый в `01_ЦЕХ/01_ЖУРНАЛЫ/test_results/` с именем `test_result_<timestamp>.json`.
- **Алгоритм:**
  1. Подготавливает временную директорию для монтирования продукта.
  2. Запускает Docker-контейнер с монтированием продукта и тестов, выполняет команду `pytest --json-report` (или аналогичную) для получения отчёта в JSON.
  3. После завершения тестов копирует отчёт из контейнера наружу.
  4. Логирует все действия в `test_stand.log`.
- **Логирование:** все шаги и ошибки записываются в `01_ЦЕХ/01_ЖУРНАЛЫ/test_stand.log`.

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
test_stand.py – запуск тестов продукта в Docker-контейнере.
"""

import json
import subprocess
import sys
import logging
import tempfile
import shutil
from pathlib import Path
from datetime import datetime

LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/test_stand.log")
RESULTS_DIR = Path("01_ЦЕХ/01_ЖУРНАЛЫ/test_results")
RESULTS_DIR.mkdir(parents=True, exist_ok=True)
LOG_FILE.parent.mkdir(parents=True, exist_ok=True)

logging.basicConfig(
    filename=LOG_FILE,
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

def run_tests(product_path: Path, test_suite: str = "tests", image: str = "python:3.11-slim"):
    # Создаём временную директорию для результатов
    with tempfile.TemporaryDirectory(prefix="test_stand_") as tmpdir:
        tmp_path = Path(tmpdir)
        report_file = tmp_path / "report.json"

        # Монтируем продукт и временную папку для отчёта
        cmd = [
            "docker", "run", "--rm",
            "-v", f"{product_path.absolute()}:/product",
            "-v", f"{tmp_path.absolute()}:/results",
            image,
            "sh", "-c",
            f"cd /product && pytest {test_suite} --json-report --json-report-file=/results/report.json"
        ]
        logging.info(f"Running command: {' '.join(cmd)}")
        try:
            subprocess.run(cmd, check=True, capture_output=True, text=True)
            logging.info("Tests completed successfully.")
        except subprocess.CalledProcessError as e:
            logging.error(f"Tests failed with error: {e.stderr}")
            # Даже если тесты упали, пытаемся получить отчёт

        # Копируем отчёт из временной директории в RESULTS_DIR
        if report_file.exists():
            timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
            dest_file = RESULTS_DIR / f"test_result_{timestamp}.json"
            shutil.copy2(report_file, dest_file)
            logging.info(f"Test report saved to {dest_file}")
            return dest_file
        else:
            logging.error("No test report generated.")
            return None

def main():
    # Парсинг входных данных (можно из аргументов или stdin)
    if len(sys.argv) > 1:
        config_path = Path(sys.argv[1])
        with open(config_path, "r", encoding="utf-8") as f:
            config = json.load(f)
    else:
        # Чтение из stdin
        config = json.load(sys.stdin)

    product_path = Path(config.get("product_path", "02_ПРОДУКТ/РЕПО"))
    test_suite = config.get("test_suite", "tests")
    image = config.get("image", "python:3.11-slim")

    report_file = run_tests(product_path, test_suite, image)
    if report_file:
        print(json.dumps({"status": "ok", "report": str(report_file)}))
    else:
        print(json.dumps({"status": "error", "message": "Tests failed or no report"}))
        sys.exit(1)

if __name__ == "__main__":
    main()
```

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)
- Скрипт `test_stand.py` создан и размещён в `agents/tools/`.
- При запуске с корректными параметрами запускается Docker-контейнер и выполняются тесты.
- Отчёт о тестировании сохраняется в указанную папку.
- Логирование всех действий ведётся.
- При отсутствии Docker или ошибках выполнения скрипт завершается с ненулевым кодом и логирует ошибку.
