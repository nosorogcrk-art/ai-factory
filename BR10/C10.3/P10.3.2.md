# СПЕЦИФИКАЦИЯ ПАТЧА P10.3.2 (L5)

**ID:** P10.3.2  
**Контейнер:** C10.3 (Packager)  
**Название:** Метаданные о навыках  
**Статус:** выполнена

---

### 1. Цель
Добавить в архив файл `metadata.json`, содержащий список навыков, использованных в продукте (из `required_skills` в спецификациях патчей).

### 2. Технические параметры
- **Источник:** список навыков передаётся через JSON на вход (`skills`).
- **Формат:** `{"product_version": "...", "build_date": "...", "skills": [{"id": "SKILL-...", "version": "..."}]}`.

### 3. Реализация
Модифицировать `packager.py`: перед упаковкой создать файл `metadata.json` в корне копии репозитория.

### 4. Критерии приёмки (DoD)
- В архиве появляется `metadata.json` с корректными данными.
- При отсутствии навыков создаётся пустой список.
