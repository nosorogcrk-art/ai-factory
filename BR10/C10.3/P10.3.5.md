# СПЕЦИФИКАЦИЯ ПАТЧА P10.3.5 (L5)

**ID:** P10.3.5  
**Контейнер:** C10.3 (Packager)  
**Название:** Интеграция с BR5  
**Статус:** выполнена

---

### 1. Цель
После создания дистрибутива отправить уведомление в коммерческий модуль (BR5) о готовности продукта.

### 2. Технические параметры
- **Адрес BR5:** переменная окружения `BR5_URL` (по умолчанию `http://br5:8095/api/products`)
- **Запрос:** POST с JSON: `{"product_name": "product-{version}", "archive": "path", "metadata": {...}}`.

### 3. Реализация
В конце работы `packager.py` отправить асинхронный POST-запрос (не блокируя). При ошибке – только логировать.

### 4. Критерии приёмки (DoD)
- При успехе лог содержит подтверждение.
- При недоступности BR5 упаковка не прерывается.
