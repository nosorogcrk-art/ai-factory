# СПЕЦИФИКАЦИЯ ПАТЧА P10.3.14 (L5)

**ID:** P10.3.14  
**Контейнер:** C10.3 (Packager)  
**Название:** Превращение C10.3 в сервис (FastAPI)  
**Статус:** выполнена

---

## 1. Цель
Оформить существующие скрипты как FastAPI-приложение с эндпоинтом `/package`, healthcheck, логированием и тестами.

---

## 2. Технические параметры

- **Новые файлы:** `main.py`, `models.py`, `services.py`, `tests/`.
- **Эндпоинты:**
  - `GET /health` – проверка работоспособности.
  - `POST /package` – запуск упаковки.
- **Логирование:** локальный файл `packager.log`, отправка в BR18.
- **Тесты:** юнит-тесты для всех функций, интеграционные тесты для эндпоинта.

---

## 3. Критерии приёмки (DoD)
- [ ] Приложение запускается и отвечает на `/health`.
- [ ] Эндпоинт `/package` создаёт архив и возвращает путь.
- [ ] Логи записываются в локальный файл и отправляются в BR18.
- [ ] Написаны юнит- и интеграционные тесты (минимум 3+3).
- [ ] Все тесты проходят.
- [ ] `mypy` и `ruff` не выдают ошибок.
- [ ] README содержит описание API и переменных окружения.
- [ ] Healthcheck настроен в `docker-compose.yml`.
