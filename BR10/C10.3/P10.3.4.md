### 1. Цель
Создать скрипт `release_notes.py`, который генерирует `RELEASE_NOTES.md` на основе коммитов Git в репозитории продукта.

### 2. Технические параметры
- **Вход:** JSON через stdin: `{"repo_path": "02_ПРОДУКТ/РЕПО", "since_tag": null, "output_file": "02_ПРОДУКТ/РЕЛИЗЫ/RELEASE_NOTES.md"}`
- **Выход:** JSON с путём к файлу.
- **Логика:** если `since_tag` передан, собирает коммиты от этого тега; иначе – все.

### 3. Реализация
Использовать GitPython для итерации по коммитам, извлекать сообщения, искать идентификаторы патчей (`IMP-...` или `P...`). Формировать Markdown-список.

### 4. Критерии приёмки (DoD)
- Файл создаётся и содержит список коммитов с группировкой по ID патчей.
- При отсутствии Git-репозитория – ошибка.
