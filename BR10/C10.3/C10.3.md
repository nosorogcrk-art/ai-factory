### **C10.3: Packager**

**Ветка-родитель:** BR10 | **ID:** C10.3 | **Ответственный:** ГЕФЕСТ

**1. ФУНКЦИОНАЛЬНОЕ ПРЕДНАЗНАЧЕНИЕ**  
Подготовка пользовательской документации, релиз-ноутс и формирование дистрибутива продукта. В дистрибутив добавляются метаданные о требуемых навыках.

**2. ТЕХНИЧЕСКАЯ ЛОГИКА (МЕХАНИКА)**  
- **Упаковка:** скрипт `packager.py` создаёт архив `product-<version>.tar.gz` из репозитория.  
- **Метаданные:** добавляет файл `metadata.json` со списком использованных навыков.  
- **Документация:** `doc_builder.py` собирает MkDocs из папки `docs`.  
- **Релиз-ноутс:** `release_notes.py` генерирует `RELEASE_NOTES.md` на основе Git-коммитов.  
- **Сервис:** предоставляет REST API (FastAPI) для внешнего вызова.

**3. ВХОДЫ И ВЫХОДЫ (INTERFACES)**  
- **Input:** HTTP-запросы к API (POST /package) с JSON-телом.  
- **Output:** JSON с путём к архиву и статусом.

**4. ИНТЕГРАЦИИ**
