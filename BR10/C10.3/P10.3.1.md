### 1. Цель
Создать скрипт `packager.py`, который упаковывает репозиторий продукта в архив `.tar.gz` и сохраняет его в `02_ПРОДУКТ/РЕЛИЗЫ/`.

### 2. Технические параметры
- **Вход:** JSON через stdin: `{"repo_path": "02_ПРОДУКТ/РЕПО", "version": "v1.0.0", "output_dir": "02_ПРОДУКТ/РЕЛИЗЫ"}`
- **Выход:** JSON с путём к архиву.
- **Логирование:** в `01_ЦЕХ/01_ЖУРНАЛЫ/packager.log`.

### 3. Реализация
Код аналогичен предоставленному в файле `packager.py` (см. загрузки). Архив создаётся командой `tar` через Python.

### 4. Критерии приёмки (DoD)
- Скрипт создаёт архив с правильным именем.
- Игнорируются `.git`, `__pycache__`, `.DS_Store`.
- При ошибке возвращается ненулевой код.
