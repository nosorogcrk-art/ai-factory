### 1. Цель
Создать скрипт `doc_builder.py`, который собирает MkDocs из папки `docs` репозитория и сохраняет результат в `02_ПРОДУКТ/РЕЛИЗЫ/docs/`.

### 2. Технические параметры
- **Вход:** JSON через stdin: `{"source": "02_ПРОДУКТ/РЕПО/docs", "output": "02_ПРОДУКТ/РЕЛИЗЫ/docs", "version": "v1.0.0"}`
- **Выход:** JSON с путём к собранной документации.
- **Зависимости:** `mkdocs` (устанавливается в образ).

### 3. Реализация
Использовать `subprocess.run(["mkdocs", "build", "-f", "mkdocs.yml", "-d", output_dir])`. Если `mkdocs.yml` отсутствует, пропускать.

### 4. Критерии приёмки (DoD)
- При наличии `mkdocs.yml` документация собирается.
- Выходная папка создаётся с именем `docs-<version>`.
- Логирование ведётся.
