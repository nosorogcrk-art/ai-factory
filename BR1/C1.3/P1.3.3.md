
### **P1.3.3: Инициатор улучшений** (LEVEL 5)

**ID:** P1.3.3  
**Контейнер:** C1.3 (Self-Audit)  
**Название:** `improvement_initiator.py` – создание задач на улучшение промптов

---

#### 1. ЗАМЫСЕЛ ПАТЧА
На основе анализа промптов (P1.3.2) создаёт задачи (патчи) в реестре задач на обновление промптов через механизмы BR7. Также добавляет успешные завершённые патчи в эволюционную память BR2 как положительные примеры.

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Зависимости:** P1.3.2 (анализ), P7.1.2 (доступ к промптам), реестр задач, BR2 (память).
- **Входные данные:** анализ промптов из файла `prompt_analysis.json`.
- **Выходные данные:** новые задачи в реестре (с типом `improvement` для промптов) и/или записи в эволюционной памяти.
- **Алгоритм:**
  1. Загружает результаты анализа.
  2. Для каждой роли, у которой есть проблемы (issues), создаёт задачу в реестре с описанием необходимых изменений.
  3. Для успешных патчей (по метрикам) добавляет запись в память (например, в файл `01_ЦЕХ/Эволюционная_память.md` или через API BR2).
- **Логирование:** в `01_ЦЕХ/01_ЖУРНАЛЫ/improvement_initiator.log`.

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
improvement_initiator.py – создание задач на улучшение промптов.
"""

import json
import logging
from pathlib import Path
from datetime import datetime

ANALYSIS_FILE = Path("01_ЦЕХ/МЕТРИКИ/prompt_analysis.json")
TASK_REGISTRY_PATH = Path("01_ЦЕХ/ТЕКУЩИЕ_ЗАДАЧИ/task_registry.json")
MEMORY_FILE = Path("01_ЦЕХ/Эволюционная_память.md")
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/improvement_initiator.log")

LOG_FILE.parent.mkdir(parents=True, exist_ok=True)
logging.basicConfig(filename=LOG_FILE, level=logging.INFO,
                    format='%(asctime)s - %(levelname)s - %(message)s')

def load_json(path, default=None):
    if path.exists():
        with open(path, "r", encoding="utf-8") as f:
            return json.load(f)
    return default if default is not None else {}

def save_json(path, data):
    with open(path, "w", encoding="utf-8") as f:
        json.dump(data, f, indent=2, ensure_ascii=False)

def add_task(registry, role, analysis):
    """Добавляет задачу на улучшение промпта."""
    date_str = datetime.now().strftime("%Y%m%d")
    count = sum(1 for t in registry if t["id"].startswith(f"PROMPT-{date_str}"))
    task_id = f"PROMPT-{date_str}-{count+1:03d}"
    description = f"Улучшить промпт для роли {role}\n"
    description += "Проблемы:\n- " + "\n- ".join(analysis.get("issues", []))
    description += "\nПредложения:\n- " + "\n- ".join(analysis.get("suggestions", []))
    task = {
        "id": task_id,
        "title": f"Improve prompt for {role}",
        "description": description,
        "status": "NEW",
        "assigned_to": None,
        "created_at": datetime.now().isoformat(),
        "updated_at": datetime.now().isoformat(),
        "history": [],
        "type": "improvement"
    }
    registry.append(task)
    logging.info(f"Created task {task_id} for {role}")
    return task_id

def add_to_memory(role):
    """Добавляет запись об успешном патче в эволюционную память."""
    entry = f"\n### {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}\n"
    entry += f"Успешный патч: улучшение промпта для роли {role}\n"
    with open(MEMORY_FILE, "a", encoding="utf-8") as f:
        f.write(entry)
    logging.info(f"Added to memory: {role}")

def main():
    analysis = load_json(ANALYSIS_FILE, {})
    if not analysis:
        logging.warning("No analysis file found, exiting.")
        return

    registry = load_json(TASK_REGISTRY_PATH, [])

    for item in analysis.get("analyses", []):
        role = item["role"]
        if item.get("has_issues", False):
            add_task(registry, role, item)
        else:
            # Если проблем нет, можно считать промпт успешным
            add_to_memory(role)

    save_json(TASK_REGISTRY_PATH, registry)

if __name__ == "__main__":
    main()
```

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)
- Скрипт `improvement_initiator.py` создан и размещён в `agents/tools/`.
- При наличии анализа создаёт задачи в реестре для ролей с проблемами.
- Для ролей без проблем добавляет записи в эволюционную память.
- Логирование работает.
- Скрипт не падает при отсутствии анализа (логирует предупреждение).
