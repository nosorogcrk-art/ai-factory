
### **P1.1.1: Сборщик метрик** (LEVEL 5)

**ID:** P1.1.1  
**Контейнер:** C1.1 (Cognitive Engine)  
**Название:** `metric_collector.py` – сбор метрик системы

---

#### 1. ЗАМЫСЕЛ ПАТЧА
Создание скрипта, который регулярно собирает ключевые метрики работы системы из реестра задач, журналов агентов и файлов токенов. Собранные данные сохраняются в структурированном виде для последующего анализа аномалий и генерации стратегических решений. Это основа для когнитивного движка.

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Источники данных:**  
  - `task_registry.json` – информация о задачах (статусы, время создания, завершения).  
  - Логи агентов в `01_ЦЕХ/ЖУРНАЛЫ/` (например, `АРГУС_ЖУРНАЛ.md`, `ГЕФЕСТ_ЖУРНАЛ.md` и др.) – для извлечения событий (ошибки, завершения).  
  - Файлы токенов `*_TOKENS.json` – для учёта затрат.  
- **Собираемые метрики:**  
  - Общее количество задач (по статусам: NEW, IN_PROGRESS, DONE и т.д.).  
  - Среднее время выполнения задачи (в секундах) для завершённых задач.  
  - Частота ошибок (количество записей об ошибках в журналах за последние 24 часа).  
  - Распределение ошибок по агентам.  
  - Суммарные затраты токенов (из файлов `*_TOKENS.json`).  
  - Количество активных задач (IN_PROGRESS).  
- **Выходной файл:** `01_ЦЕХ/МЕТРИКИ/metrics.json` с временной меткой. Формат:  
  ```json
  {
    "timestamp": "2026-03-17T12:00:00",
    "tasks": {
      "total": 42,
      "by_status": { "NEW": 5, "IN_PROGRESS": 3, "DONE": 34 },
      "avg_duration_sec": 3600
    },
    "errors": {
      "total_last_24h": 7,
      "by_agent": { "ГЕФЕСТ": 3, "РЕВА": 2, "АРГУС": 2 }
    },
    "tokens": {
      "total": 15000,
      "by_agent": { "АРГУС": 5000, "ГЕФЕСТ": 10000 }
    },
    "active_tasks": 3
  }
  ```
- **Периодичность:** скрипт предназначен для запуска по расписанию (например, каждый час). Может вызываться вручную или через планировщик.  
- **Логирование:** записывает отладочную информацию в `01_ЦЕХ/01_ЖУРНАЛЫ/metric_collector.log`.

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
metric_collector.py – сбор метрик системы для Cognitive Engine.
"""

import json
import re
import glob
import logging
from pathlib import Path
from datetime import datetime, timedelta

# Пути
TASK_REGISTRY = Path("01_ЦЕХ/ТЕКУЩИЕ_ЗАДАЧИ/task_registry.json")
JOURNALS_DIR = Path("01_ЦЕХ/ЖУРНАЛЫ")
TOKENS_DIR = Path("01_ЦЕХ/ЖУРНАЛЫ")  # токены там же
OUTPUT_DIR = Path("01_ЦЕХ/МЕТРИКИ")
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/metric_collector.log")

OUTPUT_DIR.mkdir(parents=True, exist_ok=True)
LOG_FILE.parent.mkdir(parents=True, exist_ok=True)

logging.basicConfig(
    filename=LOG_FILE,
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

def load_task_registry():
    if not TASK_REGISTRY.exists():
        return []
    with open(TASK_REGISTRY, "r", encoding="utf-8") as f:
        return json.load(f)

def count_errors_in_journals(hours=24):
    """Считает количество записей об ошибках в журналах за последние N часов."""
    error_pattern = re.compile(r'ERROR|ошибка|❌', re.IGNORECASE)
    cutoff = datetime.now() - timedelta(hours=hours)
    errors_by_agent = {}
    total_errors = 0

    for journal in JOURNALS_DIR.glob("*_ЖУРНАЛ.md"):
        agent = journal.stem.replace("_ЖУРНАЛ", "")
        try:
            with open(journal, "r", encoding="utf-8") as f:
                lines = f.readlines()
            for line in lines:
                # Ищем временную метку в начале строки (формат: ## [YYYY-MM-DD HH:MM:SS])
                timestamp_match = re.match(r'## \[(\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})\]', line)
                if timestamp_match:
                    ts_str = timestamp_match.group(1)
                    ts = datetime.strptime(ts_str, "%Y-%m-%d %H:%M:%S")
                    if ts > cutoff and error_pattern.search(line):
                        errors_by_agent[agent] = errors_by_agent.get(agent, 0) + 1
                        total_errors += 1
        except Exception as e:
            logging.warning(f"Failed to read {journal}: {e}")
    return total_errors, errors_by_agent

def collect_tokens():
    """Суммирует токены из всех *_TOKENS.json файлов."""
    total = 0
    by_agent = {}
    for token_file in TOKENS_DIR.glob("*_TOKENS.json"):
        agent = token_file.stem.replace("_TOKENS", "")
        try:
            with open(token_file, "r", encoding="utf-8") as f:
                data = json.load(f)
                tokens = data.get("used_tokens", 0)
                total += tokens
                by_agent[agent] = by_agent.get(agent, 0) + tokens
        except Exception as e:
            logging.warning(f"Failed to read {token_file}: {e}")
    return total, by_agent

def calculate_avg_duration(tasks):
    durations = []
    for task in tasks:
        if task.get("status") == "DONE":
            created = task.get("created_at")
            updated = task.get("updated_at")
            if created and updated:
                try:
                    created_dt = datetime.fromisoformat(created)
                    updated_dt = datetime.fromisoformat(updated)
                    durations.append((updated_dt - created_dt).total_seconds())
                except:
                    pass
    if durations:
        return sum(durations) / len(durations)
    return 0

def main():
    logging.info("Starting metric collection")
    tasks = load_task_registry()

    # Статистика задач
    total_tasks = len(tasks)
    by_status = {}
    for task in tasks:
        status = task.get("status", "UNKNOWN")
        by_status[status] = by_status.get(status, 0) + 1

    avg_duration = calculate_avg_duration(tasks)

    # Ошибки
    total_errors, errors_by_agent = count_errors_in_journals(24)

    # Токены
    total_tokens, tokens_by_agent = collect_tokens()

    # Активные задачи
    active_tasks = by_status.get("IN_PROGRESS", 0)

    metrics = {
        "timestamp": datetime.now().isoformat(),
        "tasks": {
            "total": total_tasks,
            "by_status": by_status,
            "avg_duration_sec": avg_duration
        },
        "errors": {
            "total_last_24h": total_errors,
            "by_agent": errors_by_agent
        },
        "tokens": {
            "total": total_tokens,
            "by_agent": tokens_by_agent
        },
        "active_tasks": active_tasks
    }

    output_file = OUTPUT_DIR / f"metrics_{datetime.now().strftime('%Y%m%d_%H%M%S')}.json"
    with open(output_file, "w", encoding="utf-8") as f:
        json.dump(metrics, f, indent=2, ensure_ascii=False)

    # Также сохраняем последнюю метрику в фиксированный файл для лёгкого доступа
    latest_file = OUTPUT_DIR / "latest_metrics.json"
    with open(latest_file, "w", encoding="utf-8") as f:
        json.dump(metrics, f, indent=2, ensure_ascii=False)

    logging.info(f"Metrics saved to {output_file}")

if __name__ == "__main__":
    main()
```

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)
- Скрипт `metric_collector.py` создан и размещён в `agents/tools/`.
- При запуске собирает метрики из существующих файлов и создаёт файл в `01_ЦЕХ/МЕТРИКИ/`.
- Если некоторые файлы отсутствуют, скрипт продолжает работу и собирает доступные данные (логирует предупреждения).
- Выходной JSON соответствует описанной структуре.
- Скрипт можно запускать вручную и по расписанию.
