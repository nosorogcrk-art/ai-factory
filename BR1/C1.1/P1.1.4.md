
### **P1.1.4: Классификатор задач** (LEVEL 5)

**ID:** P1.1.4  
**Контейнер:** C1.1 (Cognitive Engine)  
**Название:** `task_classifier.py` – классификация задач на доработку завода

---

#### 1. ЗАМЫСЕЛ ПАТЧА
Создание модуля, который анализирует входные запросы (от Аргуса, Дедала или автоматические уведомления) и выявленные аномалии, определяет тип задачи по развитию завода (улучшение промптов, рефакторинг, изменение конфигурации, добавление шаблонов и т.д.), её приоритет и релевантные компоненты. Использует правила и семантический поиск по памяти BR2 для поиска аналогичных ситуаций.

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Зависимости:** P1.1.1 (метрики), P2.1.3 (семантический поиск из BR2).
- **Входные данные:** объект с полями:
  - `source` (строка) – источник (аномалия, запрос пользователя, инициатива Дедала).
  - `description` (строка) – описание проблемы или задачи.
  - `context` (словарь) – дополнительные параметры (например, ID задачи, метрики).
- **Выходные данные:** объект с полями:
  - `task_type` – строка, один из типов: `prompt_update`, `refactor`, `config_change`, `template_add`, `other`.
  - `priority` – число (1-5, где 1 – наивысший).
  - `affected_components` – список строк (например, `["BR7/C7.1", "BR3/C3.2"]`).
  - `reasoning` – краткое обоснование.
  - `similar_cases` – список ID похожих задач из памяти (опционально).
- **Механизм:**
  - Использует набор правил (например, если частота ошибок по агенту > порога → task_type = `prompt_update`).
  - Если правил недостаточно, выполняет семантический поиск по памяти BR2, чтобы найти похожие ситуации и определить типовое решение.
  - Приоритет вычисляется на основе метрик и критичности.
- **Логирование:** в `01_ЦЕХ/01_ЖУРНАЛЫ/task_classifier.log`.

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
task_classifier.py – классификация задач на доработку завода.
"""

import json
import logging
from pathlib import Path
from typing import Dict, Any

# Предполагается импорт функции поиска из BR2
from semantic_search import search

LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/task_classifier.log")
LOG_FILE.parent.mkdir(parents=True, exist_ok=True)

logging.basicConfig(
    filename=LOG_FILE,
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

# Пороги для правил (можно вынести в конфиг)
THRESHOLDS = {
    "error_rate_per_task": 0.2,      # доля задач с ошибками
    "avg_duration_exceed": 2.0,      # превышение среднего времени в 2 раза
    "token_cost_spike": 1.5          # рост затрат токенов в 1.5 раза
}

def classify(problem: Dict[str, Any]) -> Dict[str, Any]:
    source = problem.get("source", "unknown")
    desc = problem.get("description", "")
    context = problem.get("context", {})
    
    # Начальные значения
    task_type = "other"
    priority = 3
    affected = []
    reasoning = []
    
    # Правила на основе метрик
    metrics = context.get("metrics", {})
    if metrics:
        # Пример: высокая частота ошибок у агента
        errors_by_agent = metrics.get("errors", {}).get("by_agent", {})
        if errors_by_agent:
            max_errors = max(errors_by_agent.values())
            if max_errors > 5:  # порог
                task_type = "prompt_update"
                affected = ["BR7/C7.1"]
                priority = 1
                reasoning.append(f"High error rate for agent(s): {errors_by_agent}")
        
        # Пример: задачи зависают в статусе
        if metrics.get("active_tasks", 0) > 10:  # слишком много активных
            task_type = "config_change"
            affected = ["BR7/C7.2"]
            priority = 2
            reasoning.append("Too many active tasks, possible timeout issues")
    
    # Если правил недостаточно, используем семантический поиск по памяти
    if task_type == "other" and desc:
        results = search(query=desc, k=3)
        similar_cases = [r["id"] for r in results if r["score"] > 0.7]
        if similar_cases:
            # Можно извлечь типовое решение из метаданных найденных документов
            reasoning.append(f"Found similar cases: {similar_cases}")
            # Для простоты пока оставляем тип other, но в будущем можно уточнять
        else:
            similar_cases = []
    else:
        similar_cases = []
    
    result = {
        "task_type": task_type,
        "priority": priority,
        "affected_components": affected,
        "reasoning": "; ".join(reasoning) if reasoning else "Classified by rules",
        "similar_cases": similar_cases
    }
    logging.info(f"Classified problem from {source}: {result}")
    return result

if __name__ == "__main__":
    import sys
    data = json.load(sys.stdin)
    output = classify(data)
    print(json.dumps(output, ensure_ascii=False, indent=2))
```
