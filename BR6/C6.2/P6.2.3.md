
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P6.2.3 (LEVEL 5)

**ID:** P6.2.3  
**Контейнер:** C6.2 (Semantic Auditor)  
**Название:** Проверка графа навыков  

**Зависимости:** P6.2.2

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Реализовать анализ графа зависимостей навыков из BR17 (C17.3) на наличие циклов и ссылок на несуществующие навыки. Циклические зависимости делают навык недействительным; несуществующие зависимости должны быть отмечены. Результаты проверки сохраняются и могут инициировать блокировку навыков (в P6.2.4).

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Источник данных:**  
  – API C17.3 (Skill Graph) – эндпоинт `/graph` или `/dependencies`.  
- **Проверки:**  
  – **Циклы:** для каждого навыка выполнить поиск циклов в графе (алгоритм топологической сортировки или DFS).  
  – **Несуществующие зависимости:** проверить, что каждый ID в поле `depends_on` существует в реестре навыков (можно запросить у C17.1).  
- **Действия:**  
  – Список навыков с циклами и несуществующими зависимостями сохраняется в отчёт.  
  – (Опционально) для каждого такого навыка генерируется предложение по исправлению.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Функция `check_skill_graph()`:  
  - Получить граф навыков от C17.3.  
  - Построить словарь зависимостей.  
  - Выполнить обнаружение циклов (например, с помощью поиска в глубину с раскраской).  
  - Для каждой зависимости проверить существование через C17.1.  
  - Сохранить результаты в JSON.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- Скрипт корректно обнаруживает циклы (если они есть).  
- Проверяет существование каждого навыка из зависимостей.  
- Результаты сохраняются в файл.  
- При отсутствии ошибок граф считается валидным.
