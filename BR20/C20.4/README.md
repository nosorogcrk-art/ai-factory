# C20.4 Test Runner (Запускатель тестов)

Контейнер для автоматического тестирования конфигураций перед деплоем. Включает синтаксическую, семантическую и функциональную проверку файлов конфигураций.

## Функциональность

- **Синтаксические тесты**: проверка JSON/YAML схем, валидация Markdown
- **Семантические тесты**: проверка ссылочной целостности, уникальности идентификаторов
- **Функциональные тесты**: запуск тестовых сценариев через C17.4 (Skill Tester)
- **Регрессионные тесты**: сравнение с эталонными ответами

## Переменные окружения

- `PORT` - порт для запуска сервера (по умолчанию: 8204)
- `BR18_URL` - URL для логирования в BR18 (Alert Manager)
- `ENABLE_BR18` - включение логирования в BR18 (true/false)
- `GITOPS_CORE_URL` - URL для C20.1 (GitOps Core)
- `SKILL_TESTER_URL` - URL для C17.4 (Skill Tester)
- `SKILL_REGISTRY_URL` - URL для C17.1 (Skill Registry)

## Запуск

### Локально

```bash
cd BR20/C20.4
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8204 --reload
```

### Docker

```bash
docker build -t test-runner .
docker run -p 8204:8204 test-runner
```

## API

- `GET /health` - проверка здоровья сервиса
- `POST /test` - запуск тестов
- `GET /results/{test_id}` - получение результатов тестов
- `GET /docs` - документация OpenAPI

## Интеграции

- **C20.1 (GitOps Core)**: получение файлов по коммиту
- **C17.1 (Skill Registry)**: проверка существования навыков
- **C17.4 (Skill Tester)**: функциональное тестирование навыков
- **BR18 (Monitoring)**: логирование результатов тестов
