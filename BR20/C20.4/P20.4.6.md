
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P20.4.6 (LEVEL 5)

**ID:** P20.4.6  
**Контейнер:** C20.4 (Test Runner)  
**Название:** Логирование в BR18  

**Зависимости:** P20.4.5

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить отправку логов о всех запусках тестов и их результатах в центральный лог-агрегатор BR18 (C18.1). Это обеспечит наблюдаемость работы Test Runner и позволит анализировать стабильность конфигураций.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Адрес BR18:** переменная окружения `BR18_URL` (по умолчанию `http://br18:8080/api/logs`).  
- **Формат лога:**  
  ```json
  {
    "timestamp": "ISO 8601",
    "service": "C20.4",
    "event_type": "test_run | test_completed | test_failed",
    "details": {
      "test_id": "tst_789",
      "repo": "skills",
      "commit": "abc123",
      "tests_requested": ["syntax", "semantic"],
      "passed": true,
      "summary": { "total": 10, "passed": 9, "failed": 1 }
    }
  }
  ```  
- **События для логирования:**  
  – Начало тестового прогона.  
  – Завершение (с итоговым статусом).  
  – Ошибки в процессе.  
- **Асинхронность:** отправка через `BackgroundTasks`.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Добавить функцию `send_log(event_type, details, background_tasks)`.  
- В эндпоинте `POST /test` при старте задачи отправлять лог.  
- В фоновой задаче после завершения отправлять лог с результатами.  
- При ошибках – соответствующий лог.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При каждом запуске тестов отправляется лог в BR18.  
- При завершении отправляется лог с результатами.  
- Отправка не блокирует основной процесс.  
- При недоступности BR18 ошибка логируется локально.
