### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P20.3.1 (LEVEL 5)

**ID:** P20.3.1  
**Контейнер:** C20.3 (Rollback Manager)  
**Название:** Базовая структура и хранение истории  

**Зависимости:** отсутствуют

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Создать FastAPI-приложение для управления откатами конфигураций. Реализовать приём уведомлений от Auto Deployer (C20.2) об успешных деплоях и сохранение информации о них в локальной SQLite-базе данных. Это позволит в дальнейшем использовать эту историю для откатов.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Стек:** Python + FastAPI, SQLite, Uvicorn.  
- **Порт:** 8107 (настраивается через переменную окружения `PORT`).  
- **База данных:** файл `/data/rollback.db` (монтируемый том).  
- **Таблица `deploy_history`:**  
  - `id` INTEGER PRIMARY KEY AUTOINCREMENT  
  - `deploy_id` TEXT – уникальный идентификатор деплоя (из C20.2)  
  - `repo` TEXT – имя репозитория  
  - `commit` TEXT – хеш коммита (или тег)  
  - `environment` TEXT – окружение (например, `staging`)  
  - `timestamp` TEXT (ISO 8601)  
  - `status` TEXT – `success` (пока только успешные)  
  - `files_snapshot` TEXT – JSON-слепок файлов (опционально, для быстрого восстановления)  
- **Эндпоинт для приёма уведомлений:**  
  - `POST /api/deploy/notify` – принимает JSON от C20.2:  
    ```json
    {
      "deploy_id": "dep_123",
      "repo": "skills",
      "commit": "abc123",
      "environment": "staging",
      "timestamp": "2026-03-18T12:00:00Z"
    }
    ```  
    Сохраняет запись в БД.  
- **Валидация:** проверка обязательных полей, при ошибке – 400.  
- **Локальное логирование:** файл `01_ЦЕХ/01_ЖУРНАЛЫ/rollback_manager.log`.  
- **Эндпоинт /health** – возвращает `{"status": "ok"}`.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Создать файл `rollback_manager.py` с FastAPI-приложением.  
- При старте инициализировать БД (создать таблицу, если её нет).  
- Добавить эндпоинт `POST /api/deploy/notify`.  
- В функции эндпоинта выполнить вставку в БД.  
- Добавить `/health`.  
- Настроить логирование.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- Приложение запускается на порту 8107.  
- При отправке корректного уведомления данные сохраняются в БД.  
- При неполных данных – 400.  
- Локальный лог содержит записи о полученных уведомлениях.  
- Эндпоинт `/health` отвечает `{"status": "ok"}`.
