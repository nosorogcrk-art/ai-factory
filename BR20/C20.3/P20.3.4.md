
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P20.3.4 (LEVEL 5)

**ID:** P20.3.4  
**Контейнер:** C20.3 (Rollback Manager)  
**Название:** Автоматический откат по сигналу BR18  

**Зависимости:** P20.3.3

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить возможность автоматического отката при получении сигнала от Alert Manager (C18.3) о критической ошибке после деплоя. Сигнал должен содержать ID деплоя. При получении такого сигнала автоматически создаётся задача отката (аналогично ручному) и запускается.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Эндпоинт для приёма сигналов:**  
  - `POST /api/alert` – принимает JSON от BR18:  
    ```json
    {
      "alert_id": "alert_123",
      "severity": "high",
      "message": "Errors after deployment",
      "details": {
        "deploy_id": "dep_123"
      }
    }
    ```  
  - Валидация: наличие `details.deploy_id`.  
- **Действия:**  
  1. Проверить, существует ли деплой с таким ID в истории.  
  2. Создать задачу отката (аналогично ручному) с причиной `auto: alert_{alert_id}`.  
  3. Вернуть `202 Accepted` с `rollback_id`.  
- **Логирование:** все полученные сигналы логируются.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Добавить эндпоинт `POST /api/alert`.  
- В функции проверить наличие деплоя, создать запись в `rollback_jobs` со статусом `pending`.  
- Фоновая задача из P20.3.3 подхватит её.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При отправке корректного сигнала создаётся задача отката.  
- При неверном `deploy_id` возвращается ошибка.  
- Логирование работает.  
- Задача обрабатывается фоновым процессом.
