
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P20.3.5 (LEVEL 5)

**ID:** P20.3.5  
**Контейнер:** C20.3 (Rollback Manager)  
**Название:** Логирование и история  

**Зависимости:** P20.3.4

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить отправку логов о всех значимых событиях (создание задачи отката, успех, ошибка) в центральный лог-агрегатор BR18 (C18.1). Также реализовать эндпоинт для получения истории откатов и деплоев.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Адрес BR18:** переменная окружения `BR18_URL` (по умолчанию `http://br18:8080/api/logs`).  
- **Формат лога:**  
  ```json
  {
    "timestamp": "ISO 8601",
    "service": "C20.3",
    "event_type": "rollback_created | rollback_succeeded | rollback_failed | alert_received",
    "details": { ... }
  }
  ```  
- **События для логирования:**  
  – Создание задачи отката (ручное или автоматическое).  
  – Успешное завершение отката.  
  – Ошибка отката.  
  – Получение сигнала от BR18.  
- **Эндпоинт для истории:**  
  - `GET /api/history` – возвращает список последних N откатов (из `rollback_jobs`).  
  - Опциональные параметры: `deploy_id`, `environment`, `status`.  
- **Асинхронность:** отправка логов через `BackgroundTasks`.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Добавить функцию `send_log(event_type, details, background_tasks)`.  
- Вызывать её в эндпоинтах создания отката и в фоновой задаче при завершении.  
- Добавить эндпоинт `GET /api/history` для чтения из БД.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При создании задачи отката отправляется лог.  
- При завершении отката (успех/ошибка) отправляется лог.  
- При получении сигнала от BR18 отправляется лог.  
- Эндпоинт `/api/history` возвращает корректную историю.  
- Отправка логов асинхронна.
