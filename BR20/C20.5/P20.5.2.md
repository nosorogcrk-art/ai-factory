
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P20.5.2 (LEVEL 5)

**ID:** P20.5.2  
**Контейнер:** C20.5 (Environment Manager)  
**Название:** Предоставление параметров для деплоя  

**Зависимости:** P20.5.1

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить эндпоинт для получения параметров окружения по имени, который будет использоваться Auto Deployer (C20.2) при выполнении деплоя. Также реализовать возможность инициировать деплой в конкретное окружение через вызов C20.2.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Новые эндпоинты:**  
  - `GET /environments/{name}/params` – возвращает только параметры окружения (объект `params`) для быстрого доступа (без `targets` и метаданных).  
  - `POST /environments/{name}/deploy` – инициирует деплой в указанное окружение. Принимает опциональное тело с параметрами деплоя (например, `{ "repo": "skills", "branch": "main" }`).  
    – Внутри вызывает API C20.2: `POST /deploy` с переданными параметрами и окружением.  
    – Адрес C20.2 задаётся переменной окружения `AUTO_DEPLOYER_URL` (по умолчанию `http://c20.2:8106`).  
    – Возвращает ответ от C20.2 (например, `{ "deploy_id": "dep_123", "status": "started" }`).  
- **Интеграция:**  
  – При вызове `/deploy` необходимо передать в C20.2 дополнительное поле `environment` со значением `name`.  
- **Обработка ошибок:**  
  – Если окружение не найдено – 404.  
  – Если C20.2 недоступен – 503.  
- **Логирование:** все вызовы логируются локально.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Добавить эндпоинт `GET /environments/{name}/params`, который возвращает только поле `params` из записи в БД.  
- Добавить эндпоинт `POST /environments/{name}/deploy`, который:  
  1. Проверяет существование окружения.  
  2. Формирует запрос к C20.2, добавляя `environment: name`.  
  3. Отправляет асинхронный POST-запрос к C20.2.  
  4. Возвращает ответ.  
- Обрабатывать ошибки сети и таймауты.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- `GET /environments/{name}/params` возвращает корректный JSON с параметрами.  
- `POST /environments/{name}/deploy` вызывает C20.2 и возвращает его ответ.  
- При несуществующем окружении – 404.  
- При недоступности C20.2 – 503.  
- Логирование работает.
