
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P19.3.4 (LEVEL 5)

**ID:** P19.3.4  
**Контейнер:** C19.3 (Skill Updater)  
**Название:** Применение изменений и тестирование  

**Зависимости:** P19.3.3

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
После генерации предложений необходимо применить их к навыку, создав новую версию через C17.2 (Skill Version Control), и протестировать обновлённый навык через C17.4 (Skill Tester). Если тесты успешны, новая версия может быть опубликована.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Применение изменений:**  
  – Сформировать новое содержимое навыка на основе текущей инструкции и предложений.  
  – Вызвать API C17.2 для создания коммита: `POST /commit/{skill_id}` с телом, содержащим обновлённый JSON навыка и сообщение коммита (например, "Auto-update based on error analysis").  
- **Тестирование:**  
  – После создания коммита (или новой версии) вызвать C17.4 для тестирования: `POST /test/{skill_id}` (или `POST /test` с ID навыка).  
  – Дождаться результата (можно асинхронно, периодически опрашивая статус).  
  – Если тест пройден успешно, можно обновить статус навыка в C17.1 на `active` (если он был `draft`).  
- **Хранение:**  
  – В записи задачи сохранить информацию о созданном коммите (хеш) и результате теста.  
- **Асинхронность:** все шаги выполняются в фоновой задаче.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- В фоновой задаче после генерации предложений:  
  1. Получить текущий навык из контекста.  
  2. Применить предложения к инструкции (простая конкатенация или более сложная логика).  
  3. Вызвать C17.2 для создания коммита.  
  4. Вызвать C17.4 для тестирования.  
  5. Если тест успешен, опционально обновить статус в C17.1 через `PATCH /skills/{id}`.  
  6. Сохранить результаты в БД, обновить статус задачи на `completed` или `failed`.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При успешном применении создаётся новый коммит в C17.2.  
- Запускается тестирование, результат сохраняется.  
- Если тест пройден, навык может быть активирован.  
- При ошибке на любом этапе задача помечается как `failed`.
