
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P19.1.3 (LEVEL 5) – ИСПРАВЛЕННАЯ

**ID:** P19.1.3  
**Контейнер:** C19.1 (Log Analyzer)  
**Название:** Выявление паттернов и статистика  

**Зависимости:** P19.1.2

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить анализ частотных паттернов и статистику: выявление часто встречающихся последовательностей событий, расчёт метрик (среднее время выполнения, частота ошибок) в разрезе кластеров, агентов, навыков. Результаты сохраняются в отчёте. Все вычисления выполняются асинхронно в рамках уже запущенной задачи анализа.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Дополнительные источники:**  
  – Метрики из C18.2 (например, `GET /api/metrics/history`) за тот же период.  
  – Данные из C18.4 для связывания логов с сущностями (навыки, задачи) – могут использоваться для уточнения статистики.  
- **Анализ:**  
  – Для каждого кластера ошибок вычислить статистику: количество, доля от всех ошибок, среднее время выполнения задач, приведших к ошибке.  
  – Поиск частых последовательностей событий (например, `handover_initiated → handover_failed`) с помощью алгоритма PrefixSpan или простого подсчёта пар.  
  – Сохранение результатов в таблицу `patterns`.  
- **Асинхронность:** все дополнительные запросы к внешним сервисам выполняются асинхронно (через `httpx`), но в рамках той же фоновой задачи.  
- **Хранение:** результаты дополняют существующий отчёт (можно создать отдельную таблицу `analysis_results` с JSON-полем).  
- **API:**  
  – `GET /reports/{id}/statistics` – возвращает статистику по отчёту.  
  – `GET /patterns` – возвращает список выявленных паттернов (глобально или с фильтром по отчёту).  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- В фоновой задаче после кластеризации выполнить:  
  1. Запросить метрики из C18.2 (асинхронно).  
  2. Запросить данные из C18.4 для обогащения (если доступно).  
  3. Вычислить статистику и паттерны.  
  4. Сохранить в БД.  
- Использовать `asyncio` для параллельных запросов к внешним API.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- В отчёте появляются статистические данные.  
- Паттерны (последовательности) обнаруживаются и сохраняются.  
- API возвращает корректные данные.  
- При недоступности C18.2 или C18.4 задача продолжается с предупреждением (статистика по этим источникам пропускается).
