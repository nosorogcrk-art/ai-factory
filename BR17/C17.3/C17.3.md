### 📄 ПАСПОРТ КОНТЕЙНЕРА C17.3: SKILL GRAPH (ГРАФ НАВЫКОВ)

**Ветка-родитель:** BR17 | **ID:** C17.3 | **Ответственный:** ДЕДАЛ

**1. ФУНКЦИОНАЛЬНОЕ ПРЕДНАЗНАЧЕНИЕ**  
Построение и поддержание графа зависимостей между навыками на основе метаданных из реестра навыков (C17.1). Предоставляет API для получения структуры зависимостей, проверки наличия циклов, поиска всех зависимостей конкретного навыка, а также экспорта полного графа для визуализации.

**2. ТЕХНИЧЕСКАЯ ЛОГИКА (МЕХАНИКА)**  
- **Источник данных:** периодический опрос C17.1 (GET /skills).  
- **Граф в памяти:** outgoing/incoming индексы, метаданные.  
- **API:** эндпоинты /graph, /graph/{id}, /dependencies, /reverse-dependencies, /cycle-check.  
- **Логирование:** локальный файл skill_graph.log, отправка в BR18 при обнаружении циклов.

**3. ИНТЕГРАЦИИ**  
- C17.1 (Skill Registry) – получение данных.  
- BR18 – отправка логов.  
- C4.2 – визуализация графа.

**4. СТЕК ТЕХНОЛОГИЙ**  
- Python + FastAPI, httpx, asyncio.

**5. СПИСОК ПАТЧЕЙ**  
- P17.3.1 – инициализация и загрузка данных.  
- P17.3.2 – построение графа и базовые запросы.  
- P17.3.3 – транзитивные и обратные зависимости.  
- P17.3.4 – проверка циклов и логирование.
