
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P17.3.4 (LEVEL 5)

**ID:** P17.3.4  
**Контейнер:** C17.3 (Skill Graph)  
**Название:** Проверка циклов и логирование  

**Зависимости:** P17.3.3

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить возможность обнаружения циклов в графе зависимостей навыков и отправку соответствующих уведомлений в BR18. Циклические зависимости делают навыки непригодными для использования, поэтому необходимо их выявлять и сообщать об этом. Также добавить эндпоинт для проверки наличия циклов по запросу.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Эндпоинт:**  
  - `GET /cycle-check` – проверяет наличие циклов в текущем графе и возвращает список найденных циклов.  
  - Ответ:  
    ```json
    {
      "has_cycles": true,
      "cycles": [
        ["SKILL-001", "SKILL-042", "SKILL-001"],
        ...
      ]
    }
    ```  
  - Если циклов нет: `{ "has_cycles": false, "cycles": [] }`.  

- **Алгоритм обнаружения циклов:**  
  - Для каждого узла выполнить поиск в глубину с раскраской (0 – не посещён, 1 – в процессе, 2 – обработан).  
  - При обнаружении ребра в узел со статусом 1 фиксируется цикл.  

- **Логирование в BR18:**  
  – При каждом обнаружении цикла (как при периодической проверке, так и при вызове эндпоинта) отправлять событие в **BR18 (C18.1 Log Aggregator)**.  
  – Формат лога:  
    ```json
    {
      "timestamp": "...",
      "service": "C17.3",
      "event_type": "cycle_detected",
      "details": {
        "cycle": ["SKILL-001", "SKILL-042", "SKILL-001"]
      }
    }
    ```  
  – Также логировать успешное завершение проверки (без циклов) по желанию.  

- **Периодическая проверка:** можно добавить фоновую задачу, которая раз в час выполняет проверку и при обнаружении циклов отправляет алерт (но это может быть позже). Пока реализуем только по запросу.  

- **Интеграция с BR18:** использовать тот же механизм, что и в других патчах (асинхронная отправка).  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Реализовать функцию `detect_cycles()`, которая обходит `outgoing` и возвращает список циклов.  
- Добавить эндпоинт `/cycle-check`, вызывающий эту функцию.  
- В функции отправки логов использовать `BackgroundTasks`.  
- Если циклы найдены, отправить лог в BR18.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При наличии цикла в графе эндпоинт `/cycle-check` возвращает список циклов.  
- При отсутствии циклов возвращает `"has_cycles": false`.  
- При обнаружении цикла отправляется лог в BR18.  
- Логирование работает, ошибки отправки не ломают эндпоинт.
