### 📄 ПАСПОРТ ВЕТКИ BR17: ХРАНИЛИЩЕ НАВЫКОВ (SKILLS REPOSITORY)

**ID:** BR17  
**Ответственный:** [назначить]  
**Замысел:** Централизованное хранение, версионирование и управление навыками (Skills) агентов. Каждый навык представляет собой формализованное описание способа выполнения конкретной задачи (инструкции, примеры, требования, зависимости). Репозиторий обеспечивает повторное использование лучших практик, быстрое обучение новых агентов и эволюцию знаний завода.  

**Границы:**  
- **Отвечает за:**  
  – Реестр всех навыков с их метаданными (ID, версия, описание, автор, дата создания, статус).  
  – Версионирование навыков через интеграцию с Git (хранение истории изменений, возможность отката).  
  – Построение и поддержание графа зависимостей между навыками (какие навыки от каких зависят, какие конфликтуют).  
  – Автоматическое тестирование навыков в изолированной песочнице для подтверждения их работоспособности.  
  – Публикацию навыков для использования агентами через API (выдача по запросу с учётом прав доступа).  
  – Индексацию навыков в семантической памяти (BR2) для поиска по смыслу.  
- **Не занимается:**  
  – Логикой выполнения задач (это задача агентов).  
  – Обучением людей (BR8).  
  – Синхронизацией навыков между разными экземплярами заводов (это задача BR11).  

**Валидация:**  
- Любой агент может запросить список навыков и получить актуальную версию с корректными метаданными.  
- Каждый новый навык проходит автоматическое тестирование (C17.4) перед публикацией; процент успешных прохождений не ниже 95%.  
- Граф зависимостей (C17.3) не содержит циклических ссылок; все зависимости разрешимы.  
- Время ответа API публикации навыков (C17.5) не превышает 500 мс при стандартной нагрузке.  

**СОСТАВ УЗЛОВ (L3):**  

- **C17.1: Skill Registry.**  
  Реестр всех навыков с метаданными: уникальный идентификатор, название, версия, описание, автор, дата создания, статус (черновик/активен/устарел), теги, ссылки на связанные патчи. Обеспечивает CRUD-операции над записями.

- **C17.2: Skill Version Control.**  
  Интеграция с Git (или аналогичной системой) для хранения истории изменений навыков. Каждый навык хранится как отдельный файл (например, в формате Markdown с YAML-шапкой) в репозитории. Позволяет просматривать изменения, сравнивать версии, выполнять откат.

- **C17.3: Skill Graph.**  
  Построение и поддержание графа зависимостей между навыками. Анализирует содержимое навыков (например, раздел «Зависимости») и создаёт направленный граф. Используется агентами для понимания контекста и планирования выполнения сложных задач. Интегрируется с BR2 для семантического поиска по графу.

- **C17.4: Skill Tester.**  
  Автоматическая проверка навыков в изолированной среде (песочнице). Для каждого навыка запускается набор тестовых сценариев, имитирующих реальные условия. Результаты тестирования сохраняются и влияют на статус навыка. При обнаружении ошибок уведомляет Дедала (BR1) через BR18.

- **C17.5: Skill Publisher.**  
  API для выдачи навыков агентам по запросу. Учитывает версию навыка, права доступа агента (интеграция с BR7) и контекст задачи. Поддерживает пакетную выдачу нескольких навыков, кэширование для повышения производительности. Логирует все запросы в BR18 для последующего анализа.
