### **C17.2: Skill Version Control (Версионирование навыков)**

**Ветка-родитель:** BR17 | **ID:** C17.2 | **Ответственный:** ДЕДАЛ

**1. ФУНКЦИОНАЛЬНОЕ ПРЕДНАЗНАЧЕНИЕ**  
Обеспечение хранения истории изменений навыков в Git-репозитории, возможность просмотра истории, сравнения версий и отката к предыдущим состояниям. Предоставляет API для выполнения Git-операций. Все действия логируются в BR18.

**2. ТЕХНИЧЕСКАЯ ЛОГИКА (МЕХАНИКА)**  
- **Хранение:** Git-репозиторий в `/data/skills-repo`.  
- **API:** эндпоинты `/commit`, `/history`, `/file`, `/diff`, `/rollback`, `/health`.  
- **Логирование:** локальный файл `skill_version_control.log` и отправка в BR18.  
- **Тесты:** pytest с моками GitPython.  

**3. ИНТЕГРАЦИИ**  
- C17.1 – для получения данных навыка.  
- BR18 – отправка логов.  

**4. СТЕК ТЕХНОЛОГИЙ**  
- Python + FastAPI, GitPython, httpx, Docker.  

**5. СПИСОК ПАТЧЕЙ**  
- P17.2.1 – инициализация репозитория.  
- P17.2.2 – базовые операции с коммитами.  
- P17.2.3 – diff и rollback.  
- P17.2.4 – логирование в BR18.
