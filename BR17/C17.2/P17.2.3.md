
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P17.2.3 (LEVEL 5)

**ID:** P17.2.3  
**Контейнер:** C17.2 (Skill Version Control)  
**Название:** Diff и rollback  

**Зависимости:** P17.2.2

---

#### 1. ЗАМЫСЕЛ ПАТЧА
Добавить возможность сравнения двух версий файла навыка (diff) и отката к предыдущей версии (rollback). Это необходимо для анализа изменений и восстановления состояния навыка при ошибках.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ

- **Эндпоинты:**
  - `GET /diff/{skill_id}?from=<hash>&to=<hash>` – возвращает diff между двумя версиями.
    - Параметры: `from` и `to` – хеши коммитов (или теги).
    - Возвращает строку с unified diff (как выводит `git diff`).
    - Если одна из версий не найдена – 404.
  - `POST /rollback/{skill_id}?to=<hash>` – откатывает файл к указанной версии.
    - Параметр `to` – хеш коммита.
    - Действия:
      1. Получить содержимое файла из указанного коммита.
      2. Перезаписать текущий файл этим содержимым.
      3. Создать новый коммит с сообщением вида `"Rollback to {hash}"`.
    - Возвращает `{ "new_commit_hash": "def456" }`.
- **Обработка ошибок:** аналогично предыдущему патчу.
- **Логирование:** записывать все операции.

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ

- Для `GET /diff`:
  - Использовать `repo.git.diff('--no-color', f'{from_hash}..{to_hash}', '--', file_path)`.
  - Вернуть результат.
- Для `POST /rollback`:
  - Получить коммит по `to_hash`, извлечь содержимое файла.
  - Записать это содержимое в файл.
  - Выполнить commit с сообщением о rollback.

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)

- При запросе diff с существующими хешами возвращается корректный diff.
- При rollback создаётся новый коммит с восстановленным содержимым, история сохраняется.
- При неверных хешах – 404.
- Логирование работает.
