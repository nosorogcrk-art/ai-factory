### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P17.4.3 (LEVEL 5)

**ID:** P17.4.3  
**Контейнер:** C17.4 (Skill Tester)  
**Название:** Изолированное выполнение тестов (Docker)  
**Статус:** в работе

**Зависимости:** P17.4.2

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Реализовать запуск тестов для навыка в изолированной среде (Docker-контейнер). Для каждого тестового запуска создаётся временный контейнер, в котором выполняется инструкция навыка с заданными входными данными, и собирается результат.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Инфраструктура:** контейнер C17.4 имеет доступ к Docker-сокету (`/var/run/docker.sock`).  
- **Тестовый образ:** используется базовый образ (например, `python:3.12-slim`), в который монтируются инструкции навыка и тестовые данные.  
- **Процесс тестирования:**  
  1. Для навыка создаётся временная директория, куда копируются:  
     - скрипт с инструкцией (генерируется из поля `instruction` навыка);  
     - тестовые данные (из библиотеки тестов).  
  2. Запускается Docker-контейнер с этой директорией, выполняющий команду `python script.py`.  
  3. Собирается stdout/stderr, время выполнения.  
  4. Результат сравнивается с ожидаемым.  
- **Результат:** возвращается статус теста (passed/failed), детали ошибок, время выполнения.  

---

#### 3. РЕАЛИЗАЦИЯ (L6) – ОПИСАНИЕ  

- Добавить функцию `run_test_in_docker(skill_id, test_case)`.  
- Использовать библиотеку `docker` (Docker SDK для Python).  
- В `services.start_test_real` после получения навыка запускать тестовый контейнер.  
- Сохранять результат в БД.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- [ ] При запуске теста для навыка создаётся Docker-контейнер, выполняющий инструкцию.  
- [ ] Результат (успех/неудача) возвращается в ответе.  
- [ ] Временные файлы удаляются после завершения.  
- [ ] При ошибках Docker (например, образ не найден) возвращается понятное сообщение.  
- [ ] Тесты обновлены (моки Docker).  
- [ ] Статический анализ пройден.
