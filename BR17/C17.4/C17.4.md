### 📄 ПАСПОРТ КОНТЕЙНЕРА C17.4: SKILL TESTER (ТЕСТИРОВЩИК НАВЫКОВ)

**Ветка-родитель:** BR17 | **ID:** C17.4 | **Ответственный:** ДЕДАЛ

**1. ФУНКЦИОНАЛЬНОЕ ПРЕДНАЗНАЧЕНИЕ**  
Автоматическая проверка работоспособности и качества навыков в изолированной среде. Реализованы базовая заглушка (P17.4.1), интеграция с C17.1 (P17.4.2), изолированное выполнение тестов через Docker (P17.4.3), библиотека тестов с метриками (P17.4.4) и логирование в BR18 (P17.4.5 – в работе).

**2. ТЕХНИЧЕСКАЯ ЛОГИКА (МЕХАНИКА)**  
- **API:** эндпоинты `/health`, `/status`, `/test/{skill_id}`, `/results/{skill_id}`, `/test/all`.  
- **Интеграция с C17.1:** получение метаданных навыка.  
- **Тестирование:** Docker-контейнер `python:3.12-slim` выполняет инструкцию навыка.  
- **Библиотека тестов:** поддержка нескольких тестовых кейсов (планируется).  
- **Метрики:** возвращаются в ответе `/results/{skill_id}`.  
- **Логирование:** локальный файл `skill_tester.log` и отправка в BR18.  
- **Хранение:** SQLite для результатов тестов.

**3. ИНТЕГРАЦИИ**  
- C17.1 (Skill Registry) – для получения данных навыка.  
- BR18 – отправка логов (P17.4.5).  

**4. СТЕК ТЕХНОЛОГИЙ**  
- Python + FastAPI.  
- SQLite, httpx, Docker SDK for Python.  
- Docker (контейнер с доступом к сокету).
