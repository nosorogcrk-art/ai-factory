# C0.5 System Mapper

Контейнер для автоматического построения и предоставления машиночитаемой карты завода.

## Функциональность

- Сканирование паспортов веток (`BR*/BR*.md`)
- Сканирование паспортов контейнеров (`BR*/C*/C*.md`)
- Сканирование спецификаций патчей (`BR*/C*/P*.md`)
- Построение JSON-карты (`SYSTEM_MAP.json`)
- REST API для доступа к карте

## API

| Эндпоинт | Метод | Описание |
|----------|-------|----------|
| `/health` | GET | Проверка работоспособности |
| `/map` | GET | Полная карта завода (параметр `refresh=true` для принудительного обновления) |
| `/branches` | GET | Список веток |
| `/containers` | GET | Список контейнеров |
| `/patches` | GET | Список патчей |
| `/stats` | GET | Статистика завода |

## Переменные окружения

| Переменная | Значение по умолчанию | Описание |
|------------|-----------------------|----------|
| `PORT` | 8098 | Порт, на котором запускается сервис |
| `BR18_URL` | `http://br18:8080/api/logs` | Адрес для отправки логов (опционально) |
| `ENABLE_BR18` | `false` | Включить отправку логов в BR18 |

## Запуск

```bash
docker build -t system-mapper .
docker run -p 8098:8098 -v $(pwd):/app system-mapper
