### **C0.5: System Mapper**

**Ветка-родитель:** BR0 | **ID:** C0.5 | **Ответственный:** ГЕРМЕС

**1. ФУНКЦИОНАЛЬНОЕ ПРЕДНАЗНАЧЕНИЕ**  
Построение машиночитаемой карты завода, карты портов и веб-интерфейса для управления.

**2. ТЕХНИЧЕСКАЯ ЛОГИКА (МЕХАНИКА)**  
- **API:**  
  - `GET /map` – карта завода (ветки, контейнеры, патчи).  
  - `GET /ports` – карта портов (запущенные контейнеры, порты, healthcheck).  
  - `GET /view` – единый пульт управления (HTML/JS).  
  - `GET /health` – healthcheck.  
- **Порты:** собирает данные через Docker API (сокет) и паспорта контейнеров.  
- **Логирование:** локальный файл + BR18.

**3. ИНТЕГРАЦИИ**  
- BR18 – логи.  
- Docker – через `/var/run/docker.sock`.

**4. СТЕК ТЕХНОЛОГИЙ**  
- Python + FastAPI, статика.  
- PyYAML, httpx, subprocess (docker ps).
