# СПЕЦИФИКАЦИЯ ПАТЧА P0.5.5 (L5)

**ID:** P0.5.5  
**Контейнер:** C0.5 (System Mapper)  
**Название:** Добавление человеко-читаемой веб-страницы карты завода  
**Статус:** проект

---

## 1. Цель
Добавить в System Mapper веб-страницу, которая отображает карту завода в удобном для человека виде (таблицы, статистика, цветовая индикация), доступную по эндпоинту `/view`.

---

## 2. Технические параметры

### 2.1. Модифицируемые файлы
- `BR0/C0.5/main.py` – добавить эндпоинт `/view`, подключить статику.
- `BR0/C0.5/static/index.html` – создать файл с HTML/JS для отображения карты.
- `BR0/C0.5/Dockerfile` – скопировать папку `static` в образ.

### 2.2. Новые эндпоинты
- `GET /view` – возвращает HTML-страницу.

### 2.3. Алгоритм
1. В `main.py` добавить маршрут `/view`, который читает файл `static/index.html` и возвращает его как HTML.
2. Подключить статику через `app.mount("/static", StaticFiles(directory="static"), name="static")` (опционально, если понадобятся отдельные CSS/JS файлы).
3. В HTML через `fetch('/map')` загружать JSON и динамически строить таблицы.

---
