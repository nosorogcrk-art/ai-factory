# C0.1 - Оркестратор среды (Гермес)

## Описание
Контейнер для управления Docker-контейнерами завода. Обеспечивает запуск, остановку, перезапуск и мониторинг состояния контейнеров.

## Функциональность

### Основные возможности
- Управление Docker-контейнерами (запуск, остановка, перезапуск)
- Получение статуса контейнеров (running, stopped, unhealthy)
- Мониторинг доступности Docker демона
- Логирование действий в BR18
- Healthcheck самого сервиса

### API эндпоинты
- `GET /health` - проверка состояния сервиса
- `GET /containers` - список всех контейнеров
- `GET /containers/{name}/status` - статус конкретного контейнера
- `POST /containers/{name}/start` - запуск контейнера
- `POST /containers/{name}/stop` - остановка контейнера
- `POST /containers/{name}/restart` - перезапуск контейнера

## Технические детали

### Архитектура
- FastAPI приложение на Python 3.12
- Использование Docker API через subprocess
- Асинхронное логирование в BR18
- Healthcheck с проверкой Docker демона

### Зависимости
- Python 3.12
- Docker CLI (доступ к Docker демону)

## Развертывание

### Docker образ
```bash
docker build -t orchestrator .
docker run -p 8100:8100 -v /var/run/docker.sock:/var/run/docker.sock orchestrator
```

### Docker Compose
Сервис `orchestrator` уже добавлен в `docker-compose.yml`:
```yaml
orchestrator:
  build: ./BR0/C0.1
  ports:
    - "8100:8100"
  networks:
    - factory-net
  volumes:
    - /var/run/docker.sock:/var/run/docker.sock
    - ./01_ЦЕХ:/app/01_ЦЕХ
  environment:
    - BR18_URL=http://log-aggregator:8093/api/logs
  healthcheck:
    test: ["CMD", "curl", "-f", "http://localhost:8100/health"]
    interval: 30s
    timeout: 5s
    retries: 3
```
