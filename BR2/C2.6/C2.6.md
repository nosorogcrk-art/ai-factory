#### 1. ФУНКЦИОНАЛЬНОЕ ПРЕДНАЗНАЧЕНИЕ

Управление изолированной памятью для каждого разрабатываемого проекта **и глобальной памятью завода**. Обеспечивает:

- Хранение диалогов, артефактов (патчи, спецификации, код) для проектов.
- **Глобальную индексацию документов завода** (паспортов веток, контейнеров, спецификаций патчей, L2) через эндпоинт `/index`.
- **Глобальный семантический поиск** по всем проиндексированным документам завода через эндпоинт `/search`.
- Семантический поиск по данным проекта (`/projects/{id}/search`).
- Переносимость проекта между экземплярами завода путём копирования папки.

---

#### 2. ТЕХНИЧЕСКАЯ ЛОГИКА (МЕХАНИКА)

**Хранение проектов:**
- Корневая папка: `01_ЦЕХ/ПРОЕКТЫ/`.
- Каждый проект: `01_ЦЕХ/ПРОЕКТЫ/{project_id}/`
  - `metadata.json` – название, даты, статус (active, archived).
  - `artifacts/` – файлы артефактов (патчи, спецификации, код).
  - `vector_index/` – файлы векторной БД (Chroma) для проекта.
- SQLite для метаданных (проекты, сообщения, артефакты) с индексами.

**Глобальная память завода:**
- Отдельная коллекция Chroma: `factory_docs`.
- Эндпоинт `POST /index`:
  - Принимает список путей к файлам.
  - Проверяет существование файла, размер ≤ 10 МБ.
  - Читает содержимое (UTF-8).
  - Генерирует эмбеддинг через `SentenceTransformer('all-MiniLM-L6-v2')`.
  - Сохраняет в коллекцию `factory_docs` с метаданными: `path`, `filename`, `size`, `timestamp`, `type` (markdown, json, code).
- Эндпоинт `POST /search`:
  - Принимает `query` и `limit`.
  - Возвращает результаты из `factory_docs` с оценкой релевантности (score = 1 - distance) и сниппетом (первые 200 символов).

**Векторный индекс (Chroma) для проектов:**
- Для каждого проекта создаётся отдельная коллекция.
- При добавлении сообщения или артефакта автоматически генерируется эмбеддинг и сохраняется.

**API (внутренний):**
- `POST /projects` – создать проект.
- `GET /projects` – список проектов.
- `GET /projects/{id}` – метаданные проекта.
- `POST /projects/{id}/messages` – добавить сообщение (индексируется).
- `GET /projects/{id}/messages` – история сообщений.
- `POST /projects/{id}/artifacts` – добавить артефакт (сохраняет файл, индексирует).
- `POST /projects/{id}/search` – семантический поиск по проекту.
- `DELETE /projects/{id}` – мягкое удаление.
- **`POST /index`** – глобальная индексация документов завода.
- **`POST /search`** – глобальный семантический поиск.

**Логирование:**
- Локальный файл: `01_ЦЕХ/01_ЖУРНАЛЫ/project_memory.log`.
- Асинхронная отправка в BR18 (через `BackgroundTasks`).

**Healthcheck:** `GET /health` → `{"status": "ok"}`.
