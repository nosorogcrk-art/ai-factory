# СПЕЦИФИКАЦИЯ ПАТЧА P2.6.7 (L5)

**ID:** P2.6.7  
**Контейнер:** C2.6 (Project Memory)  
**Название:** Логирование в BR18 и локальный файл

## 1. Цель
Добавить отправку логов о создании/обновлении проектов, добавлении сообщений, артефактов, ошибках в BR18, а также запись в локальный файл.

## 2. Технические параметры
- **Модифицируемые файлы:** `BR2/C2.6/main.py`, `BR2/C2.6/services.py`
- **Локальный лог:** файл `01_ЦЕХ/01_ЖУРНАЛЫ/project_memory.log` (создаётся автоматически).
- **Отправка в BR18:** использовать `BackgroundTasks` для асинхронной отправки.
- **Формат лога (BR18):** `{ "timestamp": "...", "service": "C2.6", "event_type": "project_created|message_added|artifact_added|error", "details": { "project_id": "...", "name": "..." } }`
- **Адрес BR18:** из переменной окружения `BR18_URL` (по умолчанию `http://br18:8080/api/logs`).

## 3. Требования к коду
- [ ] В каждом эндпоинте после успешной операции вызывать отправку лога.
- [ ] При ошибках отправлять лог с `event_type: "error"` и деталями.
- [ ] Использовать стандартный модуль `logging` для записи в файл.

## 4. Тесты
- [ ] Юнит-тест: проверка, что функция отправки лога вызывается (мок).
- [ ] Интеграционный тест: проверка, что при создании проекта лог записывается в файл.

## 5. Критерии приёмки (DoD)
- [ ] Локальный файл `project_memory.log` создаётся и содержит записи.
- [ ] В логах контейнера видны отправки в BR18.
- [ ] При недоступности BR18 ошибка не влияет на ответ.
