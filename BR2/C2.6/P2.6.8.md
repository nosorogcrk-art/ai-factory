# СПЕЦИФИКАЦИЯ ПАТЧА P2.6.8 (L5)

**ID:** P2.6.8  
**Контейнер:** C2.6 (Project Memory)  
**Название:** Дополнение тестов

## 1. Цель
Дописать недостающие юнит‑ и интеграционные тесты для покрытия ключевых функций и эндпоинтов.

## 2. Технические параметры
- **Тестируемые функции (юнит-тесты):**
  1. `create_project_service` – проверка создания проекта и уникальности имени.
  2. `add_message_service` – проверка добавления сообщения.
  3. `add_artifact_service` – проверка создания артефакта и записи файла.
  4. `search_project_service` – проверка семантического поиска (мок Chroma).
  5. `recover_projects` – проверка восстановления проектов из файловой системы.
- **Интеграционные тесты (TestClient):**
  1. `POST /projects` – создание, дубликат имени.
  2. `POST /projects/{id}/messages` – успех, несуществующий проект.
  3. `POST /projects/{id}/artifacts` – успех, ошибка при отсутствии папки.
  4. `GET /projects/{id}/search` – успех, пустой результат.
  5. `DELETE /projects/{id}/artifacts/{artifact_id}` – удаление артефакта.
- **Инструменты:** `pytest`, `pytest-mock`, `fastapi.testclient.TestClient`.

## 3. Требования к коду
- [ ] Тесты размещены в `BR2/C2.6/tests/test_services.py` и `test_api.py`.
- [ ] Использовать моки для внешних вызовов (Chroma, BR18).
- [ ] Проверять, что при ошибках возвращаются корректные HTTP-статусы.

## 4. Критерии приёмки (DoD)
- [ ] Все тесты проходят.
- [ ] Покрытие ключевых функций не менее 80% (проверять через `pytest --cov`).
- [ ] Написано не менее 5 новых тестов (в сумме юнит+интеграционные).
