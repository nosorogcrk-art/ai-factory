
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P2.5.2 (LEVEL 5)

**ID:** P2.5.2  
**Контейнер:** C2.5 (Source Quality Filter)  
**Название:** REST API для фильтра качества

**Зависимости:** P2.5.1

---

#### 1. ЗАМЫСЕЛ ПАТЧА
Создать HTTP-сервис на базе FastAPI, который предоставляет эндпоинт `/check` для внешнего вызова (в первую очередь от C2.4). Сервис использует функцию `check_source` из базового модуля, оборачивает её в REST API с валидацией входных данных через Pydantic.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ

- **Фреймворк:** FastAPI + Uvicorn.
- **Порт:** 8085 (настраивается через переменную окружения `PORT`).
- **Модели Pydantic:**
  - `SourceCheckRequest` – с полями, соответствующими структуре запроса (см. паспорт C2.5). Все поля опциональны, но в зависимости от `type` некоторые становятся обязательными (проверка вручную или через discriminated union).
  - `SourceCheckResponse` – поля `allowed: bool`, `reason: Optional[str]`.
- **Эндпоинт:** `POST /check` – принимает JSON, валидирует, вызывает `check_source`, возвращает ответ.
- **Обработка ошибок:**
  - При отсутствии поля `type` или неверном значении – 422 с пояснением.
  - При внутренней ошибке – 500 с логированием.
- **Логирование:** записывать в локальный лог-файл (`source_filter_api.log`) информацию о запросах и ошибках (уровень INFO/ERROR).

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ
- Создать файл `main.py` (или `api.py`).
- Импортировать `check_source` из `source_filter`.
- Определить Pydantic-модели с валидаторами (например, проверка формата даты).
- Реализовать эндпоинт `/check`, который:
  - Принимает запрос;
  - Преобразует даты из строк в объекты `datetime` при необходимости;
  - Вызывает `check_source`;
  - Возвращает JSON-ответ.
- Добавить эндпоинт `/health` для проверки работоспособности.
- Запуск сервера через `uvicorn.run` или командную строку.

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)
- Приложение запускается и отвечает на `POST /check`.
- При корректных данных возвращается `allowed: true/false` с причиной.
- При неверных данных возвращается 422.
- Локальные логи создаются.
- Код соответствует стандартам.
