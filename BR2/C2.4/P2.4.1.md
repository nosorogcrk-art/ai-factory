
### **P2.4.1: Конфигуратор внешних источников** (LEVEL 5)

**ID:** P2.4.1  
**Контейнер:** C2.4  
**Название:** `source_config.py` – управление списком внешних источников

---

### 1. ЗАМЫСЕЛ ПАТЧА
Создание инструмента для инициализации и редактирования конфигурационного файла `sources.json`, содержащего список отслеживаемых GitHub-репозиториев и параметры фильтрации. Обеспечивает удобное добавление/удаление источников.

---

### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Директория конфигурации:** `00_КАНОН/Внешние_источники/`
- **Файл конфигурации:** `sources.json` со структурой:
  ```json
  {
    "repositories": [
      {
        "url": "https://github.com/microsoft/autogen",
        "branch": "main",
        "min_stars": 1000,
        "license_allow": ["MIT", "Apache-2.0", "BSD-3-Clause"]
      }
    ],
    "global": {
      "clone_dir": "00_ПАМЯТЬ/Внешние/",
      "update_interval_days": 7
    }
  }
  ```
- **Скрипт `source_config.py`** с функциями:
  - `init()` – создаёт папку и файл с примером конфигурации, если они отсутствуют.
  - `add_repo(url, branch, min_stars, license_allow)` – добавляет репозиторий в список.
  - `remove_repo(url)` – удаляет репозиторий.
  - `list_repos()` – выводит список.
  - Интерактивный режим при запуске без аргументов.
- **Логирование:** действия записываются в `01_ЦЕХ/01_ЖУРНАЛЫ/source_config.log`.

---

### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
source_config.py – управление конфигурацией внешних источников.
"""

import os
import json
import sys
import logging
from pathlib import Path

CONFIG_DIR = Path("00_КАНОН/Внешние_источники")
CONFIG_FILE = CONFIG_DIR / "sources.json"
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/source_config.log")

LOG_FILE.parent.mkdir(parents=True, exist_ok=True)
logging.basicConfig(filename=LOG_FILE, level=logging.INFO,
                    format='%(asctime)s - %(levelname)s - %(message)s')

DEFAULT_CONFIG = {
    "repositories": [
        {
            "url": "https://github.com/microsoft/autogen",
            "branch": "main",
            "min_stars": 1000,
            "license_allow": ["MIT", "Apache-2.0", "BSD-3-Clause"]
        }
    ],
    "global": {
        "clone_dir": "00_ПАМЯТЬ/Внешние/",
        "update_interval_days": 7
    }
}

def load_config():
    if not CONFIG_FILE.exists():
        return None
    with open(CONFIG_FILE, "r", encoding="utf-8") as f:
        return json.load(f)

def save_config(config):
    with open(CONFIG_FILE, "w", encoding="utf-8") as f:
        json.dump(config, f, indent=2, ensure_ascii=False)
    logging.info("Configuration saved.")

def init():
    CONFIG_DIR.mkdir(parents=True, exist_ok=True)
    if not CONFIG_FILE.exists():
        save_config(DEFAULT_CONFIG)
        print(f"Created default config at {CONFIG_FILE}")
    else:
        print(f"Config already exists at {CONFIG_FILE}")

def add_repo(url, branch="main", min_stars=1000, license_allow=None):
    config = load_config()
    if config is None:
        print("Config not found. Run init first.")
        return
    if license_allow is None:
        license_allow = ["MIT", "Apache-2.0", "BSD-3-Clause"]
    new_repo = {
        "url": url,
        "branch": branch,
        "min_stars": min_stars,
        "license_allow": license_allow
    }
    # Проверка на дубликат
    for repo in config["repositories"]:
        if repo["url"] == url:
            print("Repository already in list.")
            return
    config["repositories"].append(new_repo)
    save_config(config)
    print(f"Added {url}")

def remove_repo(url):
    config = load_config()
    if config is None:
        print("Config not found.")
        return
    initial_len = len(config["repositories"])
    config["repositories"] = [r for r in config["repositories"] if r["url"] != url]
    if len(config["repositories"]) < initial_len:
        save_config(config)
        print(f"Removed {url}")
    else:
        print("URL not found.")

def list_repos():
    config = load_config()
    if config is None:
        print("Config not found.")
        return
    for i, repo in enumerate(config["repositories"], 1):
        print(f"{i}. {repo['url']} (branch: {repo.get('branch','main')})")

def interactive():
    while True:
        print("\nCommands: init, add, remove, list, quit")
        cmd = input("> ").strip().lower()
        if cmd == "init":
            init()
        elif cmd == "add":
            url = input("URL: ").strip()
            branch = input("Branch [main]: ").strip() or "main"
            min_stars = int(input("Min stars [1000]: ").strip() or "1000")
            print("Allowed licenses (comma-separated) [MIT,Apache-2.0,BSD-3-Clause]:")
            lic_input = input().strip()
            license_allow = [x.strip() for x in lic_input.split(",")] if lic_input else None
            add_repo(url, branch, min_stars, license_allow)
        elif cmd == "remove":
            url = input("URL: ").strip()
            remove_repo(url)
        elif cmd == "list":
            list_repos()
        elif cmd == "quit":
            break
        else:
            print("Unknown command.")

if __name__ == "__main__":
    if len(sys.argv) == 1:
        interactive()
    elif sys.argv[1] == "init":
        init()
    elif sys.argv[1] == "add" and len(sys.argv) >= 3:
        add_repo(sys.argv[2])
    elif sys.argv[1] == "remove" and len(sys.argv) >= 3:
        remove_repo(sys.argv[2])
    elif sys.argv[1] == "list":
        list_repos()
    else:
        print("Usage: source_config.py [init|add <url>|remove <url>|list]")
```

- Интерактивный режим позволяет управлять списком.
