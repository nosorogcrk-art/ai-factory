### **C2.4: External Knowledge Collector (Сборщик внешних знаний)**

**Ветка-родитель:** BR2 | **ID:** C2.4 | **Ответственный:** МНЕМОСИНА

**1. ФУНКЦИОНАЛЬНОЕ ПРЕДНАЗНАЧЕНИЕ**  
Автоматический сбор, фильтрация и индексация материалов из внешних источников (в первую очередь GitHub), обеспечивающий пополнение базы знаний завода лучшими практиками индустрии.

**2. ТЕХНИЧЕСКАЯ ЛОГИКА (МЕХАНИКА)**  
- **Конфигурация источников:** Файл `00_КАНОН/Внешние_источники/sources.json` со списком отслеживаемых GitHub-репозиториев (например, `"microsoft/autogen"`). Параметры: URL, ветка, минимальное количество звёзд, фильтр по лицензии.  
- **Сбор данных (GitHub):**  
  - Использование GitHub API (с токеном для увеличения лимитов) для получения метаданных репозитория (звёзды, форки, последний коммит, лицензия).  
  - Клонирование репозитория (или обновление, если уже склонирован).  
  - Извлечение полезных артефактов: README, примеры кода (файлы `.py`, `.md`), issues с высоким рейтингом (опционально).  
- **Фильтрация качества:**  
  - Исключение репозиториев с лицензиями, запрещающими использование (например, AGPL, если недопустимо).  
  - Отсев репозиториев с низкими метриками: звёзды < порога, форки < порога, не обновлялся больше года.  
- **Избегание дублирования:** Для каждого репозитория сохраняется информация о последнем обработанном коммите. При следующем запуске обновляются только изменившиеся файлы.  
- **Передача в индексатор:** После извлечения текста (аналогично C2.2) данные передаются в C2.2 для индексации.  
- **Логирование:** Детальный лог всех операций с указанием обработанных репозиториев и ошибок.

**3. ВХОДЫ И ВЫХОДЫ (INTERFACES)**  
- **Input:** Конфигурация источников.  
- **Output:** Новые документы, переданные в C2.2.

**4. СТЕК ТЕХНОЛОГИЙ**  
- GitHub API (PyGithub).  
- GitPython для работы с репозиториями.  
- Модуль извлечения текста (может использовать функции из C2.2).  
- Логика фильтрации на Python.  
- JSON-файлы для хранения состояния последних коммитов.

**5. СПИСОК ПАТЧЕЙ И ИХ ФУНКЦИИ**  
- **P2.4.1 (Конфигуратор внешних источников):** Создание структуры папок и файла `sources.json` с примером конфигурации; скрипт `source_config.py` для управления списком.  
- **P2.4.2 (Сборщик GitHub):** Скрипт `github_collector.py`, который по конфигурации скачивает репозитории, извлекает артефакты и сохраняет состояние последнего коммита.  
- **P2.4.3 (Интеграция сборщика с индексатором):** Модуль, который передаёт собранные данные в C2.2 для индексации.  
- **P2.4.4 (Фильтр качества):** Скрипт `source_filter.py`, который оценивает источники (звёзды, форки, активность, лицензию) и отсеивает низкокачественные.
