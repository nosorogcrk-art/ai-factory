
### **P2.4.2: Сборщик GitHub** (LEVEL 5)

**ID:** P2.4.2  
**Контейнер:** C2.4  
**Название:** `github_collector.py` – сбор репозиториев с GitHub

---

### 1. ЗАМЫСЕЛ ПАТЧА
Скрипт, который по конфигурации `sources.json` скачивает (или обновляет) указанные репозитории, извлекает из них полезные артефакты (README, примеры кода) и сохраняет их локально для последующей индексации. Также отслеживает состояние последнего обработанного коммита, чтобы избежать повторной обработки неизменённых файлов.

---

### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Зависимости:** P2.4.1 (конфигурация), библиотеки `PyGithub`, `GitPython`.
- **Алгоритм:**
  1. Загрузить конфигурацию из `sources.json`.
  2. Для каждого репозитория:
     - Получить метаданные через GitHub API (звёзды, форки, лицензию).
     - Проверить фильтры (звёзды >= min_stars, лицензия в списке разрешённых).
     - Если репозиторий прошел фильтр, клонировать или обновить его в `clone_dir` (из конфига).
     - Записать в файл состояния (рядом с репозиторием) последний обработанный коммит.
     - Извлечь файлы с расширениями `.md`, `.py`, `.js`, `.ipynb` и т.п. (список настраивается).
     - Для каждого извлечённого файла сохранить его локально с путём, удобным для индексатора.
  3. Логировать все действия.
- **Файл состояния:** для каждого репозитория создаётся JSON-файл с полем `last_commit_sha`. При следующем запуске сравнивается с текущим HEAD, обрабатываются только изменившиеся файлы.
- **Логирование:** `01_ЦЕХ/01_ЖУРНАЛЫ/github_collector.log`.

---

### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
github_collector.py – сбор и обновление репозиториев с GitHub.
"""

import os
import json
import logging
import shutil
from pathlib import Path
from github import Github
from git import Repo
from datetime import datetime

CONFIG_FILE = Path("00_КАНОН/Внешние_источники/sources.json")
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/github_collector.log")
STATE_DIR = Path("00_ПАМЯТЬ/Внешние/state")

LOG_FILE.parent.mkdir(parents=True, exist_ok=True)
STATE_DIR.mkdir(parents=True, exist_ok=True)
logging.basicConfig(filename=LOG_FILE, level=logging.INFO,
                    format='%(asctime)s - %(levelname)s - %(message)s')

# GitHub API (можно передать токен через переменную окружения)
GITHUB_TOKEN = os.environ.get("GITHUB_TOKEN")
if GITHUB_TOKEN:
    g = Github(GITHUB_TOKEN)
else:
    g = Github()  # анонимный доступ, но с ограничениями

# Расширения файлов, которые считаем полезными
KEEP_EXTENSIONS = {'.md', '.py', '.js', '.ipynb', '.txt', '.rst'}

def load_config():
    with open(CONFIG_FILE, "r", encoding="utf-8") as f:
        return json.load(f)

def get_repo_metadata(repo_url):
    """Извлекает имя владельца и репозитория из URL."""
    # Пример: https://github.com/microsoft/autogen
    parts = repo_url.rstrip('/').split('/')
    owner, repo_name = parts[-2], parts[-1]
    return owner, repo_name

def meets_criteria(repo, min_stars, license_allow):
    """Проверяет, удовлетворяет ли репозиторий фильтрам."""
    if repo.stargazers_count < min_stars:
        return False
    if license_allow:
        license_name = repo.license.name if repo.license else None
        if license_name not in license_allow:
            return False
    return True

def get_last_commit_sha(repo_path):
    """Возвращает SHA последнего коммита."""
    repo = Repo(repo_path)
    return repo.head.commit.hexsha

def load_state(repo_name):
    state_file = STATE_DIR / f"{repo_name}.json"
    if state_file.exists():
        with open(state_file, "r") as f:
            return json.load(f)
    return {"last_commit": None}

def save_state(repo_name, last_commit):
    state_file = STATE_DIR / f"{repo_name}.json"
    with open(state_file, "w") as f:
        json.dump({"last_commit": last_commit, "updated": datetime.now().isoformat()}, f)

def collect_repo(repo_url, branch, min_stars, license_allow, clone_base):
    owner, repo_name = get_repo_metadata(repo_url)
    try:
        repo = g.get_repo(f"{owner}/{repo_name}")
    except Exception as e:
        logging.error(f"Failed to access {repo_url}: {e}")
        return

    if not meets_criteria(repo, min_stars, license_allow):
        logging.info(f"Repo {repo_url} does not meet criteria, skipping.")
        return

    clone_path = Path(clone_base) / f"{owner}_{repo_name}"
    state = load_state(f"{owner}_{repo_name}")
    current_head = None

    if clone_path.exists():
        # Обновляем
        try:
            local_repo = Repo(clone_path)
            origin = local_repo.remotes.origin
            origin.pull()
            current_head = get_last_commit_sha(clone_path)
            if current_head == state.get("last_commit"):
                logging.info(f"No new commits in {repo_url}")
                return
        except Exception as e:
            logging.error(f"Failed to update {repo_url}: {e}")
            return
    else:
        # Клонируем
        try:
            local_repo = Repo.clone_from(repo_url, clone_path, branch=branch)
            current_head = get_last_commit_sha(clone_path)
        except Exception as e:
            logging.error(f"Failed to clone {repo_url}: {e}")
            return

    # Обработка файлов
    processed_files = []
    for root, _, files in os.walk(clone_path):
        for file in files:
            ext = Path(file).suffix.lower()
            if ext in KEEP_EXTENSIONS:
                src = Path(root) / file
                # Относительный путь внутри репозитория
                rel_path = src.relative_to(clone_path)
                # Копируем в специальную папку для индексации? Или просто отмечаем для индексатора.
                # Для простоты будем передавать список путей в индексатор через P2.4.3.
                processed_files.append(str(src))
    logging.info(f"Processed {len(processed_files)} files from {repo_url}")

    save_state(f"{owner}_{repo_name}", current_head)
    # Возвращаем список обработанных файлов для передачи в индексатор
    return processed_files

def main():
    config = load_config()
    clone_base = config["global"]["clone_dir"]
    Path(clone_base).mkdir(parents=True, exist_ok=True)

    all_files = []
    for repo in config["repositories"]:
        files = collect_repo(
            repo["url"],
            repo.get("branch", "main"),
            repo.get("min_stars", 1000),
            repo.get("license_allow"),
            clone_base
        )
        if files:
            all_files.extend(files)

    # Сохраняем список обработанных файлов для следующего патча
    if all_files:
        out_file = Path(clone_base) / "latest_batch.json"
        with open(out_file, "w") as f:
            json.dump(all_files, f)
        logging.info(f"Saved list of {len(all_files)} files to {out_file}")

if __name__ == "__main__":
    main()
```

### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)
- Скрипт запускается и обрабатывает репозитории согласно конфигурации.
- При первом запуске репозитории клонируются, при повторном – обновляются.
- Учитываются фильтры по звёздам и лицензиям.
- Создаётся файл `latest_batch.json` со списком обработанных файлов.
- Логирование ведётся.
