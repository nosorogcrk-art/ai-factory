#### 1. ЗАМЫСЕЛ ПАТЧА
Создание сервиса, который отслеживает изменения в директориях `00_КАНОН/` и `01_ЦЕХ/`, извлекает текст из файлов, преобразует его в векторные представления (эмбеддинги) и синхронизирует их с векторным хранилищем C2.1. Это обеспечивает актуальность семантического индекса для поиска.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Зависимости:**
  - Патч **P2.0.1** (общий модуль эмбеддингов `embedding_model.py`).
  - Патч **P2.1.1** (инициализированное векторное хранилище Chroma).
- **Отслеживание изменений:**
  - Использование библиотеки `watchdog` для мониторинга событий файловой системы (создание, изменение, удаление).
  - Дополнительное периодическое полное сканирование раз в час для гарантии согласованности (запускается в отдельном потоке).
- **Извлечение текста:**
  - Для Markdown (`.md`): удаляются синтаксические элементы разметки (заголовки, списки), а ссылки вида `[[ID]]` преобразуются в текст самого идентификатора, чтобы сохранить семантическую связь.
  - Для исходного кода (`.py`, `.js`, `.ts` и др.): извлекается весь текст файла (включая комментарии и строки документации), так как комментарии несут важную смысловую нагрузку.
  - **Бинарные файлы** игнорируются (список расширений задаётся в конфигурации).
- **Генерация эмбеддингов:** вызов функции `encode(text)` из общего модуля `embedding_model.py`, возвращающей вектор размерности 384.
- **Обновление хранилища C2.1:**
  - При создании/изменении файла: сначала удаляется существующая запись с идентификатором, равным относительному пути файла (если есть), затем добавляется новый вектор с метаданными.
  - При удалении файла: удаляется соответствующая запись.
- **Идентификатор документа:** полный относительный путь от корня проекта (например, `00_КАНОН/01_РОЛИ/ARGUS.md`).
- **Метаданные:** сохраняются в Chroma вместе с вектором:
  - `path` – путь к файлу.
  - `source` – всегда `"internal"` для внутренних документов.
  - `timestamp` – время последней модификации файла (числовой timestamp).
  - `title` – первая непустая строка файла (обрезается до 100 символов).
- **Игнорируемые файлы:** служебные и бинарные файлы (`.gitkeep`, `prompt_hashes.json`, `SYSTEM_REGISTRY.json`, `*.log`, а также бинарные расширения: `.jpg`, `.png`, `.pdf`, `.zip`, `.exe`, `.dll`, `.so`, `.class`, `.pyc` и др.). Список настраивается через конфигурационный файл `memory_config.json`; при его отсутствии используются значения по умолчанию.
- **Логирование:** все действия записываются в `01_ЦЕХ/01_ЖУРНАЛЫ/indexer.log` с указанием времени, файла, типа операции и возможных ошибок.

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
indexer.py – индексатор документов для семантической памяти.
Отслеживает изменения в 00_КАНОН/ и 01_ЦЕХ/, обновляет векторное хранилище C2.1.
"""

import os
import re
import time
import json
import logging
import threading
from pathlib import Path
from watchdog.observers import Observer
from watchdog.events import FileSystemEventHandler
import chromadb
from embedding_model import get_encoder

# === Конфигурация ===
VECTOR_STORE_DIR = Path("00_ПАМЯТЬ/ВЕКТОРЫ")
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/indexer.log")
WATCH_DIRS = [Path("00_КАНОН"), Path("01_ЦЕХ")]
COLLECTION_NAME = "documents"
CONFIG_FILE = Path("00_КАНОН/Конфиги/memory_config.json")

# Загрузка конфигурации (если есть)
if CONFIG_FILE.exists():
    with open(CONFIG_FILE, "r", encoding="utf-8") as f:
        config = json.load(f)
else:
    config = {}

# Игнорируемые файлы: служебные и бинарные
IGNORE_PATTERNS = config.get("ignore_patterns", [
    r".*\.gitkeep$",
    r".*prompt_hashes\.json$",
    r".*SYSTEM_REGISTRY\.json$",
    r".*\.log$",
    r".*\.(jpg|jpeg|png|gif|bmp|ico|pdf|zip|tar|gz|7z|rar|exe|dll|so|bin|class|pyc)$"
])

# Настройка логирования
LOG_FILE.parent.mkdir(parents=True, exist_ok=True)
logging.basicConfig(
    filename=LOG_FILE,
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

# Подключение к Chroma (хранилище C2.1)
client = chromadb.PersistentClient(path=str(VECTOR_STORE_DIR))
collection = client.get_or_create_collection(COLLECTION_NAME)
encoder = get_encoder()  # синглтон

def should_ignore(file_path: Path) -> bool:
    """Проверяет, нужно ли игнорировать файл."""
    for pattern in IGNORE_PATTERNS:
        if re.match(pattern, str(file_path)):
            return True
    return False

def extract_text(file_path: Path) -> str | None:
    """Извлекает чистый текст из файла в зависимости от расширения."""
    ext = file_path.suffix.lower()
    try:
        with open(file_path, "r", encoding="utf-8", errors="ignore") as f:
            content = f.read()
    except Exception as e:
        logging.error(f"Error reading {file_path}: {e}")
        return None

    if ext == ".md":
        # Заменяем [[ID]] на сам ID, сохраняем текст ссылки
        content = re.sub(r'\[\[(.*?)\]\]', r'\1', content)
        # Убираем символы заголовков, но оставляем текст
        content = re.sub(r'^#+\s*', '', content, flags=re.MULTILINE)
        # Убираем маркеры списков, оставляя текст
        content = re.sub(r'^[\*\-\+]\s+', '', content, flags=re.MULTILINE)
        return content
    else:
        # Для всех остальных (включая код) возвращаем как есть
        return content

def get_title(content: str) -> str:
    """Возвращает первую непустую строку (обрезанную до 100 символов)."""
    for line in content.splitlines():
        line = line.strip()
        if line:
            return line[:100]
    return ""

def index_file(file_path: Path):
    """Индексирует один файл (добавляет/обновляет в хранилище C2.1)."""
    if should_ignore(file_path):
        return
    text = extract_text(file_path)
    if text is None or not text.strip():
        return
    embedding = encoder.encode(text).tolist()
    metadata = {
        "path": str(file_path),
        "source": "internal",
        "timestamp": str(file_path.stat().st_mtime),
        "title": get_title(text)
    }
    doc_id = str(file_path)

    # Удаляем старую запись, если она есть
    try:
        collection.delete(ids=[doc_id])
    except:
        pass

    collection.add(ids=[doc_id], embeddings=[embedding], metadatas=[metadata])
    logging.info(f"Indexed {doc_id}")

def remove_file(file_path: Path):
    """Удаляет файл из индекса."""
    doc_id = str(file_path)
    try:
        collection.delete(ids=[doc_id])
        logging.info(f"Removed {doc_id}")
    except Exception as e:
        logging.error(f"Failed to remove {doc_id}: {e}")

class ChangeHandler(FileSystemEventHandler):
    def on_modified(self, event):
        if not event.is_directory and not should_ignore(Path(event.src_path)):
            index_file(Path(event.src_path))

    def on_created(self, event):
        if not event.is_directory and not should_ignore(Path(event.src_path)):
            index_file(Path(event.src_path))

    def on_deleted(self, event):
        if not event.is_directory:
            remove_file(Path(event.src_path))

def full_scan():
    """Полное сканирование всех целевых директорий."""
    logging.info("Starting full scan...")
    for base in WATCH_DIRS:
        if not base.exists():
            continue
        for root, _, files in os.walk(base):
            for file in files:
                file_path = Path(root) / file
                if not should_ignore(file_path):
                    index_file(file_path)
    logging.info("Full scan completed.")

def periodic_scan(interval=3600):
    """Функция для периодического запуска полного сканирования в отдельном потоке."""
    while True:
        time.sleep(interval)
        full_scan()

def main():
    # При старте выполняем полное сканирование
    full_scan()

    # Запускаем watchdog
    observer = Observer()
    for watch_dir in WATCH_DIRS:
        if watch_dir.exists():
            observer.schedule(ChangeHandler(), str(watch_dir), recursive=True)
    observer.start()
    logging.info("Watchdog started. Monitoring directories: %s", [str(d) for d in WATCH_DIRS if d.exists()])

    # Запускаем периодическое сканирование в отдельном потоке
    t = threading.Thread(target=periodic_scan, args=(3600,), daemon=True)
    t.start()

    try:
        while True:
            time.sleep(1)
    except KeyboardInterrupt:
        observer.stop()
    observer.join()

if __name__ == "__main__":
    main()
```

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)
- Скрипт `indexer.py` размещён в `agents/tools/` и может быть запущен как демон.
- При первом запуске выполняется полное сканирование всех документов в `00_КАНОН/` и `01_ЦЕХ/`, и они появляются в векторном хранилище (проверяется через поиск).
- При создании нового файла (например, `test.md`) он автоматически индексируется в течение нескольких секунд.
- При изменении файла индекс обновляется.
- При удалении файла запись удаляется из хранилища.
- Служебные и бинарные файлы (`.gitkeep`, `prompt_hashes.json`, `*.jpg`, `*.png`, `*.pdf` и т.д.) игнорируются.
- Логирование ведётся в указанный файл, ошибки обрабатываются.
- Периодическое сканирование запускается и не мешает основной работе.
- Скрипт корректно взаимодействует с C2.1 через его API.
