### **P2.1.1: Инициализация векторной БД** (LEVEL 5)

**ID:** P2.1.1 | **Контейнер:** C2.1 | **Название:** `init_vector_store.py` – инициализация Chroma DB

**1. ЗАМЫСЕЛ ПАТЧА**  
Создание скрипта, который при первом запуске или по команде инициализирует векторное хранилище Chroma в заданной директории, создаёт пустую коллекцию и проверяет её работоспособность. Это фундамент для всех последующих операций с эмбеддингами.

**2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ**  
- **Целевая директория:** `00_ПАМЯТЬ/ВЕКТОРЫ/` (создаётся автоматически).  
- **Используемая БД:** Chroma (persistent client).  
- **Коллекция:** по умолчанию `"documents"`, с метаданными, включающими поля `source` (internal/external), `path`, `timestamp`.  
- **Проверка:** после инициализации выполняется тестовый запрос (добавление одного вектора и поиск) для подтверждения работоспособности.  
- **Логирование:** записываются шаги и результат в лог-файл `01_ЦЕХ/01_ЖУРНАЛЫ/vector_store_init.log`.  
- **Повторный запуск:** если хранилище уже существует, скрипт проверяет его целостность и при необходимости пересоздаёт (с предупреждением).

**3. РЕАЛИЗАЦИЯ (L6 — КОД)**  

Файл: `agents/tools/init_vector_store.py`

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
init_vector_store.py – инициализация векторного хранилища Chroma.
Создаёт директорию, запускает Chroma persistent client и создаёт коллекцию.
"""

import os
import sys
import logging
import chromadb
from pathlib import Path
from datetime import datetime

# Конфигурация
VECTOR_STORE_DIR = Path("00_ПАМЯТЬ/ВЕКТОРЫ")
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/vector_store_init.log")
COLLECTION_NAME = "documents"

# Настройка логирования
LOG_FILE.parent.mkdir(parents=True, exist_ok=True)
logging.basicConfig(
    filename=LOG_FILE,
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

def init_vector_store():
    # Создаём директорию, если её нет
    VECTOR_STORE_DIR.mkdir(parents=True, exist_ok=True)
    logging.info(f"Vector store directory: {VECTOR_STORE_DIR}")

    # Инициализируем клиент Chroma
    try:
        client = chromadb.PersistentClient(path=str(VECTOR_STORE_DIR))
        logging.info("Chroma client created.")
    except Exception as e:
        logging.error(f"Failed to create Chroma client: {e}")
        sys.exit(1)

    # Проверяем существование коллекции
    try:
        collection = client.get_collection(COLLECTION_NAME)
        logging.info(f"Collection '{COLLECTION_NAME}' already exists.")
        # Можно выполнить тест
    except ValueError:
        # Коллекция не существует – создаём
        collection = client.create_collection(
            name=COLLECTION_NAME,
            metadata={"hnsw:space": "cosine"}  # или "l2"
        )
        logging.info(f"Collection '{COLLECTION_NAME}' created.")
    except Exception as e:
        logging.error(f"Error accessing collection: {e}")
        sys.exit(1)

    # Тест: добавляем один вектор и ищем
    try:
        test_id = "test_doc"
        test_embedding = [0.0] * 384  # размерность модели MiniLM
        test_metadata = {"source": "test", "path": "/dev/null"}
        collection.add(ids=[test_id], embeddings=[test_embedding], metadatas=[test_metadata])
        results = collection.query(query_embeddings=[test_embedding], n_results=1)
        if results['ids'][0][0] == test_id:
            logging.info("Test query passed.")
        else:
            logging.warning("Test query returned unexpected result.")
        # Удаляем тестовую запись
        collection.delete(ids=[test_id])
        logging.info("Test record cleaned up.")
    except Exception as e:
        logging.error(f"Test failed: {e}")
        sys.exit(1)

    logging.info("Vector store initialized successfully.")
    print("✅ Vector store ready.")

if __name__ == "__main__":
    init_vector_store()
```

**4. КРИТЕРИЙ ПРИЕМКИ (DoD)**  
- Скрипт `init_vector_store.py` создан и размещён в `agents/tools/`.  
- При первом запуске создаётся директория `00_ПАМЯТЬ/ВЕКТОРЫ/` и инициализируется Chroma-коллекция.  
- При повторном запуске проверяется целостность (коллекция существует) и выполняется тест.  
- Логирование работает, ошибки приводят к выходу с ненулевым кодом.  
- После выполнения скрипта векторное хранилище готово к использованию другими компонентами.
