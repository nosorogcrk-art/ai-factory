### **P2.1.2: Индексатор документов** (LEVEL 5)

**ID:** P2.1.2  
**Контейнер:** C2.1 (Vector Store)  
**Название:** `indexer.py` – индексация документов в векторное хранилище

---

### 1. ЗАМЫСЕЛ ПАТЧА

Создание скрипта, который отслеживает изменения в папках `00_КАНОН/` и `01_ЦЕХ/`, извлекает текст, генерирует эмбеддинги с использованием единой модели и обновляет векторное хранилище (C2.1). Обеспечивает актуальность семантического индекса.

---

### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ

- **Зависимости:** P2.1.1 (инициализированное хранилище), P2.0.1 (общий модуль эмбеддингов).
    
- **Отслеживание изменений:** watchdog для событий создания, изменения, удаления файлов.
    
- **Извлечение текста:**
    
    - Markdown (`.md`): удаляются синтаксические элементы разметки (заголовки, списки), а ссылки вида `[[ID]]` преобразуются в текст самого идентификатора (сохраняется семантическая связь).
        
    - Код (`.py`, `.js`, `.ts`, `.java`, `.c`, `.cpp` и др.): индексируется весь файл целиком (включая комментарии и строки документации).
        
    - Бинарные файлы (`.jpg`, `.png`, `.gif`, `.pdf`, `.zip`, `.exe`, `.dll` и т.п.) игнорируются.
        
- **Генерация эмбеддингов:** вызов `encoder.encode(text)` через общий модуль. При ошибках модели предусмотрены повторные попытки (3 попытки с экспоненциальной задержкой).
    
- **Обновление хранилища:**
    
    - При создании/изменении файла: старый вектор удаляется (если есть), добавляется новый.
        
    - При удалении файла: вектор удаляется.
        
- **Идентификатор документа:** полный относительный путь (например, `00_КАНОН/01_РОЛИ/ARGUS.md`).
    
- **Метаданные:** `source` (internal), `path`, `timestamp` (mtime), `title` (первая строка).
    
- **Игнорируемые файлы:** список настраивается через `memory_config.json`. По умолчанию включает служебные и бинарные расширения.
    
- **Логирование:** детальный лог в `01_ЦЕХ/01_ЖУРНАЛЫ/indexer.log`.

### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

python

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
indexer.py – индексация документов в векторное хранилище (C2.1).
"""
import os
import re
import time
import json
import logging
from pathlib import Path
from watchdog.observers import Observer
from watchdog.events import FileSystemEventHandler
import chromadb
from embedding_model import get_encoder
# Конфигурация
VECTOR_STORE_DIR = Path("00_ПАМЯТЬ/ВЕКТОРЫ")
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/indexer.log")
WATCH_DIRS = [Path("00_КАНОН"), Path("01_ЦЕХ")]
COLLECTION_NAME = "documents"
CONFIG_FILE = Path("00_КАНОН/Конфиги/memory_config.json")
# Загрузка конфигурации
if CONFIG_FILE.exists():
    with open(CONFIG_FILE, "r", encoding="utf-8") as f:
        config = json.load(f)
else:
    config = {}
IGNORE_PATTERNS = config.get("ignore_patterns", [
    r".*\.gitkeep$",
    r".*prompt_hashes\.json$",
    r".*SYSTEM_REGISTRY\.json$",
    r".*\.log$",
    r".*\.(jpg|jpeg|png|gif|bmp|ico|pdf|zip|tar|gz|7z|rar|exe|dll|so|bin|class|pyc)$"
])
# Настройка логирования
LOG_FILE.parent.mkdir(parents=True, exist_ok=True)
logging.basicConfig(
    filename=LOG_FILE,
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)
# Инициализация клиента Chroma и коллекции
client = chromadb.PersistentClient(path=str(VECTOR_STORE_DIR))
collection = client.get_or_create_collection(COLLECTION_NAME)
encoder = get_encoder()
def should_ignore(file_path: Path) -> bool:
    """Проверяет, нужно ли игнорировать файл."""
    for pattern in IGNORE_PATTERNS:
        if re.match(pattern, str(file_path)):
            return True
    return False
def extract_text(file_path: Path) -> str | None:
    """Извлечение чистого текста из файла."""
    ext = file_path.suffix.lower()
    try:
        with open(file_path, 'r', encoding='utf-8') as f:
            content = f.read()
    except Exception as e:
        logging.error(f"Error reading {file_path}: {e}")
        return None
    if ext == '.md':
        # Заменяем [[ID]] на сам ID, оставляем текст ссылки
        content = re.sub(r'\[\[(.*?)\]\]', r'\1', content)
        # Убираем символы заголовков, оставляя текст
        content = re.sub(r'^#+\s*', '', content, flags=re.MULTILINE)
        # Убираем маркеры списков, оставляя текст
        content = re.sub(r'^[\*\-\+]\s+', '', content, flags=re.MULTILINE)
        return content
    elif ext in ('.py', '.js', '.ts', '.java', '.c', '.cpp'):
        # Индексируем весь файл целиком, включая комментарии и строки документации
        return content
    else:
        # Для остальных текстовых форматов возвращаем как есть
        return content
def get_title(content: str) -> str:
    """Извлекает заголовок из содержимого (первая непустая строка)."""
    for line in content.splitlines():
        line = line.strip()
        if line:
            return line[:100]
    return ""
def encode_with_retry(text, retries=3, delay=1):
    """Генерация эмбеддинга с повторными попытками при ошибках."""
    for attempt in range(retries):
        try:
            return encoder.encode(text).tolist()
        except Exception as e:
            logging.warning(f"Encoding attempt {attempt+1} failed: {e}")
            if attempt < retries - 1:
                time.sleep(delay)
                delay *= 2
            else:
                raise
def index_file(file_path: Path):
    """Обновляет индекс для одного файла."""
    if should_ignore(file_path):
        return
    text = extract_text(file_path)
    if text is None or not text.strip():
        return
    embedding = encode_with_retry(text)
    metadata = {
        "source": "internal",
        "path": str(file_path),
        "timestamp": str(file_path.stat().st_mtime),
        "title": get_title(text)
    }
    doc_id = str(file_path)
    # Удаляем старый вектор, если есть
    try:
        collection.delete(ids=[doc_id])
    except:
        pass
    collection.add(ids=[doc_id], embeddings=[embedding], metadatas=[metadata])
    logging.info(f"Indexed {doc_id}")
def remove_file(file_path: Path):
    """Удаляет документ из индекса."""
    doc_id = str(file_path)
    try:
        collection.delete(ids=[doc_id])
        logging.info(f"Removed {doc_id}")
    except Exception as e:
        logging.error(f"Failed to remove {doc_id}: {e}")
class ChangeHandler(FileSystemEventHandler):
    def on_modified(self, event):
        if not event.is_directory and not should_ignore(Path(event.src_path)):
            index_file(Path(event.src_path))
    def on_created(self, event):
        if not event.is_directory and not should_ignore(Path(event.src_path)):
            index_file(Path(event.src_path))
    def on_deleted(self, event):
        if not event.is_directory:
            remove_file(Path(event.src_path))
def full_scan():
    """Полное сканирование всех файлов в целевых директориях."""
    logging.info("Starting full scan...")
    for base_dir in WATCH_DIRS:
        if not base_dir.exists():
            continue
        for root, _, files in os.walk(base_dir):
            for file in files:
                file_path = Path(root) / file
                if not should_ignore(file_path):
                    index_file(file_path)
    logging.info("Full scan completed.")
def main():
    # При запуске делаем полное сканирование
    full_scan()
    logging.info("Starting watchdog...")
    observer = Observer()
    for watch_dir in WATCH_DIRS:
        if watch_dir.exists():
            observer.schedule(ChangeHandler(), str(watch_dir), recursive=True)
    observer.start()
    try:
        while True:
            time.sleep(1)
    except KeyboardInterrupt:
        observer.stop()
    observer.join()
if __name__ == "__main__":
    main()

### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)

- Скрипт `indexer.py` создан и запускается как демон.
    
- При добавлении/изменении файлов индекс обновляется (проверяется через поиск).
    
- При удалении файла запись удаляется из хранилища.
    
- Логирование работает.
    
- При старте выполняется полное сканирование.
    
- Игнорируются служебные и бинарные файлы согласно конфигурации.
    
- Повторные попытки при ошибках модели работают (можно проверить, временно отключив модель).
