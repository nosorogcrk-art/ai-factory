### **C2.1: Vector Store (Векторное хранилище)**

**Ветка-родитель:** BR2 | **ID:** C2.1 | **Ответственный:** МНЕМОСИНА

**1. ФУНКЦИОНАЛЬНОЕ ПРЕДНАЗНАЧЕНИЕ**  
Управление векторной базой данных, обеспечивающей хранение эмбеддингов документов и эффективный поиск по семантической близости. Служит основой для всех операций семантического поиска внутри завода.

**2. ТЕХНИЧЕСКАЯ ЛОГИКА (МЕХАНИКА)**  
- **Выбор БД:** Используется **Chroma DB** как наиболее интегрируемая с файловой системой и поддерживающая метаданные.  
- **Инициализация:** При первом запуске создаётся структура БД в директории `00_ПАМЯТЬ/ВЕКТОРЫ/`.  
- **Операции:**  
  - `add(ids, embeddings, metadatas)` – добавление векторов с метаданными (путь, дата, источник).  
  - `delete(ids)` – удаление векторов по идентификаторам (используется индексатором при изменении/удалении файла).  
  - `search(query_embedding, k, filter)` – поиск k ближайших соседей с возможностью фильтрации по метаданным (источник, дата).  
- **Версионирование:** Поддерживаются снимки (snapshots) состояния БД для отката (через копирование папки или встроенные средства Chroma).  
- **Единая модель эмбеддингов:** Используется модель `sentence-transformers/all-MiniLM-L6-v2`, загружаемая один раз и доступная всем компонентам через общий модуль.

**3. ВХОДЫ И ВЫХОДЫ (INTERFACES)**  
- **Input:** Команды на добавление/удаление векторов, поисковые запросы (вектор + параметры).  
- **Output:** Список идентификаторов документов с метаданными и оценками близости.

**4. СТЕК ТЕХНОЛОГИЙ**  
- Chroma DB (Python-клиент).  
- Сериализация метаданных в JSON.  
- Интеграция с файловой системой через монтируемый том.  
- Единый модуль загрузки модели (`embedding_model.py`).

**5. СПИСОК ПАТЧЕЙ И ИХ ФУНКЦИИ**  
- **P2.1.1 (Инициализация векторной БД):** Создание скрипта `init_vector_store.py`, который при первом запуске создаёт директорию `00_ПАМЯТЬ/ВЕКТОРЫ/`, инициализирует пустую Chroma-коллекцию и проверяет её работоспособность.  
- **P2.1.2 (Индексатор документов)** – использует API C2.1 для добавления/удаления.  
- **P2.1.3 (Семантический поиск)** – использует API C2.1 для поиска.
