---

### 1. ЗАМЫСЕЛ ПАТЧА

После добавления новых ссылок в документ необходимо обновить глобальный граф связей (C4.2), чтобы новые связи отображались в визуализации и учитывались при анализе. Патч добавляет вызов API графа для информирования о новых рёбрах.

---

### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ

- **Зависимости:** P3.4.2, C4.2 (Graph Visualizer).
    
- **Механизм:** при каждом успешном добавлении ссылки агент отправляет запрос к API графа (например, через HTTP POST на `/api/graph/add_edge` с параметрами `source` (ID текущего документа) и `target` (ID целевого документа)).
    
- Если документ не имеет собственного ID (например, отчёт не зарегистрирован в реестре), то создаётся временный узел или операция пропускается.
    
- **Логирование:** добавляются записи об отправленных запросах.

### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

python

# Добавить функцию отправки уведомления в граф
import requests
def notify_graph(source_doc_id: str, target_doc_id: str):
    """Отправляет информацию о новом ребре в граф."""
    try:
        response = requests.post(
            "http://localhost:19008/api/graph/add_edge",
            json={"source": source_doc_id, "target": target_doc_id},
            timeout=2
        )
        if response.status_code == 200:
            logging.info(f"Graph edge added: {source_doc_id} -> {target_doc_id}")
        else:
            logging.warning(f"Graph API returned {response.status_code}")
    except Exception as e:
        logging.error(f"Failed to notify graph: {e}")
