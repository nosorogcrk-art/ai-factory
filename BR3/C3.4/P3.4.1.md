---

### 1. ЗАМЫСЕЛ ПАТЧА

Создание скрипта, который автоматически проставляет ссылки на связанные документы в текстовых отчётах. На первом этапе используется упрощённый подход: поиск по ключевым словам и обращение к семантическому поиску (C2.3) для нахождения релевантных документов. Результат – текст с добавленными ссылками `[[ID]]`.

---

### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ

- **Зависимости:** C2.3 (семантический поиск), общий модуль эмбеддингов (P2.0.1) – опционально.
    
- **Вход:** JSON-объект с полями:
    
    - `text` (строка) – исходный текст.
        
    - `doc_id` (строка, опционально) – идентификатор обрабатываемого документа.
        
    - `max_links` (число, по умолчанию 10) – максимальное количество добавляемых ссылок.
        
- **Выход:** JSON-объект с полем `text` – модифицированный текст.
    
- **Алгоритм:**
    
    1. Извлечение из текста всех слов, которые могут быть идентификаторами (например, `BR7`, `P3.1.1`, `C2.3`). Для этого используется регулярное выражение `[A-Z][0-9.]+` (упрощённо).
        
    2. Для каждого найденного потенциального ID выполняется поиск в семантическом хранилище (C2.3) с фильтром по типу (если поддерживается). Если документ с таким ID существует, формируется ссылка `[[ID]]`.
        
    3. Если в тексте уже есть ссылка на этот ID (т.е. `[[ID]]` присутствует), пропускаем.
        
    4. В противном случае добавляем ссылку после первого упоминания ID (или в конец абзаца, если ID не найден, но документ релевантен по смыслу).
        
    5. Возвращаем изменённый текст.
        
- **Логирование:** в `01_ЦЕХ/01_ЖУРНАЛЫ/citations_agent.log`.

### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

python

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
citations_agent.py – базовый Citations Agent.
Добавляет ссылки [[ID]] в текст на основе семантического поиска.
"""
import json
import re
import logging
from pathlib import Path
from typing import List, Optional
# Предполагается, что есть модуль для работы с семантическим поиском
from semantic_search import search
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/citations_agent.log")
LOG_FILE.parent.mkdir(parents=True, exist_ok=True)
logging.basicConfig(
    filename=LOG_FILE,
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)
def extract_potential_ids(text: str) -> List[str]:
    """Извлекает из текста последовательности, похожие на ID (буквы+цифры+точки)."""
    # Пример: BR7, P3.1.1, C2.3
    pattern = r'\b[A-Z][0-9.]+\b'
    return list(set(re.findall(pattern, text)))
def add_citations(text: str, max_links: int = 10) -> str:
    """
    Добавляет ссылки на документы, если их ID найдены в тексте.
    """
    potential_ids = extract_potential_ids(text)
    added = 0
    # Для простоты не будем изменять текст прямо в цикле,
    # а соберём замены и применим их позже.
    replacements = []
    for pid in potential_ids:
        if added >= max_links:
            break
        # Проверяем, существует ли документ через семантический поиск
        # (можно искать по точному ID, если есть индекс)
        results = search(query=pid, k=1, filters={"source": "internal"})
        if results and results[0]["id"] == pid:
            # Если в тексте ещё нет ссылки [[pid]]
            if f"[[{pid}]]" not in text:
                # Заменяем первое вхождение pid на [[pid]]
                # Используем re.sub с count=1
                new_text, count = re.subn(rf'\b{re.escape(pid)}\b', f'[[{pid}]]', text, count=1)
                if count > 0:
                    text = new_text
                    added += 1
                    logging.info(f"Added citation for {pid}")
    return text
def main():
    import sys
    data = json.load(sys.stdin)
    text = data.get("text", "")
    max_links = data.get("max_links", 10)
    result_text = add_citations(text, max_links)
    print(json.dumps({"text": result_text}))
if __name__ == "__main__":
    main()
