### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P3.3.3 (LEVEL 5)

**ID:** P3.3.3  
**Контейнер:** C3.3 (Training Simulator)  
**Название:** Интеграция с памятью (сохранение успешных кейсов)

**Зависимости:** P3.3.2 (доработанный симулятор)

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить в симулятор функцию автоматического сохранения успешно пройденных тестовых кейсов в Эволюционную память (BR2). Это позволит накапливать эталонные примеры поведения агентов, которые впоследствии могут использоваться для обучения (BR19) и улучшения промптов. На данном этапе сохранение производится в простой текстовый файл (например, `01_ЦЕХ/Эволюционная_память.md`), но структура записи должна быть совместима с будущей интеграцией с BR2 (т.е. содержать ключевые поля для индексации).

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Целевой файл:** `01_ЦЕХ/Эволюционная_память.md` (создаётся автоматически).  
- **Формат записи:** Markdown-блок с метаданными в YAML-шапке (для будущего парсинга) или просто структурированный текст. Рекомендуется использовать формат:  
  ```markdown
  ### Успешный кейс [ID кейса] – [Дата]
  - **Название:** ...
  - **Целевой агент:** ...
  - **Использованные навыки:** [список]
  - **Результат:** ...
  - **Описание:** ...
  ```
- **Условия сохранения:**  
  - Кейс должен быть пройден успешно (валидация дала `success: true`).  
  - (Опционально) кейс должен иметь флаг `save_to_memory: true` в своей конфигурации (по умолчанию `true`).  
- **Процесс:**  
  - В конце выполнения кейса, если он успешен, симулятор вызывает функцию `store_to_memory(case_data, result_data)`.  
  - Функция формирует запись и дописывает её в конец файла `Эволюционная_память.md`.  
  - Также можно добавить запись в лог-файл симулятора.  
- **Интеграция с BR2:**  
  - В будущем, когда BR2 будет полностью реализован, этот файл может быть проиндексирован как источник эталонных документов. Пока же он служит для ручного просмотра и отладки.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- В `simulator.py` добавить функцию `store_successful_case(case, result)`.  
- Вызывать её после успешной валидации (перед завершением).  
- Функция открывает файл `Эволюционная_память.md` в режиме добавления и пишет запись.  

**Пример:**  
```python
MEMORY_FILE = Path("01_ЦЕХ/Эволюционная_память.md")

def store_successful_case(case, result):
    with open(MEMORY_FILE, "a", encoding="utf-8") as f:
        f.write(f"\n### Успешный кейс [{case['id']}] – {datetime.now().strftime('%Y-%m-%d %H:%M')}\n")
        f.write(f"- **Название:** {case['name']}\n")
        f.write(f"- **Целевой агент:** {case['target_agent']}\n")
        if 'required_skills' in case:
            f.write(f"- **Требуемые навыки:** {', '.join(case['required_skills'])}\n")
        f.write(f"- **Результат:** Успешно\n")
        f.write(f"- **Детали:** {result.get('details', '')}\n\n")
```

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При успешном прохождении тестового кейса в файл `Эволюционная_память.md` добавляется новая запись с информацией о кейсе.  
- При неудачном прохождении запись не добавляется.  
- Файл создаётся автоматически, если его нет.  
- Формат записи содержит ключевые поля для будущей индексации.
