### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P3.3.1 (LEVEL 5)

**ID:** P3.3.1 | **Контейнер:** C3.3 | **Название:** Библиотека кейсов

**1. ЗАМЫСЕЛ ПАТЧА**  
Создание структурированного хранилища тестовых сценариев (кейсов) для калибровки агентов. Кейсы описывают типовые ситуации, с которыми сталкиваются агенты, и содержат эталонные реакции. Это позволит в дальнейшем автоматически проверять, насколько точно агенты соблюдают Золотой стандарт и методологию.

**2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ**  
- **Директория хранения:** `00_КАНОН/Методология/Кейсы/`.  
- **Формат файлов:** JSON. Каждый файл представляет один кейс.  
- **Структура кейса:**  
  ```json
  {
    "id": "unique-string",
    "name": "Название кейса",
    "description": "Описание ситуации",
    "target_agent": "Имя агента (например, ГЕФЕСТ, АРХИ, РЕВА)",
    "input": {
      "message": "Текст запроса к агенту",
      "context": { ... }  // дополнительные параметры
    },
    "expected_output": {
      "type": "file_created", // или "message_reply", "tool_called" и т.д.
      "path": "относительный путь",
      "content_pattern": "регулярное выражение или строка",
      "tool": "имя инструмента",
      "params": { ... }
    },
    "validation_rules": [
      "правило1",
      "правило2"
    ],
    "created_at": "YYYY-MM-DD"
  }
  ```
- **Первоначальный набор кейсов:**  
  1. **L4_шаблон_патча** – проверка создания файла патча по шаблону (агент АРХИ).  
  2. **переход_статусов** – проверка корректного перехода задачи из `NEW` в `IN_PROGRESS` (агент ГЕФЕСТ).  
  3. **золотой_стандарт_сообщение** – проверка, что сообщение агента содержит обязательные поля.  
  4. **карантин_файла** – проверка реакции на неопознанный файл (агент РЕВА).  

**3. РЕАЛИЗАЦИЯ (L6 — КОД)**  

Скрипт инициализации `init_test_cases.py` создаст папку и заполнит её базовыми кейсами.

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
init_test_cases.py – создаёт библиотеку тестовых кейсов для симулятора.
"""

import json
from pathlib import Path

CASES_DIR = Path("00_КАНОН/Методология/Кейсы")

CASES = [
    {
        "id": "case-001",
        "name": "Создание патча L4 по шаблону",
        "description": "Агент Архитектор должен создать файл патча в папке 01_ЦЕХ/ЧЕРНОВИКИ/ПАТЧИ/ с правильной структурой.",
        "target_agent": "АРХИ",
        "input": {
            "message": "Создай патч для ветки BR1: реализовать модуль авторизации",
            "context": {
                "branch": "BR1",
                "patch_id": "P1.1.1"
            }
        },
        "expected_output": {
            "type": "file_created",
            "path": "01_ЦЕХ/ЧЕРНОВИКИ/ПАТЧИ/BR1/P1.1.1.md",
            "content_pattern": "# Патч P1\\.1\\.1"
        },
        "validation_rules": ["file_exists", "content_matches"],
        "created_at": "2026-03-17"
    },
    {
        "id": "case-002",
        "name": "Переход статуса задачи",
        "description": "Гефест должен взять задачу (команда take) и перевести её в IN_PROGRESS.",
        "target_agent": "ГЕФЕСТ",
        "input": {
            "message": "Возьми задачу P1.1.1 в работу",
            "context": {
                "task_id": "P1.1.1"
            }
        },
        "expected_output": {
            "type": "tool_called",
            "tool": "handover",
            "params": {
                "command": "take",
                "task_id": "P1.1.1"
            }
        },
        "validation_rules": ["tool_invoked", "status_updated"],
        "created_at": "2026-03-17"
    },
    {
        "id": "case-003",
        "name": "Сообщение о нарушении",
        "description": "Рева, обнаружив файл без пуповины, должен отправить уведомление Аргусу.",
        "target_agent": "РЕВА",
        "input": {
            "message": "Проверь целостность",
            "context": {
                "orphan_file": "01_ЦЕХ/ЧЕРНОВИКИ/random.txt"
            }
        },
        "expected_output": {
            "type": "file_created",
            "path": "01_ЦЕХ/01_ЖУРНАЛЫ/АРГУС_ВХОД/alert*.json",
            "content_pattern": ".*quarantine.*"
        },
        "validation_rules": ["file_created", "content_matches"],
        "created_at": "2026-03-17"
    }
]

def init():
    CASES_DIR.mkdir(parents=True, exist_ok=True)
    for case in CASES:
        file_path = CASES_DIR / f"{case['id']}.json"
        if not file_path.exists():
            with open(file_path, "w", encoding="utf-8") as f:
                json.dump(case, f, indent=2, ensure_ascii=False)
            print(f"Created case: {case['id']} – {case['name']}")
        else:
            print(f"Case {case['id']} already exists, skipping.")

if __name__ == "__main__":
    init()
```

**4. КРИТЕРИЙ ПРИЕМКИ (DoD)**  
- В папке `00_КАНОН/Методология/Кейсы/` созданы файлы для всех перечисленных кейсов.  
- Каждый файл имеет корректный JSON-формат.  
- Скрипт инициализации не перезаписывает существующие кейсы.
