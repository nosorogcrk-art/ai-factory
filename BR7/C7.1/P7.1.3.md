### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P7.1.3 (LEVEL 5) – ИСПРАВЛЕННАЯ ВЕРСИЯ

**ID:** P7.1.3 | **Контейнер:** C7.1 | **Название:** Версионирование промптов через Git

**1. ЗАМЫСЕЛ ПАТЧА**  
Обеспечение полной прослеживаемости изменений системных промптов. Каждое обновление файлов промптов фиксируется в Git с автоматическим присвоением тега версии, при этом служебный файл `prompt_hashes.json` исключается из контроля версий, так как генерируется автоматически. Это позволяет в любой момент откатиться к предыдущей стабильной версии и иметь чёткую историю модификаций паспортов ролей.

**2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ**

- **Зависимость:** патчи P7.1.1 и P7.1.2 должны быть реализованы (структура папок и скрипт раздачи промптов с хешами).
- **Исключаемые файлы:** `prompt_hashes.json` не должен попадать в коммиты и теги; его изменения игнорируются (можно добавить в `.gitignore` или исключать в коде).
- **Механизм:** при наличии изменений в любом файле `*.md` внутри `00_КАНОН/ПРОМПТЫ/` (кроме `prompt_hashes.json`) скрипт выполняет:
  - Добавление только изменённых `.md`-файлов в индекс Git.
  - Коммит с сообщением, содержащим список изменённых файлов.
  - Создание тега вида `prompts-YYYY-MM-DD-N` (где N – порядковый номер за день).
- **Интеграция:** скрипт `prompt_builder.py` не изменяется; при несовпадении хеша с эталоном он уже возвращает ошибку, что стимулирует ручное или автоматическое обновление эталонов после осознанных правок.
- **Логирование:** все операции с Git логируются в `01_ЦЕХ/01_ЖУРНАЛЫ/git_prompts.log`; директория создаётся автоматически.
- **Проверка окружения:** скрипт должен проверять наличие Git-репозитория в корне проекта (или выше) и корректно обрабатывать ошибки выполнения команд.

**3. РЕАЛИЗАЦИЯ (L6 — КОД)**

Файл: `agents/tools/prompt_versioning.py`

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
prompt_versioning.py – автоматическое версионирование промптов через Git.
Запускается по расписанию или после изменений в папке промптов.
"""

import os
import re
import subprocess
import logging
from pathlib import Path
from datetime import datetime

PROMPT_DIR = Path("00_КАНОН/ПРОМПТЫ")
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/git_prompts.log")
PROJECT_ROOT = Path.cwd()  # предполагается запуск из корня проекта
GIT_DIR = PROJECT_ROOT / ".git"

# Создаём директорию для логов
LOG_FILE.parent.mkdir(parents=True, exist_ok=True)

logging.basicConfig(
    filename=LOG_FILE,
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

def run_git_command(cmd, cwd=None):
    """Выполняет git-команду и возвращает stdout. При ошибке возвращает None."""
    if cwd is None:
        cwd = PROJECT_ROOT
    try:
        result = subprocess.run(cmd, cwd=cwd, capture_output=True, text=True, check=True)
        return result.stdout.strip()
    except subprocess.CalledProcessError as e:
        logging.error(f"Git command {' '.join(cmd)} failed: {e.stderr}")
        return None

def check_git_repo():
    """Проверяет наличие git-репозитория в корне проекта."""
    if not GIT_DIR.exists():
        logging.error("Git repository not found in project root.")
        return False
    return True

def get_changed_prompt_files():
    """
    Возвращает список изменённых файлов .md в PROMPT_DIR (исключая prompt_hashes.json).
    Использует 'git status --porcelain' для определения изменений.
    """
    status = run_git_command(["git", "status", "--porcelain", str(PROMPT_DIR)])
    if status is None:
        logging.error("Failed to get git status.")
        return []
    if not status.strip():
        return []

    changed = []
    for line in status.splitlines():
        # Формат: XY file_path (X - статус в индексе, Y - в рабочей копии)
        parts = line.strip().split()
        if len(parts) < 2:
            continue
        file_path = parts[1]
        # Проверяем, что файл находится в PROMPT_DIR и имеет расширение .md, исключая хеш-файл
        full_path = Path(file_path).resolve()
        if PROMPT_DIR.resolve() in full_path.parents and full_path.suffix == ".md" and full_path.name != "prompt_hashes.json":
            changed.append(file_path)
    return changed

def get_last_tag():
    """Возвращает последний тег, соответствующий шаблону prompts-* с числовым суффиксом."""
    tags_output = run_git_command(["git", "tag", "-l", "prompts-*"])
    if not tags_output:
        return None
    tags = tags_output.splitlines()
    # Фильтруем теги, соответствующие шаблону: prompts-YYYY-MM-DD-N
    pattern = re.compile(r'^prompts-\d{4}-\d{2}-\d{2}-\d+$')
    valid_tags = [t for t in tags if pattern.match(t)]
    if not valid_tags:
        return None
    # Сортируем по дате и номеру (лексикографически достаточно)
    valid_tags.sort(reverse=True)
    return valid_tags[0]

def create_new_tag():
    """Создаёт новый тег на основе текущей даты и инкремента."""
    today = datetime.now().strftime("%Y-%m-%d")
    base_tag = f"prompts-{today}"
    # Проверяем, сколько уже тегов с этим префиксом
    existing_tags = run_git_command(["git", "tag", "-l", f"{base_tag}-*"])
    if existing_tags:
        count = len(existing_tags.splitlines())
        new_tag = f"{base_tag}-{count+1}"
    else:
        new_tag = f"{base_tag}-1"
    return new_tag

def commit_and_tag(changed_files):
    """Добавляет изменения, коммитит и создаёт тег."""
    # Добавляем только изменённые .md файлы
    for file in changed_files:
        run_git_command(["git", "add", file])

    # Формируем сообщение коммита
    file_list = "\n".join(changed_files)
    commit_msg = f"Auto-update prompts\n\nChanged files:\n{file_list}"
    if run_git_command(["git", "commit", "-m", commit_msg]) is None:
        logging.error("Commit failed.")
        return False

    # Создаём тег
    tag = create_new_tag()
    if run_git_command(["git", "tag", tag]) is None:
        logging.error(f"Tag creation failed for {tag}")
        return False

    logging.info(f"Committed and tagged as {tag}")
    return True

def check_and_version():
    """Основная функция: проверяет изменения и версионирует."""
    if not check_git_repo():
        return

    changed = get_changed_prompt_files()
    if not changed:
        logging.info("No changes in prompts directory (excluding hash file).")
        return

    logging.info(f"Changed files: {changed}")
    if commit_and_tag(changed):
        logging.info("Versioning completed successfully.")
    else:
        logging.error("Versioning failed.")

if __name__ == "__main__":
    check_and_version()
```

**4. КРИТЕРИЙ ПРИЕМКИ (DoD)**  
- Скрипт `prompt_versioning.py` создан и размещён в `agents/tools/`.  
- При наличии изменений в любом `.md`-файле папки `00_КАНОН/ПРОМПТЫ/` (кроме `prompt_hashes.json`) скрипт автоматически создаёт коммит с описанием изменённых файлов и тег вида `prompts-YYYY-MM-DD-N`.  
- Файл `prompt_hashes.json` **не попадает** в коммиты и теги (проверяется отсутствием в списке изменённых).  
- При отсутствии Git-репозитория или ошибках выполнения команд скрипт корректно логирует проблему и завершается без повреждения данных.  
- Все операции логируются в `git_prompts.log`, директория для логов создаётся автоматически.  
- Скрипт может быть запущен вручную или по расписанию (например, через cron или планировщик фабрики).  
- Интеграция с `prompt_builder.py` сохранена: после изменения промпта необходимо вручную или автоматически обновить эталонные хеши (например, перезапустив `prompt_builder.py`, который при первом обнаружении несоответствия потребует обновления). Это оставляет контроль за целостностью.
