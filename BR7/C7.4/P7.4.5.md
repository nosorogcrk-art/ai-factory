
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P7.4.5 (LEVEL 5)

**ID:** P7.4.5  
**Контейнер:** C7.4 (Skill Integrator)  
**Название:** Полноценная интеграция с BR17 (учёт allowed_for_swarm)  

**Зависимости:** P17.5.5 (Skill Publisher с логированием) и P7.4.4

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить в процесс выдачи навыков проверку прав доступа на основе типа агента (`agent_type`). Для агентов типа `swarm` должны возвращаться только те навыки, у которых в метаданных установлен флаг `allowed_for_swarm: true`. Также необходимо получать навыки не только по ID, но и через Publisher (C17.5) для учёта версий и кэширования. Это обеспечит безопасность и актуальность выдаваемых инструкций.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Модифицируемый файл:** `agents/tools/skill_integrator.py`.  
- **Интеграция с C17.5 (Skill Publisher):**  
  – Адрес C17.5 задаётся переменной окружения `SKILL_PUBLISHER_URL` (по умолчанию `http://c17.5:8092`).  
  – Для получения навыков по ID использовать эндпоинт `GET /skill/{id}` с параметром `agent_type`.  
  – Для пакетного получения нескольких навыков – `POST /skills/batch` (если реализовано).  
- **Учёт флага `allowed_for_swarm`:**  
  – При запросе с `agent_type = "swarm"` необходимо передавать этот параметр в C17.5, чтобы Publisher сам отфильтровал навыки. Если Publisher не поддерживает фильтрацию, можно сначала получить навык, а затем проверить флаг на стороне интегратора. Рекомендуется использовать фильтрацию на стороне Publisher.  
- **Алгоритм:**  
  1. На этапе выбора навыков (после точного сопоставления и семантического поиска) формируется список ID.  
  2. Для получения полных данных навыков (инструкции, версии, метаданные) вызывается C17.5 (batch-запрос, если возможно).  
  3. При получении ответа от C17.5 проверяется, что для `agent_type = "swarm"` все возвращённые навыки имеют `allowed_for_swarm: true`. Если какой-то навык не удовлетворяет условию, он исключается из результата, и в `warnings` добавляется предупреждение.  
  4. Если C17.5 поддерживает параметр `agent_type`, то фильтрация происходит на его стороне, и интегратору остаётся только объединить результаты.  
- **Логирование:**  
  – Запросы к C17.5 логируются в `skill_integrator.log`.  
  – Если навык исключён из-за несоответствия `allowed_for_swarm`, это фиксируется в логе и в поле `warnings` ответа.  
- **Обработка ошибок:**  
  – При недоступности C17.5 возвращать ошибку 503 (или, возможно, использовать запасной вариант – но лучше жёстко требовать Publisher).  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- В функции `compile_prompt` после формирования списка ID навыков (из точного и семантического поиска) вызвать функцию `fetch_skills_from_publisher(skill_ids, agent_type)`.  
- Эта функция отправляет batch-запрос в C17.5 и возвращает список объектов навыков с метаданными.  
- Затем применить фильтрацию по `allowed_for_swarm`, если `agent_type == "swarm"` и Publisher не отфильтровал.  
- Сформировать ответ, включив предупреждения.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При запросе с `agent_type = "swarm"` возвращаются только навыки с `allowed_for_swarm = true`.  
- При запросе с `agent_type = "main"` возвращаются все навыки (без фильтрации).  
- Если среди запрошенных навыков есть неподходящие для swarm, они не включаются в ответ, и в поле `warnings` появляется соответствующее сообщение.  
- Все запросы к C17.5 логируются.  
- При недоступности C17.5 возвращается ошибка 503.
