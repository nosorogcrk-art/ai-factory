### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P7.2.2 (LEVEL 5) – ИСПРАВЛЕННАЯ ВЕРСИЯ

**ID:** P7.2.2 | **Контейнер:** C7.2 | **Название:** Модуль эстафеты (handover.py)

**1. ЗАМЫСЕЛ ПАТЧА**  
Реализация программного интерфейса для управления переходами задач между статусами и агентами. Модуль принимает команды (take, complete, delegate и др.), проверяет их допустимость согласно модели статусов, обновляет реестр задач и фиксирует каждое событие в журнале передачи ответственности. Это ядро протоколов SAD Logic.

**2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ**

- **Зависимости:**
  - Патч P7.2.1 должен быть выполнен (существование файлов `task_model.json` и `task_registry.json`).
- **Входные данные:** команда в формате JSON, содержащая поля:
  - `command` (строка): `take`, `complete`, `delegate`, `block`, `unblock`.
  - `task_id` (строка): идентификатор задачи.
  - `actor` (строка): роль агента, выполняющего команду.
  - `comment` (строка, опционально): пояснение.
  - Для `delegate` также поле `target` (строка) – кому передаётся задача.
- **Выходные данные:** JSON-объект с полями:
  - `success` (bool): успешность операции.
  - `error` (строка, опционально): описание ошибки.
  - `new_status` (строка, опционально): новый статус задачи.
- **Правила проверки:**
  - Задача должна существовать в реестре (для новых задач создаётся запись при команде `take`).
  - Переход должен быть разрешён в `task_model.json` для данной роли (кроме `delegate`, где статус не меняется).
  - Для `delegate`:
    - Задача должна находиться в статусе `IN_PROGRESS`.
    - Актёр должен быть текущим исполнителем задачи или Аргусом.
    - Статус задачи не изменяется, меняется только поле `assigned_to` на целевую роль.
- **Журнал эстафеты:** файл `01_ЦЕХ/01_ЖУРНАЛЫ/ЭСТАФЕТА.md`. Каждая запись добавляется в конец в формате Markdown:
  ```markdown
  ### [timestamp] – Задача [[task_id]]
  - **Действие:** take / complete / delegate / block / unblock
  - **Актёр:** роль
  - **Комментарий:** текст
  - **Новый статус:** статус
  ```
  Для `delegate` также указывается `Цель: роль`.
- **Обработка `unblock`:** задача переводится в статус `NEW` (в будущем может быть реализовано восстановление предыдущего статуса, если требуется).
- **Безопасность при параллельных вызовах:** в текущей реализации используется простая перезапись файла реестра. При одновременных вызовах возможны конфликты. Для производственной среды рекомендуется добавить файловую блокировку (например, через `fcntl.flock`), но на данном этапе это не критично при условии, что команды поступают последовательно от Аргуса.

**3. РЕАЛИЗАЦИЯ (L6 — КОД)**

Файл: `agents/tools/handover.py`

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
handover.py – модуль передачи ответственности (SAD Logic).
Обрабатывает команды смены статуса задач, ведёт журнал и реестр.
"""

import json
import sys
import argparse
from pathlib import Path
from datetime import datetime
from typing import Dict, Any, Optional

# Пути к файлам
MODEL_PATH = Path("00_КАНОН/ПРОЦЕССЫ/task_model.json")
REGISTRY_PATH = Path("01_ЦЕХ/ТЕКУЩИЕ_ЗАДАЧИ/task_registry.json")
LOG_PATH = Path("01_ЦЕХ/01_ЖУРНАЛЫ/ЭСТАФЕТА.md")

# Убедимся, что папки существуют
LOG_PATH.parent.mkdir(parents=True, exist_ok=True)

def load_json(path):
    with open(path, "r", encoding="utf-8") as f:
        return json.load(f)

def save_json(path, data):
    with open(path, "w", encoding="utf-8") as f:
        json.dump(data, f, indent=2, ensure_ascii=False)

def log_event(task_id, action, actor, comment, new_status, target=None):
    """Добавляет запись в журнал эстафеты."""
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    entry = f"\n### {timestamp} – Задача [[{task_id}]]\n"
    entry += f"- **Действие:** {action}\n"
    entry += f"- **Актёр:** {actor}\n"
    if comment:
        entry += f"- **Комментарий:** {comment}\n"
    entry += f"- **Новый статус:** {new_status}\n"
    if target:
        entry += f"- **Цель:** {target}\n"
    with open(LOG_PATH, "a", encoding="utf-8") as f:
        f.write(entry)

def is_transition_allowed(model, from_status, to_status, actor):
    """Проверяет по модели, разрешён ли переход для данной роли."""
    for t in model.get("transitions", []):
        if (t["from"] == from_status or t["from"] == "*") and t["to"] == to_status:
            allowed = t.get("allowed_roles", [])
            if "*" in allowed or actor in allowed:
                return True
    return False

def handle_command(cmd):
    """Основная функция обработки команды."""
    command = cmd.get("command")
    task_id = cmd.get("task_id")
    actor = cmd.get("actor")
    comment = cmd.get("comment", "")

    if not command or not task_id or not actor:
        return {"success": False, "error": "Missing required fields"}

    # Загружаем модель и реестр
    try:
        model = load_json(MODEL_PATH)
        registry = load_json(REGISTRY_PATH)
    except Exception as e:
        return {"success": False, "error": f"Failed to load model/registry: {e}"}

    # Находим задачу в реестре или создаём новую, если команда take и задачи нет
    task = next((t for t in registry if t["id"] == task_id), None)
    if command == "take" and task is None:
        # Новая задача
        task = {
            "id": task_id,
            "status": "NEW",
            "assigned_to": None,
            "created_at": datetime.now().isoformat(),
            "updated_at": datetime.now().isoformat(),
            "history": []
        }
        registry.append(task)
    elif task is None:
        return {"success": False, "error": f"Task {task_id} not found"}

    old_status = task["status"]

    # Определяем целевой статус в зависимости от команды
    target_status = None
    target_role = None

    if command == "take":
        target_status = "IN_PROGRESS"
        task["assigned_to"] = actor
    elif command == "complete":
        target_status = "ON_REVIEW"
    elif command == "delegate":
        target_role = cmd.get("target")
        if not target_role:
            return {"success": False, "error": "delegate requires target role"}
        # Проверяем, что задача в работе и актёр имеет право (текущий исполнитель или Аргус)
        if old_status != "IN_PROGRESS":
            return {"success": False, "error": "Can only delegate a task that is in progress"}
        if task["assigned_to"] != actor and actor != "АРГУС":
            return {"success": False, "error": "Only the current assignee or ARGUS can delegate"}
        # Меняем исполнителя, статус не меняется
        task["assigned_to"] = target_role
        target_status = old_status  # остаётся IN_PROGRESS
    elif command == "block":
        target_status = "BLOCKED"
    elif command == "unblock":
        target_status = "NEW"  # упрощённо, в будущем можно хранить предыдущий статус
    else:
        return {"success": False, "error": f"Unknown command: {command}"}

    # Проверяем переход, если статус изменился
    if target_status != old_status:
        if not is_transition_allowed(model, old_status, target_status, actor):
            return {"success": False, "error": f"Transition from {old_status} to {target_status} not allowed for {actor}"}
    else:
        # Для delegate (статус не меняется) дополнительная проверка не требуется
        pass

    # Обновляем задачу (если статус изменился)
    if target_status != old_status:
        task["status"] = target_status
    task["updated_at"] = datetime.now().isoformat()
    task["history"].append({
        "timestamp": datetime.now().isoformat(),
        "from": old_status,
        "to": target_status,
        "actor": actor,
        "comment": comment
    })

    # Сохраняем реестр
    try:
        save_json(REGISTRY_PATH, registry)
    except Exception as e:
        return {"success": False, "error": f"Failed to save registry: {e}"}

    # Логируем событие
    log_event(task_id, command, actor, comment, target_status, target_role)

    return {"success": True, "new_status": target_status}

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--command", required=True, help="Command: take/complete/delegate/block/unblock")
    parser.add_argument("--task-id", required=True, help="Task ID")
    parser.add_argument("--actor", required=True, help="Role of the actor")
    parser.add_argument("--comment", default="", help="Optional comment")
    parser.add_argument("--target", help="Target role for delegate")
    args = parser.parse_args()

    cmd = {
        "command": args.command,
        "task_id": args.task_id,
        "actor": args.actor,
        "comment": args.comment,
    }
    if args.target:
        cmd["target"] = args.target

    result = handle_command(cmd)
    print(json.dumps(result, ensure_ascii=False, indent=2))
    if not result["success"]:
        sys.exit(1)

if __name__ == "__main__":
    main()
```

**4. КРИТЕРИЙ ПРИЕМКИ (DoD)**  
- Скрипт `handover.py` создан и размещён в `agents/tools/`.  
- При запуске с корректными параметрами он:
  - Обновляет статус задачи в `task_registry.json` (кроме `delegate`, где меняется только исполнитель).
  - Добавляет запись в журнал `ЭСТАФЕТА.md`.
  - Возвращает JSON с `success: true` и новым статусом.
- Проверяет допустимость переходов согласно модели из `task_model.json`.
- Для `delegate` корректно обрабатывает смену исполнителя без изменения статуса, проверяя, что задача в статусе `IN_PROGRESS` и актёр имеет право.
- При ошибках (недопустимый переход, отсутствие задачи, неверная команда) возвращает `success: false` и описание ошибки.
- Журнал эстафеты имеет корректный Markdown-формат.
- Скрипт может быть вызван из командной строки с параметрами (для тестирования и интеграции).
