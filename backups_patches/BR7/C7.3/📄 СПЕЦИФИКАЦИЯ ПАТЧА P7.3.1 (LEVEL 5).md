### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P7.3.1 (LEVEL 5) – ИСПРАВЛЕННАЯ ВЕРСИЯ

**ID:** P7.3.1 | **Контейнер:** C7.3 | **Название:** Библиотека шаблонов для микро-агентов

**1. ЗАМЫСЕЛ ПАТЧА**  
Создание набора типовых шаблонов промптов, которые будут использоваться для генерации временных микро-агентов под конкретные задачи. Шаблоны параметризуются контекстом (например, код для рефакторинга, текст для проверки орфографии и т.д.) и содержат встроенные ограничения (доступ только к внутренним ресурсам, бюджет вызовов).

**2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ**

- **Хранение шаблонов:** директория `00_КАНОН/Шаблоны/Специалисты/` с файлами в формате JSON. Каждый шаблон содержит:
    
    - `name` – название шаблона.
        
    - `description` – краткое описание.
        
    - `prompt` – текст промпта с заполнителями вида `{{key}}`.
        
    - _**`constraints` – объект с ограничениями:**_
        
        - `internal_only` (bool) – запрет доступа к внешним ресурсам.
            
        - `max_calls` (int) – максимальное количество вызовов инструментов (бюджет).
            
    - `output_format` – ожидаемый формат результата.
        
    - `created_at` – дата создания.
        
- _**В текст промпта добавляется инструкция:**_ _«Ты работаешь только с внутренними данными, внешние ресурсы недоступны. Уложись в лимит вызовов: {{max_calls}}»._
    
- **Типовые задачи (начальный набор):**
    
    - `refactor_function.json` – рефакторинг одной функции.
        
    - `spell_check.json` – проверка орфографии.
        
    - `generate_tests.json` – генерация модульных тестов.
        
    - `code_review.json` – краткое ревью кода.
        
    - `summarize.json` – краткое изложение документации.
        

**3. РЕАЛИЗАЦИЯ (L6 — КОД)**

Пример шаблона `refactor_function.json`:

json

{
  "name": "Рефакторинг функции",
  "description": "Улучшает читаемость и структуру одной функции без изменения логики.",
  "prompt": "Ты — микро-агент, специалист по рефакторингу. Ты работаешь только с внутренними данными, внешние ресурсы недоступны. Уложись в лимит вызовов: {{max_calls}}. Тебе дана функция из файла {{target_file}}:\n```python\n{{context}}\n```\nТвоя задача: переписать эту функцию, улучшив её читаемость, разбив на более мелкие части (если это разумно), добавив комментарии и приведя в соответствие с PEP8. Не меняй внешнее поведение функции. Верни только исправленный код функции в том же языке программирования.",
  "constraints": {
    "internal_only": true,
    "max_calls": 5
  },
  "output_format": "код функции",
  "created_at": "2026-03-17"
}

Аналогично создаются остальные шаблоны.

Скрипт инициализации `init_templates.py` (не входит в патч, но может быть создан) заполняет директорию этими шаблонами. Для простоты в рамках патча достаточно создать JSON-файлы вручную или через простой скрипт.

**4. КРИТЕРИЙ ПРИЕМКИ (DoD)**

- Директория `00_КАНОН/Шаблоны/Специалисты/` создана и содержит как минимум 5 шаблонов.
    
- Каждый шаблон имеет корректную JSON-структуру с полями `name`, `description`, `prompt`, `constraints`, `output_format`, `created_at`.
    
- В промпте присутствует инструкция об ограничениях (internal only, budget).
    
- Шаблоны готовы к использованию менеджером (P7.3.2).
