### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P7.3.3 (LEVEL 5)

**ID:** P7.3.3 | **Контейнер:** C7.3 | **Название:** Автоочистка (auto_cleanup.py)

**1. ЗАМЫСЕЛ ПАТЧА**  
Автоматическое удаление временных файлов, устаревших отчётов и завершённых микро-агентов. Гарантирует, что система не засоряется мусором от работы роя специалистов.

**2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ**

- **Что удаляется:**
    
    - Временные скрипты агентов (в `/tmp`) старше 1 часа.
        
    - Файлы ответов старше N дней (настраивается) в папке `ОТВЕТЫ_СПЕЦИАЛИСТОВ`.
        
- **Конфигурация:** файл `00_КАНОН/ПРОЦЕССЫ/cleanup_config.json`:
    
    json
    
    {
      "response_retention_days": 7,
      "temp_file_pattern": "agent_*.py"
    }
    
- **Механизм:** скрипт `auto_cleanup.py` запускается периодически (например, раз в день), проверяет возраст файлов и удаляет устаревшие.
    

**3. РЕАЛИЗАЦИЯ (L6 — КОД)**

Файл: `agents/tools/auto_cleanup.py`

python

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
auto_cleanup.py – очистка временных файлов и устаревших отчётов роя специалистов.
"""
import os
import time
import json
import logging
from pathlib import Path
from datetime import datetime, timedelta
RESPONSES_DIR = Path("01_ЦЕХ/01_ЖУРНАЛЫ/ОТВЕТЫ_СПЕЦИАЛИСТОВ")
CONFIG_PATH = Path("00_КАНОН/ПРОЦЕССЫ/cleanup_config.json")
TEMP_DIR = Path("/tmp")
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/cleanup.log")
LOG_FILE.parent.mkdir(parents=True, exist_ok=True)
logging.basicConfig(
    filename=LOG_FILE,
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)
def load_config():
    default = {
        "response_retention_days": 7,
        "temp_file_pattern": "agent_*.py"
    }
    if CONFIG_PATH.exists():
        with open(CONFIG_PATH, "r", encoding="utf-8") as f:
            return json.load(f)
    return default
def clean_responses(config):
    days = config.get("response_retention_days", 7)
    cutoff = datetime.now() - timedelta(days=days)
    if RESPONSES_DIR.exists():
        for file in RESPONSES_DIR.glob("*.json"):
            mtime = datetime.fromtimestamp(file.stat().st_mtime)
            if mtime < cutoff:
                file.unlink()
                logging.info(f"Removed old response: {file.name}")
def clean_temp_files(config):
    pattern = config.get("temp_file_pattern", "agent_*.py")
    for file in TEMP_DIR.glob(pattern):
        if time.time() - file.stat().st_mtime > 3600:  # старше 1 часа
            file.unlink()
            logging.info(f"Removed temp script: {file.name}")
def main():
    config = load_config()
    clean_responses(config)
    clean_temp_files(config)
if __name__ == "__main__":
    main()

**4. КРИТЕРИЙ ПРИЕМКИ (DoD)**

- Скрипт `auto_cleanup.py` создан.
    
- При запуске удаляет файлы ответов старше заданного срока и временные скрипты старше 1 часа.
    
- Конфигурационный файл может отсутствовать, используются значения по умолчанию.
    
- Все действия логируются.
    
- Скрипт может быть запущен по расписанию без вреда для работающих процессов.
