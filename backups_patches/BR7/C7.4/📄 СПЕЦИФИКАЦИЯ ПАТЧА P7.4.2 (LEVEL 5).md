
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P7.4.2 (LEVEL 5)

**ID:** P7.4.2  
**Контейнер:** C7.4 (Skill Integrator)  
**Название:** Точное сопоставление по метаданным (заглушка)  

**Зависимости:** P7.4.1  

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Расширить функциональность интегратора: добавить возможность поиска навыков по `task_type`, `language`, `agent_type` без явного указания ID. На данном этапе это заглушка: она не обращается к реальному хранилищу BR17, а возвращает фиктивные результаты на основе простых правил (например, для определённых комбинаций возвращает заранее заданные ID навыков). Это позволит в будущем легко заменить логику на реальные запросы к BR17.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Модифицируемый модуль:** `skill_integrator.py`.  
- **Новая функция:** `find_skills_by_metadata(task_type: str, language: str = None, agent_type: str = "main", limit: int = 5) -> List[str]`  
  – Заглушка: возвращает список ID навыков, соответствующих заданным критериям, на основе простой таблицы соответствий (можно захардкодить несколько примеров). Например:  
    - Если `task_type = "refactor"` и `language = "python"` → вернуть `["SKILL-042", "SKILL-101"]`.  
    - Если `task_type = "test"` → вернуть `["SKILL-999"]`.  
    - В остальных случаях вернуть пустой список.  
  - Учитывать `agent_type`: если `agent_type = "swarm"`, возможно, возвращать только навыки с флагом `allowed_for_swarm` (пока игнорировать).  
- **Модификация основной функции `compile_prompt`:**  
  - Если передан `required_skills`, использовать старую логику (P7.4.1).  
  - Если `required_skills` не передан, но передан `task_type`, вызывать `find_skills_by_metadata`, затем для полученных ID вызвать `compile_prompt` (уже существующую функцию) с этими ID.  
  - Параметр `limit` ограничивает количество возвращаемых навыков.  
- **Логирование:**  
  – В вызове `find_skills_by_metadata` логировать запрос и результат.  
  – В `compile_prompt` добавить логирование источника (явный список или найденные по метаданным).  

---

#### 3. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При вызове `compile_prompt` без `required_skills`, но с `task_type` (и опционально `language`), происходит вызов `find_skills_by_metadata`.  
- Функция `find_skills_by_metadata` возвращает предопределённые списки для известных комбинаций.  
- Для неизвестных комбинаций возвращается пустой список, и `compile_prompt` возвращает пустой промпт с предупреждением.  
- Логирование добавлено.  
- Все изменения совместимы с P7.4.1 (т.е. старый способ с явным списком продолжает работать).
