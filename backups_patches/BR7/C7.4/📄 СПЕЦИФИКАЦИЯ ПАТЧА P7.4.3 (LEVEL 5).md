
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P7.4.3 (LEVEL 5)

**ID:** P7.4.3  
**Контейнер:** C7.4 (Skill Integrator)  
**Название:** REST API для интегратора (заглушка)  

**Зависимости:** P7.4.2  

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Создать HTTP-сервис на базе FastAPI, который будет предоставлять эндпоинт `/compile` для внешних вызовов (например, от C7.3). Сервис использует функции из `skill_integrator.py`, оборачивая их в REST API с валидацией через Pydantic. На данном этапе это заглушка, но она должна быть полностью функциональна и готова к замене реальной логики.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Создаваемые файлы:**  
  - `api.py` – FastAPI-приложение.  
  - `models.py` – Pydantic-модели для запросов и ответов.  
- **Эндпоинт:** `POST /compile`  
  - **Тело запроса** (JSON):  
    ```json
    {
      "task_type": "refactor",
      "agent_type": "swarm",
      "language": "python",
      "context": "оптимизировать функцию быстрой сортировки",
      "required_skills": ["SKILL-042", "SKILL-101"],
      "limit": 3
    }
    ```  
    Все поля, кроме `task_type`, опциональны (но `required_skills` и `limit` несовместимы? По логике, если передан `required_skills`, остальные игнорируются. Нужно отразить в модели).  
  - **Валидация:** Pydantic проверяет типы, обязательность `task_type`.  
  - **Ответ:** JSON в формате:  
    ```json
    {
      "prompt": "объединённый текст инструкций",
      "used_skills": ["SKILL-042", "SKILL-101"],
      "warnings": ["skill integrator is a stub"],
      "total_matched": 2,
      "returned": 2
    }
    ```  
- **Обработка запроса:**  
  – Извлекаются параметры, вызывается функция `compile_prompt` из модуля `skill_integrator`.  
  – Возвращается результат в виде JSON.  
  – В случае ошибки (например, внутренняя ошибка) возвращается 500 с описанием.  
- **Логирование:**  
  – Каждый запрос логируется в локальный файл `api.log` (или через модуль логирования).  
  – Также можно добавить логирование в BR18 (пока заглушка, но в будущем).  
- **Запуск сервиса:**  
  – Сервис должен запускаться на порту 8090 (настраивается через переменную окружения `PORT`).  
  – Добавить healthcheck эндпоинт `/health`.  

---

#### 3. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- FastAPI-приложение запускается и отвечает на `POST /compile`.  
- При корректном запросе возвращается JSON с полями `prompt`, `used_skills`, `warnings`, `total_matched`, `returned`.  
- Если передан `required_skills`, ответ содержит все запрошенные навыки (заглушка).  
- Если передан только `task_type`, вызывается логика точного сопоставления (из P7.4.2) и возвращаются соответствующие навыки.  
- При невалидных данных возвращается 422 с описанием ошибок.  
- Логирование запросов работает.  
- Код соответствует стандартам PEP 8, содержит docstring и комментарии.
