### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P7.1.1 (LEVEL 5) – ИСПРАВЛЕННАЯ ВЕРСИЯ

**ID:** P7.1.1 | **Контейнер:** C7.1 | **Название:** Структура промптов (Prompt Directory Scaffold)

**1. ЗАМЫСЕЛ ПАТЧА**  
Создание базовой файловой структуры для хранения промптов и паспортов 7 базовых ролей, а также подготовка пустых шаблонов Markdown для каждой роли. Это фундамент, на котором будут строиться последующие патчи P7.1.2 и P7.1.3.

**2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ**

- **Целевая директория:** `00_КАНОН/ПРОМПТЫ/` (относительно корня проекта).
    
- **Имена файлов:** для каждой роли создаётся файл `<РОЛЬ>.md` (например, `ARGUS.md`, `ARCHI.md`, `REVA.md`, `HEFEST.md`, `HERMES.md`, `MNEMOSINA.md`, `DAEDALUS.md`).
    
- **Содержимое шаблона:** минимальный каркас, включающий разделы:
    
    - `# РОЛЬ: [Название]`
        
    - `## 1. ПАСПОРТ РОЛИ` (краткое описание, полномочия, границы)
        
    - `## 2. СИСТЕМНЫЙ ПРОМПТ` (инструкция для ИИ)
        
    - _**В системный промпт включены типовые фразы:**_  
        _«При работе сначала обращайся к внутренним документам в `00_КАНОН/` и `01_ЦЕХ/`. Если задача требует микро-агента, планируй количество шагов и не превышай лимит вызовов (бюджет).»_
        
    - `## 3. ТЕХНИЧЕСКИЕ ЛИМИТЫ` (токены, доступы, разрешённые инструменты)
        
    - `## 4. ИСТОРИЯ ИЗМЕНЕНИЙ` (заполняется позже)
        
- Все файлы должны быть доступны для чтения всем агентам, но для записи – только Аргусу и авторизованным разработчикам (права `644`).
    

**3. РЕАЛИЗАЦИЯ (L6 — КОД)**

Файл: `init_prompts.sh` (обновлённая версия)

bash

#!/bin/bash
# Файл: init_prompts.sh
# Создаёт структуру каталогов и шаблоны промптов для 7 ролей.
PROMPT_DIR="00_КАНОН/ПРОМПТЫ"
mkdir -p "$PROMPT_DIR"
# Шаблон для файла промпта
create_template() {
  local role=$1
  local file="$PROMPT_DIR/${role}.md"
  if [ ! -f "$file" ]; then
    cat > "$file" <<EOF
# РОЛЬ: ${role}
## 1. ПАСПОРТ РОЛИ
*(Заполняется на основе паспорта ветки BR7)*
**Ответственный:** 
**Полномочия:**
**Границы:**
## 2. СИСТЕМНЫЙ ПРОМПТ
*(Инструкция для ИИ-агента)*
Ты — ${role}. При работе сначала обращайся к внутренним документам в 00_КАНОН/ и 01_ЦЕХ/. Если задача требует микро-агента, планируй количество шагов и не превышай лимит вызовов (бюджет).
## 3. ТЕХНИЧЕСКИЕ ЛИМИТЫ
- **Максимальное количество токенов:** 
- **Разрешённые инструменты:** 
- **Доступ к папкам:** 
## 4. ИСТОРИЯ ИЗМЕНЕНИЙ
- YYYY-MM-DD: Создан шаблон (патч P7.1.1)
EOF
    echo "Created template for ${role}"
  else
    echo "Template for ${role} already exists, skipping."
  fi
}
# Список ролей
ROLES=("ARGUS" "ARCHI" "REVA" "HEFEST" "HERMES" "MNEMOSINA" "DAEDALUS")
for role in "${ROLES[@]}"; do
  create_template "$role"
done
# Установка прав доступа (чтение для всех, запись только для владельца)
chmod -R 644 "$PROMPT_DIR"/*
chmod 755 "$PROMPT_DIR"
echo "✅ Структура промптов инициализирована."

**4. КРИТЕРИЙ ПРИЕМКИ (DoD)**

- В папке `00_КАНОН/ПРОМПТЫ/` созданы файлы для всех 7 ролей.
    
- Каждый файл содержит минимальный каркас с разделами согласно техническим параметрам, включая типовые фразы о внутренних источниках и бюджетировании.
    
- Скрипт `init_prompts.sh` выполняется без ошибок и не перезаписывает существующие файлы (если они уже есть).
    
- Права доступа установлены корректно.
