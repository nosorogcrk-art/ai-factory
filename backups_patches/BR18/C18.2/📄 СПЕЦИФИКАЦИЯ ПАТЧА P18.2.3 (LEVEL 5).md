
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P18.2.3 (LEVEL 5)

**ID:** P18.2.3  
**Контейнер:** C18.2 (Metrics Dashboard)  
**Название:** API для получения метрик  

**Зависимости:** P18.2.2

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Предоставить HTTP-эндпоинты для получения текущих агрегированных значений и списка доступных метрик. Это позволит другим компонентам (например, C4.1 Dashboard) и пользователям просматривать состояние системы.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Эндпоинты:**  
  - `GET /api/metrics` – возвращает JSON со всеми агрегатами (ключ – имя метрики, значение – объект с агрегатами).  
  - `GET /api/metrics/{name}` – возвращает агрегаты для конкретной метрики. Если метрика не найдена – 404.  
  - `GET /api/metrics/list` – возвращает список доступных имён метрик.  
- **Формат ответа:**  
  ```json
  {
    "tasks_completed": {
      "mean": 125.3,
      "max": 500,
      "min": 0,
      "sum": 12345,
      "p95": 480,
      "last_update": "2026-03-18T12:00:00Z"
    }
  }
  ```  
- **Кэширование:** агрегаты уже хранятся в памяти, поэтому ответ формируется быстро.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Добавить эндпоинты, которые обращаются к глобальному словарю `aggregates`.  
- Для одиночной метрики проверить наличие и вернуть объект, иначе 404.  
- Логировать запросы.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- `GET /api/metrics` возвращает все агрегаты.  
- `GET /api/metrics/tasks_completed` возвращает агрегаты для этой метрики.  
- Для несуществующей метрики – 404.  
- Эндпоинт `/api/metrics/list` возвращает массив имён.
