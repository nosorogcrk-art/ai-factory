#### 1. ЗАМЫСЕЛ ПАТЧА  
Создать FastAPI-приложение для управления A/B-тестами. Реализовать CRUD-операции для экспериментов с хранением в SQLite. На данном этапе логика маршрутизации запросов, сбора метрик и анализа отсутствует (заглушки). Это позволит в дальнейшем интегрироваться с другими компонентами.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Стек:** Python + FastAPI, SQLite, Uvicorn.  
- **Порт:** 8104 (настраивается через переменную окружения `PORT`).  
- **База данных:** файл `/data/ab_tests.db` (монтируемый том).  
- **Таблица `experiments`:**  
  - `id` TEXT PRIMARY KEY (уникальный идентификатор эксперимента, генерируется при создании)  
  - `type` TEXT – `prompt` или `skill`  
  - `object_id` TEXT – идентификатор объекта (например, `prompt_argus_v1`)  
  - `control_version` TEXT – версия контроля  
  - `treatment_version` TEXT – версия эксперимента  
  - `traffic_split` REAL – доля трафика для экспериментальной версии (0..1)  
  - `target_metric` TEXT – целевая метрика (например, `success_rate`)  
  - `min_samples` INTEGER – минимальное количество наблюдений  
  - `status` TEXT – `created`, `running`, `completed`, `stopped`  
  - `started_at` TEXT (ISO)  
  - `completed_at` TEXT (ISO)  
  - `result` JSON – результаты анализа (p-value, улучшение и т.д.)  
- **API эндпоинты:**  
  - `POST /experiments` – создаёт эксперимент. Тело запроса содержит поля, кроме `id`, `status`, `started_at`, `completed_at`, `result`. Возвращает созданный объект с `id`.  
  - `GET /experiments` – возвращает список всех экспериментов (с пагинацией/фильтрацией опционально).  
  - `GET /experiments/{id}` – возвращает эксперимент по ID.  
  - `PUT /experiments/{id}` – полное обновление (обычно не нужно, но можно).  
  - `PATCH /experiments/{id}` – частичное обновление (например, для изменения статуса).  
  - `DELETE /experiments/{id}` – удаление эксперимента.  
  - `POST /experiments/{id}/stop` – досрочная остановка эксперимента (меняет статус).  
- **Валидация:** проверка, что `traffic_split` между 0 и 1, `type` одно из допустимых значений.  
- **Асинхронность:** создание эксперимента происходит синхронно, никаких фоновых задач пока нет.  
- **Локальное логирование:** все запросы записываются в файл `01_ЦЕХ/01_ЖУРНАЛЫ/ab_tester.log`.  
- **Эндпоинт /health** – возвращает `{"status": "ok"}`.
