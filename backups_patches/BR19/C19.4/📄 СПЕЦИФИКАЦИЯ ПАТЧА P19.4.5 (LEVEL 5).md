
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P19.4.5 (LEVEL 5)

**ID:** P19.4.5  
**Контейнер:** C19.4 (A/B Tester)  
**Название:** Логирование и отчётность  

**Зависимости:** P19.4.4

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить отправку логов о всех значимых событиях (создание эксперимента, завершение, результаты) в центральный лог-агрегатор C18.1. Также реализовать эндпоинты для получения отчётов по экспериментам (например, в формате JSON или CSV).

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Адрес C18.1:** переменная окружения `BR18_URL` (по умолчанию `http://br18:8080/api/logs`).  
- **Формат лога:**  
  ```json
  {
    "timestamp": "ISO 8601",
    "service": "C19.4",
    "event_type": "experiment_created | experiment_completed | experiment_stopped | deployment_triggered | error",
    "details": { ... }
  }
  ```  
- **События для логирования:**  
  – Создание эксперимента.  
  – Завершение эксперимента (с результатом).  
  – Запуск деплоя (успех/ошибка).  
  – Ошибки.  
- **API для отчётности:**  
  – `GET /experiments/{id}/report` – возвращает отчёт в формате JSON с деталями и результатами.  
  – `GET /experiments/export` – экспорт всех экспериментов в CSV.  
- **Асинхронность:** отправка логов через `BackgroundTasks`.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- В эндпоинтах создания и завершения вызывать `send_log`.  
- Добавить эндпоинты отчётности, читающие данные из БД.  
- Для CSV использовать стандартный модуль `csv`.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При каждом создании эксперимента отправляется лог.  
- При завершении – лог с результатами.  
- При деплое – лог.  
- Эндпоинты отчётности возвращают корректные данные.  
- Отправка логов асинхронна.
