### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P4.3.1 (LEVEL 5)

**ID:** P4.3.1  
**Контейнер:** C4.3 (Command Console)  
**Название:** Базовая форма и обработчик команд (эхо)

**Зависимости:** отсутствуют

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Создать веб-интерфейс консоли, содержащий текстовое поле для ввода команды, кнопку отправки и область для отображения ответа. На первом этапе серверная часть реализуется как заглушка (эхо): возвращает введённую команду в JSON. Это позволит проверить работу фронтенда и подготовить основу для будущей маршрутизации.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  
- **Маршрут:** `/console` – отдаёт HTML-страницу.  
- **Фронтенд:** HTML, CSS (Bootstrap), JavaScript.  
- **Эндпоинт API:** `POST /api/command` – принимает JSON `{"command": "..."}` и возвращает `{"status": "ok", "echo": "..."}`.  
- **Логирование:** запросы логируются в `01_ЦЕХ/01_ЖУРНАЛЫ/console_api.log`.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- В существующее FastAPI-приложение (или Flask) добавить маршрут `/console`, возвращающий HTML-страницу.  
- Добавить эндпоинт-заглушку `/api/command`.  
- HTML-страница содержит форму с JavaScript-обработчиком, отправляющим команду на `/api/command` и выводящим ответ.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При переходе на `/console` отображается страница с полем ввода, кнопкой и областью вывода.  
- При вводе команды и нажатии кнопки отправляется POST-запрос, в ответе приходит echo-команда.  
- Нет ошибок в консоли браузера.
