
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P4.2.4 (LEVEL 5)

**ID:** P4.2.4  
**Контейнер:** C4.2 (Graph Visualizer)  
**Название:** Интеграция с BR17 (граф навыков)  
**Зависимости:** P4.2.3  

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить поддержку отображения графа зависимостей навыков из BR17 (C17.3). API теперь будет поддерживать параметр `type` для выбора типа графа. Фронтенд сможет переключаться между семантическим графом и графом навыков.  

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  
- **Новый эндпоинт:** `GET /api/graph?type=skills` – возвращает граф зависимостей навыков, полученный из C17.3.  
- **Формат данных:** ожидается, что C17.3 предоставляет JSON в формате `{ nodes: [{ id, label, ... }], edges: [{ source, target }] }`.  
- **Преобразование:** при необходимости привести к единому формату (аналогично семантическому графу).  
- **Кэширование:** граф навыков также кэшируется.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  
- В `graph_api.py` добавить функцию `fetch_skill_graph()`, которая обращается к C17.3.  
- В эндпоинте `/api/graph` анализировать параметр `type` и возвращать соответствующий граф.  
- Если тип не указан или `semantic`, возвращать семантический граф (как ранее).  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  
- При запросе `/api/graph?type=skills` возвращается граф навыков.  
- Структура ответа совместима с ожидаемой фронтендом (узлы и рёбра).  
- При недоступности C17.3 возвращается пустой граф с предупреждением.  
- Кэширование работает.
