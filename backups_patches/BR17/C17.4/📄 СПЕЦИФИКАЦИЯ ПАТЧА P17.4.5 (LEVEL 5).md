
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P17.4.5 (LEVEL 5)

**ID:** P17.4.5  
**Контейнер:** C17.4 (Skill Tester)  
**Название:** Логирование в BR18  

**Зависимости:** P17.4.4

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить отправку результатов тестирования и ошибок в центральный лог-агрегатор BR18 (C18.1). Это обеспечит централизованный мониторинг качества навыков и возможность анализа в BR19.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Адрес BR18:** переменная окружения `BR18_URL` (по умолчанию `http://br18:8080/api/logs`).  
- **Формат лога:**  
  ```json
  {
    "timestamp": "ISO 8601 UTC",
    "service": "C17.4",
    "event_type": "skill_test",
    "details": {
      "skill_id": "SKILL-042",
      "test_case": "basic_case",
      "passed": true,
      "duration_ms": 1500,
      "error": null
    }
  }
  ```  
- **События для логирования:**  
  - Каждый завершённый тест (успешный или нет).  
  - Критические ошибки (например, недоступность Docker).  
- **Асинхронность:** отправка выполняется в фоновом режиме, не задерживая ответ клиента.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Добавить функцию `send_log(details, background_tasks)`.  
- В процессе выполнения тестов после каждого теста вызывать эту функцию.  
- При ошибках в самом сервисе также отправлять лог с типом `error`.  
- Обрабатывать ошибки отправки (логировать локально).  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При каждом тесте отправляется лог в BR18.  
- Лог содержит все обязательные поля.  
- При недоступности BR18 ошибка не влияет на выполнение теста, но логируется локально.  
- Отправка не блокирует основной поток.
