### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P17.2.1 (LEVEL 5)

**ID:** P17.2.1  
**Контейнер:** C17.2 (Skill Version Control)  
**Название:** Инициализация Git-репозитория  

**Зависимости:** отсутствуют

---

#### 1. ЗАМЫСЕЛ ПАТЧА
Создать базовую инфраструктуру для версионирования навыков: при запуске сервиса проверить наличие Git-репозитория в заданной директории и, если его нет, инициализировать новый пустой репозиторий. Это обеспечит место для хранения файлов навыков и их истории.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ

- **Хранилище:** репозиторий располагается в монтируемом томе `/data/skills-repo`.
- **Действия при старте:**
  - Проверить существование директории `/data/skills-repo`. Если нет – создать.
  - Проверить, является ли директория Git-репозиторием (наличие поддиректории `.git`).
  - Если не является – выполнить `git init` в этой директории.
- **Логирование:** записать в локальный лог-файл (`/data/skills-repo-init.log`) информацию о результате инициализации (успех/ошибка). Также дублировать в общий лог контейнера (stdout).
- **Интеграция с последующими патчами:** после инициализации репозиторий готов к приёму файлов навыков и коммитов.
- **Стек технологий:** Python + GitPython (или subprocess для вызова git). FastAPI-приложение (если сервис будет предоставлять API, но в этом патче только инициализация).

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ

- Создать файл `skill_version_control.py` (или добавить в существующий).
- При запуске приложения (в `main` или в событии `startup`) выполнить функцию `init_repo()`:
  - Импортировать `git` из GitPython.
  - Проверить путь.
  - Если не репозиторий, вызвать `git.Repo.init(path)`.
  - Логировать результат.
- Если репозиторий уже существует, ничего не делать (только залогировать).

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)

- При первом запуске контейнера в `/data/skills-repo` создаётся Git-репозиторий (появляется папка `.git`).
- При повторном запуске повторной инициализации не происходит.
- Логи содержат информацию о выполненном действии.
- Если директория не может быть создана (нет прав), сервис завершается с ошибкой (логирует и выходит).
