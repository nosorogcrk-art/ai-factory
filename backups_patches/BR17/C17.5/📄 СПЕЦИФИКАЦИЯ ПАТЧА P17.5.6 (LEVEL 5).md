
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P17.5.6 (LEVEL 5)

**ID:** P17.5.6  
**Контейнер:** C17.5 (Skill Publisher)  
**Название:** Проверка прав и тестирования (C17.4)  

**Зависимости:** P17.5.5

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить в процесс выдачи навыка проверку прав доступа на основе типа агента (`agent_type`) и флага `allowed_for_swarm` в метаданных навыка. Также опционально проверять статус тестирования навыка через C17.4 (Skill Tester) – выдавать только те навыки, которые успешно прошли тесты. Это обеспечит безопасность и качество выдаваемых агентам инструкций.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Параметр запроса:** `agent_type` (опционально, по умолчанию `"main"`). Может принимать значения `"main"` или `"swarm"`.  
- **Проверка прав:**  
  - Если `agent_type = "swarm"`, навык должен иметь поле `allowed_for_swarm = true`. Иначе возвращать ошибку 403 с сообщением.  
- **Проверка тестирования:**  
  - Если включена опция (например, переменная окружения `SKIP_SKILL_TEST_CHECK` = false), то перед выдачей навыка выполняется запрос к C17.4 для получения статуса тестирования.  
  - Адрес C17.4 задаётся переменной `SKILL_TESTER_URL` (по умолчанию `http://c17.4:8091`).  
  - Используется эндпоинт `GET /results/{skill_id}` или специальный эндпоинт для проверки статуса (если есть).  
  - Если навык не прошёл тесты (например, последний тест неуспешен), возвращать ошибку 403 с пояснением.  
- **Конфигурация:** добавить возможность отключать эти проверки для разработки.  
- **Логирование:** все отклонения логируются в BR18 и локально.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- В функции получения навыка после получения данных из реестра (или кэша) выполнить проверку `allowed_for_swarm`, если `agent_type == "swarm"`.  
- Затем, если проверка тестирования включена, выполнить асинхронный запрос к C17.4. Интерпретировать ответ (можно договориться о простом поле `overall == "passed"`).  
- При любой неудаче вернуть HTTP 403 с сообщением, не выдавая навык.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При запросе с `agent_type=swarm` для навыка, у которого `allowed_for_swarm=false`, возвращается 403.  
- При включённой проверке тестирования и неуспешном тесте возвращается 403.  
- При успешных проверках навык выдаётся нормально.  
- Все отказы логируются.
