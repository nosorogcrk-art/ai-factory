
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P17.5.5 (LEVEL 5)

**ID:** P17.5.5  
**Контейнер:** C17.5 (Skill Publisher)  
**Название:** Логирование в BR18  

**Зависимости:** P17.5.4

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить отправку логов о всех запросах к API публикатора в центральный лог-агрегатор BR18 (C18.1). Это обеспечит наблюдаемость использования навыков и позволит анализировать частоту запросов, популярность навыков и возможные ошибки.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Адрес BR18:** переменная окружения `BR18_URL` (по умолчанию `http://br18:8080/api/logs`).  
- **Формат лога:**  
  ```json
  {
    "timestamp": "ISO 8601 UTC",
    "service": "C17.5",
    "event_type": "skill_published",
    "details": {
      "skill_id": "SKILL-042",
      "version": "1.2.3",
      "agent_type": "main",
      "cached": true,
      "response_time_ms": 45
    }
  }
  ```  
- **События для логирования:**  
  - Каждый успешный запрос `GET /skill/...` и `POST /skills/batch` (для batch можно логировать как одно событие с указанием списка навыков).  
  - Ошибки (4xx, 5xx) с указанием причины.  
- **Асинхронность:** отправка выполняется в фоновом режиме (`BackgroundTasks` в FastAPI).  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Добавить функцию `send_log(event_type, details, background_tasks)`.  
- В каждом эндпоинте после обработки запроса (или при ошибке) вызывать эту функцию.  
- Для batch-запросов логировать общее время и количество запрошенных навыков.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При каждом запросе к API отправляется лог в BR18.  
- Лог содержит все обязательные поля.  
- При недоступности BR18 ошибка не влияет на ответ, но логируется локально.
