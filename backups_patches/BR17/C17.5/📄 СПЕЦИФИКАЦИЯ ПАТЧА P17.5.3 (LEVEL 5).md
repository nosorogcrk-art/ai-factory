
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P17.5.3 (LEVEL 5)

**ID:** P17.5.3  
**Контейнер:** C17.5 (Skill Publisher)  
**Название:** Поддержка версий и batch-запросов  

**Зависимости:** P17.5.2

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Расширить API возможностью запрашивать конкретную версию навыка (через параметр `version`), а также получать несколько навыков одним запросом (batch). Для получения старых версий необходимо обращаться к C17.2 (Skill Version Control). Пакетная выдача полезна для интегратора навыков (C7.4).

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Новые эндпоинты и параметры:**  
  1. `GET /skill/{skill_id}` – добавить опциональный query-параметр `version`. Если `version` указан, запросить эту версию у C17.2, иначе – последнюю активную из C17.1.  
  2. `POST /skills/batch` – тело запроса:  
     ```json
     {
       "skills": ["SKILL-042", "SKILL-101"],
       "agent_type": "main"
     }
     ```  
     Возвращает массив объектов навыков в том же порядке. Для каждого навыка применяется логика получения последней версии (или можно добавить параметр `version` индивидуально, но для простоты пока все последние).  
- **Интеграция с C17.2:**  
  - Адрес C17.2 задаётся переменной окружения `SKILL_VERSION_CONTROL_URL` (по умолчанию `http://c17.2:8089`).  
  - Для получения конкретной версии используется `GET /file/{skill_id}?ref={version}` (где `ref` может быть хешем коммита или тегом).  
- **Обработка ошибок:** если навык не найден ни в C17.1, ни в C17.2, в batch-запросе вместо объекта может быть `null` или поле `error`. Для простоты можно возвращать `null` для отсутствующих навыков.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- В функции `GET /skill/{skill_id}` добавить проверку наличия параметра `version`. Если есть – вызвать C17.2, иначе – C17.1.  
- Для batch-запроса реализовать конкурентные вызовы (asyncio.gather) для ускорения.  
- Возвращать массив, сохраняя порядок.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При запросе `GET /skill/SKILL-042?version=abc123` возвращается содержимое из C17.2.  
- При отсутствии версии или ошибке в C17.2 – 404.  
- `POST /skills/batch` возвращает массив с запрошенными навыками (если какие-то не найдены – на их месте `null`).  
- Логирование запросов к C17.2 работает.
