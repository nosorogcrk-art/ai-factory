### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P17.5.1 (LEVEL 5)

**ID:** P17.5.1  
**Контейнер:** C17.5 (Skill Publisher)  
**Название:** Базовая структура и API (заглушка)  

**Зависимости:** отсутствуют

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Создать каркас микросервиса для публикации навыков: FastAPI-приложение с заглушечными эндпоинтами для выдачи навыков по ID и получения статуса. На данном этапе все эндпоинты возвращают фиктивные ответы, что позволяет проверить работоспособность API и подготовить инфраструктуру для последующей интеграции с реестром навыков.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Стек:** Python + FastAPI, Uvicorn.  
- **Порт:** 8092 (настраивается через переменную окружения `PORT`).  
- **Эндпоинты-заглушки:**  
  - `GET /skill/{skill_id}` – принимает `skill_id`, возвращает фиктивный ответ:  
    ```json
    {
      "id": "SKILL-042",
      "version": "1.2.3",
      "name": "Stub Skill",
      "instruction": "Stub instruction",
      "dependencies": [],
      "metadata": {}
    }
    ```  
  - `GET /status` – возвращает `{"status": "ok", "service": "C17.5"}`.  
  - (Другие эндпоинты, например `POST /skills/batch`, пока не реализуются, но можно добавить заглушку с `501 Not Implemented`.)  
- **Логирование:** все запросы записываются в локальный лог-файл `01_ЦЕХ/01_ЖУРНАЛЫ/skill_publisher.log`.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Создать файл `skill_publisher.py` с FastAPI-приложением.  
- Определить Pydantic-модели для ответов (хотя бы минимальные).  
- Реализовать эндпоинты как простые функции, возвращающие фиксированные JSON-объекты.  
- Настроить логирование через `logging`.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- Приложение запускается на указанном порту.  
- При `GET /skill/SKILL-042` возвращается корректный JSON с заглушечными данными.  
- Эндпоинт `/status` возвращает `{"status": "ok", "service": "C17.5"}`.  
- Логи запросов пишутся в указанный файл.
