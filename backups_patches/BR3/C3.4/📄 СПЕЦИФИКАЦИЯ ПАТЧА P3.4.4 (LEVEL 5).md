
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P3.4.4 (LEVEL 5)

**ID:** P3.4.4  
**Контейнер:** C3.4 (Citations Agent)  
**Название:** Интеграция с новым API C2.3 (семантический поиск с метаданными)

**Зависимости:** P2.3.4 (доработка C2.3), P3.4.2 (предыдущая интеграция с семантическим поиском)

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Модифицировать Citations Agent для использования обновлённого API семантического поиска (C2.3), который теперь возвращает расширенные метаданные (источник, дата, тип, связанные сущности). Это позволит агенту более точно подбирать ссылки и обогащать их дополнительной информацией (например, помечать внешние источники, добавлять дату публикации). Также улучшается качество фильтрации результатов за счёт использования порога релевантности и метаданных.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Изменения в вызове C2.3:**  
  - Вместо простого поиска по тексту теперь используется эндпоинт `/search` с параметрами:  
    - `query` – текст блока.  
    - `k` – количество кандидатов (например, 5).  
    - `filters` – фильтры по метаданным (например, `{"source_type": "internal"}`).  
  - Ответ C2.3 содержит массив объектов с полями: `id`, `source`, `source_type`, `timestamp`, `title`, `related_entities`, `score`, `snippet`.  
- **Алгоритм работы агента:**  
  1. Разбить текст на блоки (абзацы).  
  2. Для каждого блока выполнить запрос к C2.3 с `k = max_links * 2` и фильтрами (если заданы).  
  3. Отфильтровать результаты по порогу `score >= threshold`.  
  4. Для каждого подходящего документа проверить, не ссылается ли уже блок на него (по наличию `[[id]]`). Если нет, добавить ссылку в конец блока. При этом можно добавить дополнительный текст, например, `[внешний источник: дата]`.  
  5. Использовать поле `related_entities` для поиска дополнительных связей (опционально, может быть включено в следующем патче).  
- **Конфигурация:**  
  - Добавить параметр `use_metadata` (bool) для включения/отключения обогащения ссылок метаданными.  
  - Параметр `show_source` (bool) – добавлять ли пометку об источнике (например, `[GitHub]`).  
- **Логирование:**  
  - Добавить в лог информацию о полученных метаданных (источники, даты) для отладки.

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- В `citations_agent.py` изменить функцию `add_semantic_citations`.  
- Заменить прямой вызов `search` на новый формат с фильтрами.  
- При формировании ссылки использовать метаданные: например, если `source_type == "external"`, добавить пометку `[внеш.]`.  
- Обновить обработку ответа: теперь результат – список словарей.  

**Пример:**  
```python
def add_semantic_citations(text, threshold=0.7, max_per_block=2):
    paragraphs = text.split('\n\n')
    new_paragraphs = []
    for para in paragraphs:
        if not para.strip():
            new_paragraphs.append(para)
            continue
        results = semantic_search(para, k=max_per_block*2, filters={"source_type": "internal"})
        links_added = 0
        for res in results:
            if res['score'] >= threshold and links_added < max_per_block:
                doc_id = res['id']
                if f"[[{doc_id}]]" not in para:
                    # обогащение метаданными
                    extra = ""
                    if res.get('source_type') == 'external':
                        extra = f" (источник: {res.get('source', 'внешний')})"
                    para += f" [[{doc_id}]]{extra}"
                    links_added += 1
        new_paragraphs.append(para)
    return '\n\n'.join(new_paragraphs)
```

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- Citations Agent при обработке текста вызывает обновлённый эндпоинт C2.3.  
- В ответе используются метаданные для обогащения ссылок (например, добавление пометок о внешних источниках).  
- Порог релевантности применяется корректно.  
- Логи содержат информацию о полученных метаданных.  
- Обратная совместимость: если C2.3 не поддерживает новый формат, агент должен корректно обрабатывать ошибку (например, использовать старый механизм).
