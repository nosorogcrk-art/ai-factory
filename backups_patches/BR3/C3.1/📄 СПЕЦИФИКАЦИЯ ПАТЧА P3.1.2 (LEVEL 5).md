### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P3.1.2 (LEVEL 5)

**ID:** P3.1.2 | **Контейнер:** C3.1 | **Название:** Золотой стандарт

**1. ЗАМЫСЕЛ ПАТЧА**  
Создание основополагающего документа «Золотой стандарт», определяющего единые правила и принципы работы для всех агентов системы. Документ фиксирует требования к качеству, безопасности, прослеживаемости и взаимодействию, служит источником истины для методологии.

**2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ**  
- **Расположение:** `00_КАНОН/Методология/КАНОНЫ/ЗОЛОТОЙ_СТАНДАРТ.md`.  
- **Обязательные разделы:**  
  - **1. ЦЕЛЬ** – зачем нужен Золотой стандарт.  
  - **2. ОБЩИЕ ПРИНЦИПЫ** – фундаментальные правила (прослеживаемость, атомарность, запрет на кодинг без спеки и т.д.).  
  - **3. ПРАВИЛА ДЛЯ АГЕНТОВ** – что разрешено и запрещено каждой роли.  
  - **4. ТРЕБОВАНИЯ К ДОКУМЕНТАЦИИ** – как оформлять артефакты.  
  - **5. КОНТРОЛЬ КАЧЕСТВА** – процедуры проверки.  
  - **6. ИСТОРИЯ ИЗМЕНЕНИЙ**.  
- Документ должен быть утверждён владельцем (метка `[[APPROVED]]`).

**3. РЕАЛИЗАЦИЯ (L6 — КОД)**  

Файл: `init_golden_standard.py`

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
init_golden_standard.py – создаёт базовую версию документа «Золотой стандарт».
"""

from pathlib import Path

GOLDEN_PATH = Path("00_КАНОН/Методология/КАНОНЫ/ЗОЛОТОЙ_СТАНДАРТ.md")

def create_golden_standard():
    if GOLDEN_PATH.exists():
        print(f"Golden standard already exists at {GOLDEN_PATH}")
        return

    GOLDEN_PATH.parent.mkdir(parents=True, exist_ok=True)

    content = """# ЗОЛОТОЙ СТАНДАРТ ЦИФРОВОЙ ФАБРИКИ

**Статус:** ЧЕРНОВИК (после утверждения заменить на УТВЕРЖДЁН)

## 1. ЦЕЛЬ
Обеспечить единообразие, качество и прослеживаемость всех процессов разработки.

## 2. ОБЩИЕ ПРИНЦИПЫ
- **Прослеживаемость (Traceability):** Каждая единица работы (патч) должна иметь «пуповину» к утверждённому замыслу.
- **Атомарность:** Патч изменяет не более 5 файлов и затрагивает только один слой.
- **Запрет на код без спеки:** Написание кода (L6) допускается только после утверждения спецификации L5.
- **Единый источник истины:** Все документы хранятся в структурированном виде в папке `00_КАНОН/` и версионируются через Git.

## 3. ПРАВИЛА ДЛЯ АГЕНТОВ
- **АРГУС:** Обладает правом вето, контролирует соблюдение канонов, назначает задачи.
- **АРХИ:** Проектирует архитектуру, создаёт ТЗ, следит за соответствием стандартам.
- **ГЕФЕСТ:** Реализует код строго по ТЗ, обязан писать тесты.
- **РЕВА:** Проверяет код на соответствие стандартам, возвращает на доработку при нарушениях.
- **ГЕРМЕС:** Обеспечивает инфраструктуру, контролирует порты и безопасность среды.
- **МНЕМОСИНА:** Ведёт память, индексирует смыслы, анализирует противоречия.
- **ДЕДАЛ:** Управляет мета-логикой, саморефлексией и развитием САГА.

## 4. ТРЕБОВАНИЯ К ДОКУМЕНТАЦИИ
- Каждый документ уровня L1–L5 должен иметь уникальный ID и ссылку на родительский документ.
- Обязательные поля: замысел, границы, состав узлов, валидация.
- Изменения фиксируются в истории версий.

## 5. КОНТРОЛЬ КАЧЕСТВА
- Автоматические проверки: линтеры, семантический анализ, сканирование уязвимостей.
- Ручное ревью для критических патчей (по усмотрению Аргуса).
- Периодический аудит Мнемосиной на целостность смыслов.

## 6. ИСТОРИЯ ИЗМЕНЕНИЙ
- 2026-03-17: Создан базовый документ (патч P3.1.2)

[[APPROVED]]  # Владелец должен убрать комментарий и оставить метку после утверждения
"""

    with open(GOLDEN_PATH, "w", encoding="utf-8") as f:
        f.write(content)

    print(f"Golden standard created at {GOLDEN_PATH}")

if __name__ == "__main__":
    create_golden_standard()
```

**4. КРИТЕРИЙ ПРИЕМКИ (DoD)**  
- Файл `ЗОЛОТОЙ_СТАНДАРТ.md` создан в указанной папке.  
- Содержит все обязательные разделы.  
- После утверждения владельцем в файле присутствует метка `[[APPROVED]]`.  
- Скрипт не перезаписывает существующий документ.
