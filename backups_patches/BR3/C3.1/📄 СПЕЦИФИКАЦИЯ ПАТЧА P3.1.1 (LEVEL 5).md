### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P3.1.1 (LEVEL 5)

**ID:** P3.1.1 | **Контейнер:** C3.1 | **Название:** Структура методологии

**1. ЗАМЫСЕЛ ПАТЧА**  
Создание базовой файловой структуры для хранения методологических документов и шаблонов уровней L1–L6, а также подготовка пустых шаблонов для каждого уровня. Это основа, на которой будут строиться все последующие методологические артефакты (Золотой стандарт, каноны, регламенты).

**2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ**  
- **Целевая директория:** `00_КАНОН/Методология/` (относительно корня проекта).  
- **Поддиректории:**  
  - `ШАБЛОНЫ/` – для хранения шаблонов уровней L1–L6.  
  - `КАНОНЫ/` – для Золотого стандарта и других канонов (будет заполняться позже).  
- **Имена файлов шаблонов:** для каждого уровня создаётся файл `ШАБЛОН_L1.md`, `ШАБЛОН_L2.md`, … `ШАБЛОН_L6.md`.  
- **Содержимое шаблона:** минимальный каркас, включающий разделы:  
  - `# Уровень L[1-6]: [Название]`  
  - `## 1. ЗАМЫСЕЛ`  
  - `## 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ`  
  - `## 3. РЕАЛИЗАЦИЯ`  
  - `## 4. КРИТЕРИЙ ПРИЕМКИ`  
  - `## 5. ИСТОРИЯ ИЗМЕНЕНИЙ`  
- Все файлы должны иметь права доступа `644` (чтение для всех, запись только для владельца).

**3. РЕАЛИЗАЦИЯ (L6 — КОД)**  

Файл: `init_methodology.sh`

```bash
#!/bin/bash
# init_methodology.sh – создаёт структуру методологии и шаблоны L1–L6

BASE_DIR="00_КАНОН/Методология"
TEMPLATES_DIR="$BASE_DIR/ШАБЛОНЫ"

mkdir -p "$TEMPLATES_DIR"

# Функция создания шаблона для уровня
create_template() {
  level=$1
  name=$2
  file="$TEMPLATES_DIR/ШАБЛОН_L$level.md"
  if [ ! -f "$file" ]; then
    cat > "$file" <<EOF
# Уровень L$level: $name

## 1. ЗАМЫСЕЛ
*(Опишите цель данного уровня)*

## 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
*(Перечислите ключевые параметры и требования)*

## 3. РЕАЛИЗАЦИЯ
*(Укажите, что должно быть создано на этом уровне)*

## 4. КРИТЕРИЙ ПРИЕМКИ
*(Как проверить, что уровень пройден успешно)*

## 5. ИСТОРИЯ ИЗМЕНЕНИЙ
- $(date +%Y-%m-%d): Создан шаблон (патч P3.1.1)
EOF
    echo "Created template for L$level"
  else
    echo "Template for L$level already exists, skipping."
  fi
}

create_template 1 "Идея"
create_template 2 "Продукт (Паспорт ветки)"
create_template 3 "Контейнеры"
create_template 4 "Патчи"
create_template 5 "Спецификация"
create_template 6 "Код (Реализация)"

# Установка прав доступа
chmod -R 644 "$TEMPLATES_DIR"/*
chmod 755 "$BASE_DIR" "$TEMPLATES_DIR"

echo "✅ Методологическая структура инициализирована."
```

**4. КРИТЕРИЙ ПРИЕМКИ (DoD)**  
- В папке `00_КАНОН/Методология/ШАБЛОНЫ/` созданы файлы для всех уровней L1–L6.  
- Каждый файл содержит минимальный каркас с указанными разделами.  
- Скрипт `init_methodology.sh` выполняется без ошибок и не перезаписывает существующие файлы.  
- Права доступа установлены корректно.
