### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P3.2.1 (LEVEL 5)

**ID:** P3.2.1 | **Контейнер:** C3.2 | **Название:** Базовая конфигурация конвейера

**1. ЗАМЫСЕЛ ПАТЧА**  
Создание эталонного JSON-файла, описывающего стандартный набор этапов производственного конвейера (Pipeline-16). Этот файл станет источником истины для оркестратора и других компонентов, определяя последовательность и параметры этапов разработки.

**2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ**  
- **Файл:** `00_КАНОН/Методология/pipeline_config.json`.  
- **Структура:** объект JSON с полями:  
  - `version` (строка) – версия конфигурации.  
  - `stages` (массив) – список этапов, каждый со следующими полями:  
    - `id` (строка) – уникальный идентификатор этапа (например, `L1_IDEA`, `L2_PASSPORT`, …).  
    - `name` (строка) – краткое название.  
    - `description` (строка) – пояснение.  
    - `required` (boolean) – обязателен ли этап для всех проектов.  
    - `timeout` (число, опционально) – максимальное время выполнения в секундах.  
    - `allowed_roles` (массив строк) – роли, которые могут выполнять этот этап.  
    - `next_stage` (строка или объект с условиями) – следующий этап по умолчанию.  
- **Набор этапов:** соответствует 16 этапам Pipeline-16 (можно сгруппировать по уровням L1–L6). Для простоты можно описать 16 последовательных этапов.  

**3. РЕАЛИЗАЦИЯ (L6 — КОД)**  

Создадим скрипт `init_pipeline_config.py`, который генерирует базовую конфигурацию.

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
init_pipeline_config.py – создаёт базовую конфигурацию конвейера (pipeline_config.json).
"""

import json
from pathlib import Path

CONFIG_PATH = Path("00_КАНОН/Методология/pipeline_config.json")

def create_base_config():
    if CONFIG_PATH.exists():
        print(f"Pipeline config already exists at {CONFIG_PATH}")
        return

    CONFIG_PATH.parent.mkdir(parents=True, exist_ok=True)

    config = {
        "version": "1.0",
        "stages": [
            {"id": "L1_IDEA", "name": "Идея", "description": "Сбор первичных смыслов", "required": True, "allowed_roles": ["АРГУС"]},
            {"id": "L2_PASSPORT", "name": "Паспорт ветки", "description": "Определение границ и целей", "required": True, "allowed_roles": ["АРХИ"]},
            {"id": "L3_CONTAINERS", "name": "Контейнеры", "description": "Разбиение на функциональные узлы", "required": True, "allowed_roles": ["АРХИ"]},
            {"id": "L4_PATCHES", "name": "Патчи", "description": "Атомарная нарезка", "required": True, "allowed_roles": ["АРГУС", "АРХИ"]},
            {"id": "L5_SPEC", "name": "Спецификация", "description": "Создание детального ТЗ", "required": True, "allowed_roles": ["АРХИ", "ГЕФЕСТ"]},
            {"id": "L6_CODE", "name": "Код", "description": "Написание кода", "required": True, "allowed_roles": ["ГЕФЕСТ"]},
            # Далее можно продолжить с этапами проверки, интеграции и т.д. (до 16)
            {"id": "REVIEW", "name": "Ревью", "description": "Проверка кода Ревой", "required": True, "allowed_roles": ["РЕВА"]},
            {"id": "REWORK", "name": "Доработка", "description": "Исправление замечаний", "required": False, "allowed_roles": ["ГЕФЕСТ"]},
            {"id": "INTEGRATION", "name": "Интеграция", "description": "Сборка и тестирование", "required": True, "allowed_roles": ["ГЕРМЕС"]},
            {"id": "DEPLOY", "name": "Деплой", "description": "Развёртывание", "required": False, "allowed_roles": ["ГЕРМЕС"]},
            {"id": "ARCHIVE", "name": "Архивация", "description": "Перенос в архив", "required": True, "allowed_roles": ["МНЕМОСИНА"]}
        ]
    }

    with open(CONFIG_PATH, "w", encoding="utf-8") as f:
        json.dump(config, f, indent=2, ensure_ascii=False)

    print(f"Pipeline config created at {CONFIG_PATH}")

if __name__ == "__main__":
    create_base_config()
```

**4. КРИТЕРИЙ ПРИЕМКИ (DoD)**  
- Файл `pipeline_config.json` создан в указанной папке.  
- Содержит как минимум 10 этапов, включая ключевые из Pipeline-16.  
- JSON-структура валидна и соответствует описанию.  
- Скрипт не перезаписывает существующий файл.
