
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P20.3.2 (LEVEL 5)

**ID:** P20.3.2  
**Контейнер:** C20.3 (Rollback Manager)  
**Название:** API для ручного отката  

**Зависимости:** P20.3.1

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Реализовать эндпоинт для ручного запуска отката к предыдущей версии. По ID деплоя или по окружению и целевой версии (коммиту) инициируется процесс отката. Пока сам процесс отката не реализован, эндпоинт создаёт запись о задаче отката в БД и возвращает `rollback_id`.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Новый эндпоинт:**  
  - `POST /api/rollback` – принимает JSON:  
    ```json
    {
      "deploy_id": "dep_123",        // опционально, если указан, игнорируются остальные
      "environment": "staging",      // опционально, требуется указать target_version
      "target_version": "abc123",    // хеш коммита или тег
      "reason": "manual"              // опционально
    }
    ```  
    Должен быть указан либо `deploy_id`, либо пара `environment` + `target_version`.  
  - Ответ: `{ "rollback_id": "rb_456", "status": "pending" }`.  
- **Таблица `rollback_jobs`:**  
  - `id` TEXT PRIMARY KEY (генерируется, например, `rb_<uuid>`)  
  - `deploy_id` TEXT (если откат по ID деплоя)  
  - `environment` TEXT  
  - `target_version` TEXT  
  - `reason` TEXT  
  - `status` TEXT (`pending`, `in_progress`, `completed`, `failed`)  
  - `created_at` TEXT  
  - `completed_at` TEXT  
  - `result` TEXT (JSON с деталями)  
- **Логика:**  
  – Проверить корректность параметров.  
  – Если указан `deploy_id`, найти запись в `deploy_history`. Если не найдена – 404.  
  – Создать запись в `rollback_jobs` со статусом `pending`.  
  – Вернуть ID задачи.  
  – (Реальный откат будет запущен в фоне позже).  
- **Логирование:** все запросы логируются.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Добавить таблицу `rollback_jobs` в БД.  
- В эндпоинте `POST /api/rollback` выполнить валидацию, создать запись, вернуть ID.  
- (Фоновая задача пока не запускается).  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При запросе с `deploy_id` существующего деплоя создаётся задача отката.  
- При запросе с `environment` и `target_version` создаётся задача.  
- При неверных параметрах – 400.  
- Запись появляется в БД.  
- Логирование работает.
