
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P20.4.4 (LEVEL 5)

**ID:** P20.4.4  
**Контейнер:** C20.4 (Test Runner)  
**Название:** Интеграция с C3.3 (Training Simulator)  

**Зависимости:** P20.4.3

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить возможность тестирования промптов на калибровочных кейсах через C3.3 (Training Simulator). Для каждого промпта (если он изменился) запускается прогон тестовых сценариев, результаты добавляются в отчёт.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Новый тип тестов:** `prompt_test` (или расширение `functional` для промптов).  
- **Интеграция с C3.3:**  
  – Адрес задаётся переменной окружения `TRAINING_SIMULATOR_URL` (по умолчанию `http://c3.3:8080`).  
  – Для каждого промпта вызывается `POST /test` с телом, содержащим промпт и, возможно, ID кейса.  
  – Получение результата: аналогично C17.4.  
- **Процесс:**  
  1. Определить файлы-промпты (по пути, например, в `prompts/`).  
  2. Для каждого отправить запрос в C3.3.  
  3. Собрать результаты.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- В фоновой задаче после предыдущих тестов (если запрошено) выполнить интеграцию с C3.3.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- Для каждого промпта выполняется запрос к C3.3.  
- Результаты тестирования сохраняются.  
- При ошибке C3.3 тест помечается как неудачный.
