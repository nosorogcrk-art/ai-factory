### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P20.5.1 (LEVEL 5)

**ID:** P20.5.1  
**Контейнер:** C20.5 (Environment Manager)  
**Название:** Базовая структура и CRUD окружений  

**Зависимости:** отсутствуют

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Создать FastAPI-приложение для управления окружениями (dev, staging, production). Реализовать CRUD-операции для окружений с хранением в SQLite. На данном этапе параметры окружений хранятся в базе, но не используются для реального управления контейнерами. Это основа для последующей интеграции с деплоем и инфраструктурой.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Стек:** Python + FastAPI, SQLite, Uvicorn.  
- **Порт:** 8109 (настраивается через переменную окружения `PORT`).  
- **База данных:** файл `/data/environments.db` (монтируемый том).  
- **Таблица `environments`:**  
  - `name` TEXT PRIMARY KEY (например, `dev`, `staging`, `production`)  
  - `targets` TEXT – JSON-объект, отображающий типы конфигураций на URL целевых сервисов (например, `{"skills": "http://c17.5:8092", "prompts": "http://c7.1:8080"}`)  
  - `params` TEXT – JSON-объект с параметрами окружения (таймауты, ключи доступа, лимиты)  
  - `current_version` TEXT – опционально, текущая версия развёрнутых конфигураций  
  - `created_at` TEXT  
  - `updated_at` TEXT  
- **API эндпоинты:**  
  - `GET /environments` – возвращает список окружений (имена).  
  - `GET /environments/{name}` – возвращает полные данные окружения.  
  - `POST /environments` – создаёт новое окружение. Тело запроса должно содержать поля `name`, `targets`, `params`.  
  - `PUT /environments/{name}` – полностью заменяет данные окружения.  
  - `PATCH /environments/{name}` – частичное обновление (например, только `params`).  
  - `DELETE /environments/{name}` – удаляет окружение.  
- **Валидация:**  
  – Проверка уникальности имени при создании.  
  – Поля `targets` и `params` должны быть валидными JSON-объектами.  
  – Имена окружений должны соответствовать допустимым символам (например, только буквы, цифры, дефис).  
- **Локальное логирование:** файл `01_ЦЕХ/01_ЖУРНАЛЫ/environment_manager.log`.  
- **Эндпоинт /health** – возвращает `{"status": "ok"}`.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Создать файл `environment_manager.py` с FastAPI-приложением.  
- При старте инициализировать SQLite (создать таблицу, если её нет).  
- Определить Pydantic-модели для запросов и ответов.  
- Реализовать CRUD-эндпоинты с использованием SQLite.  
- Настроить логирование.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- Приложение запускается на порту 8109.  
- Можно создать окружение через POST, получить его по GET, обновить, удалить.  
- Валидация неверных данных возвращает 422.  
- Локальный лог содержит записи о запросах.  
- Эндпоинт `/health` отвечает `{"status": "ok"}`.
