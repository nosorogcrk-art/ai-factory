
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P20.1.2 (LEVEL 5)

**ID:** P20.1.2  
**Контейнер:** C20.1 (GitOps Core)  
**Название:** Операции с ветками и коммитами  

**Зависимости:** P20.1.1

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Реализовать API для базовых Git-операций: создание веток, создание коммитов (добавление/изменение файлов), получение истории коммитов и содержимого файлов по ссылке. Эти операции необходимы для работы Auto Deployer (C20.2) и других компонентов.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Новые эндпоинты:**  
  - `POST /repos/{repo}/branches` – создание новой ветки. Тело запроса: `{ "name": "feature/new", "source": "develop" }` (если `source` не указан, от текущей HEAD).  
  - `POST /repos/{repo}/commits` – создание коммита. Тело запроса:  
    ```json
    {
      "branch": "feature/new-skill",
      "files": [
        { "path": "skills/SKILL-042.json", "content": "{...}" }
      ],
      "message": "Add new refactoring skill",
      "author": "gefest"
    }
    ```  
    (Поле `author` опционально, можно брать из служебного токена).  
  - `GET /repos/{repo}/commits` – возвращает список коммитов. Параметры: `branch` (ветка), `limit`, `offset`.  
  - `GET /repos/{repo}/files/{path:path}` – получить содержимое файла. Параметры: `ref` (ветка, тег или хеш коммита).  
- **Валидация:** проверять существование репозитория, ветки и т.д.  
- **Обработка ошибок:** 404, 400, 409 (конфликт при создании ветки).  
- **Логирование:** все операции логируются.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- В файле `gitops_core.py` добавить эндпоинты.  
- Использовать GitPython для работы с репозиторием.  
- При создании коммита:  
  1. Получить репозиторий.  
  2. Переключиться на указанную ветку (если не существует – ошибка).  
  3. Для каждого файла записать содержимое по пути.  
  4. Добавить файлы в индекс (`repo.index.add`).  
  5. Выполнить коммит (`repo.index.commit`).  
- Для получения истории использовать `repo.iter_commits(rev=branch, max_count=limit, skip=offset)`.  
- Для получения файла – `repo.tree(ref)[path].data_stream.read().decode()`.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- Можно создать ветку через API.  
- Можно создать коммит с новым файлом; после этого файл появляется в репозитории.  
- История коммитов возвращается корректно.  
- Получение файла по ссылке работает.  
- Все ошибки обрабатываются.
