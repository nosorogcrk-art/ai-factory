**2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ**

- **Библиотеки:** `openai==1.0.0`, `pydantic==2.10.0`, `python-dotenv==1.0.0`, `watchdog==6.0.0`, `gitpython==3.1.40`.
    

**3. РЕАЛИЗАЦИЯ (L6 — КОД)**

Dockerfile

```
# Файл: Dockerfile
FROM python:3.11-slim

ARG VERSION=1.0.0
LABEL version=${VERSION}
LABEL description="Базовый образ Цифровой Фабрики (7 агентов)"

RUN apt-get update && apt-get install -y \
    git \
    curl \
    procps \
    && rm -rf /var/lib/apt/lists/*

RUN pip install --no-cache-dir \
    openai==1.0.0 \
    pydantic==2.10.0 \
    python-dotenv==1.0.0 \
    watchdog==6.0.0 \
    gitpython==3.1.40

WORKDIR /constructor

# Самодиагностика при старте
CMD ["python", "-c", "import openai, pydantic, dotenv, watchdog, git; \
print('---'); \
print(f'STATUS: OK | openai={openai.__version__}, pydantic={pydantic.__version__}'); \
print('Среда PRODUCTION активна. Все библиотеки импортированы успешно.'); \
print('---')"]
```
