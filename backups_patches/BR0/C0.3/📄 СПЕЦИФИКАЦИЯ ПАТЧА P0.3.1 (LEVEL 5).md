### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P0.3.1 (LEVEL 5)

**ID:** P0.3.1 | **Контейнер:** C0.3 | **Название:** Разметка диска (init_dirs.sh)

**1. ЗАМЫСЕЛ ПАТЧА** Инициализация физического пространства с контролем прав и защитой от удаления пустых папок.

**2. РЕАЛИЗАЦИЯ (L6 — КОД)**

Bash

```
#!/bin/bash
# Файл: init_dirs.sh

DIRS=(
  "00_КАНОН/01_РОЛИ"
  "00_КАНОН/02_ПРАВИЛА"
  "01_ЦЕХ/01_ЖУРНАЛЫ"
  "01_ЦЕХ/01_ЖУРНАЛЫ/АРГУС_ВХОД"
  "01_ЦЕХ/02_ЧЕРНОВИКИ"
  "01_ЦЕХ/КАРАНТИН"
  "02_ПРОДУКТ/01_КОД"
  "02_ПРОДУКТ/02_ДОКИ"
)

for dir in "${DIRS[@]}"; do
  if [ ! -d "$dir" ]; then
    mkdir -p "$dir"
    echo "Created: $dir"
  fi
  # Защита пустых директорий для Git
  touch "$dir/.gitkeep"
done

# Установка прав доступа
chmod -R 755 00_КАНОН
chmod -R 775 01_ЦЕХ 02_ПРОДУКТ

echo "Infrastructure directories initialized successfully."
```
