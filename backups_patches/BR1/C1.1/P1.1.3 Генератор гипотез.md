
### **P1.1.3: Генератор гипотез** (LEVEL 5)

**ID:** P1.1.3  
**Контейнер:** C1.1 (Cognitive Engine)  
**Название:** `hypothesis_generator.py` – генерация предложений по улучшению

---

#### 1. ЗАМЫСЕЛ ПАТЧА
На основе выявленных аномалий и классифицированных задач формирует конкретные предложения по улучшению (гипотезы) и создаёт соответствующие задачи в реестре (патчи на доработку завода). При необходимости привлекает LLM для формулирования детальных планов.

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Зависимости:** P1.1.2 (аномалии), P2.1.3 (семантический поиск), вызов DeepSeek (опционально).
- **Вход:** список аномалий.
- **Выход:** новые задачи, добавленные в реестр (или специальный канал).

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – концептуально

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

import json
import logging
from pathlib import Path
from datetime import datetime

LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/hypothesis_generator.log")
LOG_FILE.parent.mkdir(parents=True, exist_ok=True)
logging.basicConfig(filename=LOG_FILE, level=logging.INFO, format='%(asctime)s - %(message)s')

def generate_hypothesis(anomaly):
    """Превращает аномалию в гипотезу и создаёт задачу."""
    task = {
        "id": f"IMP-{datetime.now().strftime('%Y%m%d%H%M%S')}",
        "title": f"Improve {anomaly['type']}",
        "description": str(anomaly),
        "status": "NEW",
        "assigned_to": None,
        "created_at": datetime.now().isoformat()
    }
    # Здесь можно вызвать LLM для более детального описания
    # Сохраняем в реестр
    with open("01_ЦЕХ/ТЕКУЩИЕ_ЗАДАЧИ/task_registry.json", "r+") as f:
        reg = json.load(f)
        reg.append(task)
        f.seek(0)
        json.dump(reg, f, indent=2)
    logging.info(f"Generated hypothesis task {task['id']}")

# и т.д.
```
