
### **P1.1.2: Анализатор аномалий** (LEVEL 5)

**ID:** P1.1.2  
**Контейнер:** C1.1 (Cognitive Engine)  
**Название:** `anomaly_detector.py` – выявление аномалий в работе системы

---

#### 1. ЗАМЫСЕЛ ПАТЧА
Модуль, который на основе собранных метрик (из P1.1.1) и классифицированных задач (из P1.1.4) выявляет аномалии: зависшие задачи, неэффективные промпты, повторяющиеся ошибки, отклонения от нормы. Результаты передаются в генератор гипотез.

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Зависимости:** P1.1.1 (метрики), P1.1.4 (классификатор – опционально, может использоваться для уточнения).
- **Входные данные:** 
  - Текущие метрики (из `latest_metrics.json` или переданные).
  - Реестр задач (для поиска зависших).
- **Аномалии для выявления:**
  - Зависшие задачи (статус не менялся дольше таймаута, определённого в `timeout_config.json`).
  - Рост частоты ошибок по агенту (сравнение с историческими данными).
  - Увеличение времени выполнения задач.
  - Неэффективные промпты (косвенно – по частым возвратам на доработку).
- **Выходные данные:** список аномалий с типом, описанием, критичностью и ссылками на объекты.

def detect_stalled_tasks(tasks, timeout_config):
    """Возвращает список зависших задач."""
    stalled = []
    now = datetime.now()
    for task in tasks:
        status = task.get("status")
        if status in timeout_config:
            updated = datetime.fromisoformat(task["updated_at"])
            if (now - updated).total_seconds() > timeout_config[status]:
                stalled.append({
                    "type": "stalled_task",
                    "task_id": task["id"],
                    "status": status,
                    "since": updated.isoformat()
                })
    return stalled
