### **P1.3.1: Сборщик метрик качества** (LEVEL 5)

**ID:** P1.3.1  
**Контейнер:** C1.3 (Self-Audit)  
**Название:** `quality_metrics.py` – сбор метрик качества выполнения патчей

---

#### 1. ЗАМЫСЕЛ ПАТЧА
Создание скрипта, который анализирует историю выполненных задач и ревью, вычисляет метрики качества работы агентов. Метрики включают процент успешных задач с первого раза, среднее количество замечаний на ревью, частоту возвратов на доработку. Эти данные используются для последующего анализа эффективности промптов.

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Источники данных:**
  - Реестр задач `task_registry.json` (содержит историю переходов, в т.ч. поля `history`).
  - Журналы ревью (например, `01_ЦЕХ/01_ЖУРНАЛЫ/РЕВЬЮ.log` или записи в `ЭСТАФЕТА.md` с действиями `complete`/`rework`).
- **Собираемые метрики:**
  - `success_first_try` – доля задач, переведённых в DONE без промежуточного статуса REWORK.
  - `avg_review_comments` – среднее количество замечаний на ревью (если извлекается).
  - `rework_frequency` – количество возвратов на доработку по каждому агенту.
  - `avg_duration_review` – среднее время нахождения в статусе ON_REVIEW.
- **Выходной файл:** `01_ЦЕХ/МЕТРИКИ/quality_metrics.json` с временной меткой и агрегированными показателями.
- **Периодичность:** может запускаться после каждого завершённого патча или по расписанию.
- **Логирование:** записывает отладочную информацию в `01_ЦЕХ/01_ЖУРНАЛЫ/quality_metrics.log`.

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
quality_metrics.py – сбор метрик качества выполнения патчей.
"""

import json
import logging
from pathlib import Path
from datetime import datetime, timedelta
from collections import defaultdict

TASK_REGISTRY_PATH = Path("01_ЦЕХ/ТЕКУЩИЕ_ЗАДАЧИ/task_registry.json")
REVIEW_LOG_PATH = Path("01_ЦЕХ/01_ЖУРНАЛЫ/РЕВЬЮ.log")  # если есть отдельный журнал
OUTPUT_DIR = Path("01_ЦЕХ/МЕТРИКИ")
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/quality_metrics.log")

OUTPUT_DIR.mkdir(parents=True, exist_ok=True)
LOG_FILE.parent.mkdir(parents=True, exist_ok=True)

logging.basicConfig(
    filename=LOG_FILE,
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

def load_task_registry():
    if not TASK_REGISTRY_PATH.exists():
        return []
    with open(TASK_REGISTRY_PATH, "r", encoding="utf-8") as f:
        return json.load(f)

def compute_metrics(tasks):
    """
    Вычисляет метрики качества на основе истории задач.
    """
    total_tasks = len([t for t in tasks if t.get("status") == "DONE"])
    first_try_success = 0
    rework_counts = defaultdict(int)
    review_durations = []

    for task in tasks:
        if task.get("status") != "DONE":
            continue
        history = task.get("history", [])
        # Считаем, сколько раз задача переходила в REWORK
        reworks = sum(1 for entry in history if entry.get("to") == "REWORK")
        if reworks == 0:
            first_try_success += 1
        else:
            # Записываем количество реворков по агенту (последний исполнитель)
            agent = task.get("assigned_to")
            if agent:
                rework_counts[agent] += reworks

        # Длительность ревью: время между ON_REVIEW и следующим статусом (DONE или REWORK)
        review_start = None
        for entry in history:
            if entry.get("to") == "ON_REVIEW":
                review_start = datetime.fromisoformat(entry["timestamp"])
            elif review_start and entry.get("from") == "ON_REVIEW":
                review_end = datetime.fromisoformat(entry["timestamp"])
                review_durations.append((review_end - review_start).total_seconds())
                review_start = None

    metrics = {
        "timestamp": datetime.now().isoformat(),
        "total_done_tasks": total_tasks,
        "success_first_try": first_try_success / total_tasks if total_tasks else 0,
        "avg_review_duration_sec": sum(review_durations)/len(review_durations) if review_durations else 0,
        "rework_frequency": dict(rework_counts)
    }
    return metrics

def main():
    tasks = load_task_registry()
    metrics = compute_metrics(tasks)

    output_file = OUTPUT_DIR / f"quality_{datetime.now().strftime('%Y%m%d_%H%M%S')}.json"
    with open(output_file, "w", encoding="utf-8") as f:
        json.dump(metrics, f, indent=2, ensure_ascii=False)

    latest_file = OUTPUT_DIR / "latest_quality_metrics.json"
    with open(latest_file, "w", encoding="utf-8") as f:
        json.dump(metrics, f, indent=2, ensure_ascii=False)

    logging.info(f"Quality metrics saved to {output_file}")

if __name__ == "__main__":
    main()
```

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)
- Скрипт `quality_metrics.py` создан и размещён в `agents/tools/`.
- При запуске вычисляет метрики на основе реестра задач.
- Выходной JSON содержит все указанные поля.
- При отсутствии реестра скрипт не падает (обрабатывает ошибки).
- Логирование работает.
