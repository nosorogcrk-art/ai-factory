
### **P1.3.2: Анализатор промптов** (LEVEL 5)

**ID:** P1.3.2  
**Контейнер:** C1.3 (Self-Audit)  
**Название:** `prompt_analyzer.py` – анализ системных промптов агентов

---

#### 1. ЗАМЫСЕЛ ПАТЧА
Модуль, который сравнивает текущие системные промпты агентов с эталонными требованиями (из Золотого стандарта, канонов, лучших практик) и выявляет слабые места. На основе метрик качества (из P1.3.1) и анализа текста промптов формулирует рекомендации по их улучшению.

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Зависимости:** P1.3.1 (метрики), P7.1.2 (доступ к промптам), возможно, LLM для анализа.
- **Входные данные:** (опционально) список ролей для анализа; по умолчанию все.
- **Выходные данные:** JSON-отчёт с рекомендациями по каждой роли.
- **Алгоритм:**
  1. Загружает текущие промпты из `00_КАНОН/ПРОМПТЫ/` (через `prompt_builder` или напрямую).
  2. Загружает эталонные шаблоны/правила из BR3 (например, `ЗОЛОТОЙ_СТАНДАРТ.md`, шаблоны L5).
  3. Для каждой роли:
     - Анализирует наличие обязательных разделов, соответствие структуре.
     - Сравнивает с метриками качества: если у агента высокая частота ошибок или реворков, ищет в промпте возможные причины (отсутствие чётких инструкций, противоречия).
     - Опционально вызывает LLM для оценки качества промпта и генерации рекомендаций.
  4. Сохраняет отчёт в `01_ЦЕХ/МЕТРИКИ/prompt_analysis.json`.
- **Логирование:** в `01_ЦЕХ/01_ЖУРНАЛЫ/prompt_analyzer.log`.

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
prompt_analyzer.py – анализ системных промптов агентов.
"""

import json
import logging
import re
from pathlib import Path
from datetime import datetime

PROMPT_DIR = Path("00_КАНОН/ПРОМПТЫ")
METRICS_FILE = Path("01_ЦЕХ/МЕТРИКИ/latest_quality_metrics.json")
OUTPUT_FILE = Path("01_ЦЕХ/МЕТРИКИ/prompt_analysis.json")
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/prompt_analyzer.log")

LOG_FILE.parent.mkdir(parents=True, exist_ok=True)
logging.basicConfig(filename=LOG_FILE, level=logging.INFO,
                    format='%(asctime)s - %(levelname)s - %(message)s')

# Список обязательных разделов в промпте (из Золотого стандарта)
REQUIRED_SECTIONS = [
    "ПАСПОРТ РОЛИ",
    "СИСТЕМНЫЙ ПРОМПТ",
    "ТЕХНИЧЕСКИЕ ЛИМИТЫ",
    "ИСТОРИЯ ИЗМЕНЕНИЙ"
]

def load_prompt(role):
    file_path = PROMPT_DIR / f"{role}.md"
    if not file_path.exists():
        return None
    with open(file_path, "r", encoding="utf-8") as f:
        return f.read()

def load_metrics():
    if not METRICS_FILE.exists():
        return {}
    with open(METRICS_FILE, "r", encoding="utf-8") as f:
        return json.load(f)

def analyze_prompt(role, prompt, metrics):
    issues = []
    suggestions = []

    # Проверка наличия обязательных разделов
    for section in REQUIRED_SECTIONS:
        if section not in prompt:
            issues.append(f"Отсутствует раздел '{section}'")
            suggestions.append(f"Добавить раздел '{section}' с описанием.")

    # Проверка длины промпта (слишком короткий – плохо)
    if len(prompt) < 500:
        issues.append("Промпт слишком короткий (<500 символов)")
        suggestions.append("Расширить промпт, добавить детальные инструкции.")

    # Связь с метриками: если у агента высокий реворк, отметить
    rework_freq = metrics.get("rework_frequency", {}).get(role, 0)
    if rework_freq > 5:
        issues.append(f"Высокая частота реворков ({rework_freq})")
        suggestions.append("Проанализировать инструкции: возможно, они неоднозначны.")

    # Если есть success_first_try < 0.5, тоже отметить
    success_rate = metrics.get("success_first_try", 1)
    if success_rate < 0.5:
        issues.append("Низкая доля успешных с первого раза")
        suggestions.append("Проверить, достаточно ли чётко описаны критерии успеха.")

    return {
        "role": role,
        "issues": issues,
        "suggestions": suggestions,
        "has_issues": len(issues) > 0
    }

def main():
    metrics = load_metrics()
    results = []
    for role_file in PROMPT_DIR.glob("*.md"):
        if role_file.name == "prompt_hashes.json":
            continue
        role = role_file.stem
        prompt = load_prompt(role)
        if prompt:
            analysis = analyze_prompt(role, prompt, metrics)
            results.append(analysis)
            logging.info(f"Analyzed {role}: {len(analysis['issues'])} issues")

    output = {
        "timestamp": datetime.now().isoformat(),
        "analyses": results
    }
    with open(OUTPUT_FILE, "w", encoding="utf-8") as f:
        json.dump(output, f, indent=2, ensure_ascii=False)

if __name__ == "__main__":
    main()
```

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)
- Скрипт `prompt_analyzer.py` создан и размещён в `agents/tools/`.
- При запуске анализирует все промпты, выявляет отсутствие разделов и связывает с метриками.
- Результат сохраняется в JSON-файл.
- Логирование работает.
- Скрипт не падает при отсутствии метрик (использует значения по умолчанию).
