### **P1.2.3: Создатель спецификаций** (LEVEL 5)

**ID:** P1.2.3  
**Контейнер:** C1.2 (Patch Architect)  
**Название:** `spec_generator.py` – генерация спецификаций L5 для патчей

---

### 1. ЗАМЫСЕЛ ПАТЧА
Для каждого нового патча, созданного декомпозитором (P1.2.1), скрипт генерирует файл спецификации уровня L5 на основе соответствующего шаблона из методологии (BR3, C3.1). Спецификация заполняется данными из описания патча и сохраняется в директорию `01_ЦЕХ/ЧЕРНОВИКИ/СПЕКИ/`.

---

### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Зависимости:** P1.2.1 (патчи), P3.1.1 (шаблоны спецификаций).
- **Входные данные:** (опционально) список ID патчей, для которых нужно создать спецификации. Если не указан, обрабатываются все патчи с типом `improvement`, у которых ещё нет спецификации.
- **Выходные данные:** файлы спецификаций в папке `01_ЦЕХ/ЧЕРНОВИКИ/СПЕКИ/` с именами `<ID патча>.md`.
- **Алгоритм:**
  1. Загружает реестр задач.
  2. Определяет, для каких патчей нужно создать спецификацию.
  3. Для каждого такого патча загружает шаблон L5 (например, `ШАБЛОН_L5.md` z `00_КАНОН/Методология/ШАБЛОНЫ/`).
  4. Заменяет в шаблоне плейсхолдеры (например, `{{PATCH_ID}}`, `{{TITLE}}`, `{{DESCRIPTION}}`) на данные из задачи.
  5. Сохраняет результат в файл.
- **Логирование:** в `01_ЦЕХ/01_ЖУРНАЛЫ/spec_generator.log`.

---

### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
spec_generator.py – генерация спецификаций L5 для патчей.
"""

import json
import sys
import logging
from pathlib import Path

TASK_REGISTRY_PATH = Path("01_ЦЕХ/ТЕКУЩИЕ_ЗАДАЧИ/task_registry.json")
TEMPLATE_PATH = Path("00_КАНОН/Методология/ШАБЛОНЫ/ШАБЛОН_L5.md")
SPEC_DIR = Path("01_ЦЕХ/ЧЕРНОВИКИ/СПЕКИ/")
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/spec_generator.log")

SPEC_DIR.mkdir(parents=True, exist_ok=True)
LOG_FILE.parent.mkdir(parents=True, exist_ok=True)

logging.basicConfig(filename=LOG_FILE, level=logging.INFO,
                    format='%(asctime)s - %(levelname)s - %(message)s')

def load_json(path, default):
    """Загружает JSON из файла, возвращает default при ошибке."""
    if path.exists():
        with open(path, "r", encoding="utf-8") as f:
            return json.load(f)
    return default

def load_template():
    if not TEMPLATE_PATH.exists():
        # Заглушка, если шаблона нет – создаём минимальный
        return """# СПЕЦИФИКАЦИЯ ПАТЧА {{PATCH_ID}}

## 1. ЗАМЫСЕЛ
{{DESCRIPTION}}

## 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
*Будут уточнены в процессе реализации.*

## 3. РЕАЛИЗАЦИЯ
*Код и описание изменений.*

## 4. КРИТЕРИЙ ПРИЕМКИ (DoD)
*Условия завершения патча.*

## 5. ИСТОРИЯ ИЗМЕНЕНИЙ
- {{DATE}}: Создана спецификация.
"""
    with open(TEMPLATE_PATH, "r", encoding="utf-8") as f:
        return f.read()

def generate_spec(task, template):
    from datetime import datetime
    content = template.replace("{{PATCH_ID}}", task["id"])
    content = content.replace("{{TITLE}}", task.get("title", ""))
    content = content.replace("{{DESCRIPTION}}", task.get("description", ""))
    content = content.replace("{{DATE}}", datetime.now().strftime("%Y-%m-%d"))
    return content

def main():
    registry = load_json(TASK_REGISTRY_PATH, [])
    template = load_template()

    # Определяем, какие патчи обрабатывать
    target_ids = sys.argv[1:] if len(sys.argv) > 1 else None

    for task in registry:
        if task.get("type") != "improvement":
            continue
        if target_ids and task["id"] not in target_ids:
            continue
        spec_file = SPEC_DIR / f"{task['id']}.md"
        if spec_file.exists():
            logging.info(f"Spec for {task['id']} already exists, skipping.")
            continue
        spec_content = generate_spec(task, template)
        with open(spec_file, "w", encoding="utf-8") as f:
            f.write(spec_content)
        logging.info(f"Generated spec for {task['id']}")

if __name__ == "__main__":
    main()
```

---

### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)
- Скрипт `spec_generator.py` создан и размещён в `agents/tools/`.
- При запуске без аргументов создаёт спецификации для всех новых патчей улучшения.
- При указании конкретных ID создаёт спецификации только для них.
- Спецификации сохраняются в правильной папке.
- Если шаблон отсутствует, используется встроенный минимальный шаблон.
- Логирование ведётся.
- Скрипт не завершается с ошибкой при отсутствии реестра (используется пустой список).
