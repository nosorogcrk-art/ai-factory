
### **P2.1.3: Семантический поиск** (LEVEL 5)

**ID:** P2.1.3 | **Контейнер:** C2.1 | **Название:** `semantic_search.py` – API семантического поиска

**1. ЗАМЫСЕЛ ПАТЧА**  
Создание модуля, предоставляющего функцию поиска по текстовому запросу, а также опционально HTTP-сервер для вызова из других компонентов. Модуль использует векторное хранилище для поиска ближайших соседей и возвращает обогащённые результаты.

**2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ**  
- **Зависимости:** P2.1.1 (хранилище), общий модуль эмбеддингов.  
- **Функция поиска:**  
  - Принимает: `query` (строка), `k` (число, по умолчанию 10), `filter` (словарь с условиями по метаданным, например `{"source": "internal"}`).  
  - Возвращает список объектов с полями: `id`, `path`, `title`, `source`, `timestamp`, `score`, `snippet`.  
- **Генерация сниппета:** извлекается фрагмент текста из исходного файла, содержащий ключевые слова запроса. Для упрощения можно брать первые 200 символов.  
- **Кэширование:** LRU-кэш на 100 запросов (результаты хранятся 5 минут).  
- **HTTP-сервер (опционально):** эндпоинт `/search`, принимающий JSON и возвращающий JSON.  
- **Логирование:** запросы и ошибки в `semantic_search.log`.

**3. РЕАЛИЗАЦИЯ (L6 — КОД)**  

Файл: `agents/tools/semantic_search.py`

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
semantic_search.py – семантический поиск по векторному хранилищу.
"""

import json
import logging
from pathlib import Path
import chromadb
from embedding_model import get_encoder
from flask import Flask, request, jsonify
from functools import lru_cache
import time

# Конфигурация
VECTOR_STORE_DIR = Path("00_ПАМЯТЬ/ВЕКТОРЫ")
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/semantic_search.log")
COLLECTION_NAME = "documents"
CACHE_SIZE = 100
CACHE_TTL = 300  # секунд

# Настройка логирования
LOG_FILE.parent.mkdir(parents=True, exist_ok=True)
logging.basicConfig(
    filename=LOG_FILE,
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

# Инициализация клиента и модели
client = chromadb.PersistentClient(path=str(VECTOR_STORE_DIR))
collection = client.get_collection(COLLECTION_NAME)
encoder = get_encoder()

# Простой кэш с временем жизни
cache = {}

def get_snippet(file_path, query, max_len=200):
    """Возвращает фрагмент текста, содержащий ключевые слова запроса."""
    try:
        with open(file_path, 'r', encoding='utf-8') as f:
            content = f.read()
        # Поиск вхождения ключевых слов (простейший вариант)
        words = set(query.lower().split())
        lines = content.splitlines()
        for line in lines:
            if any(word in line.lower() for word in words):
                return line.strip()[:max_len]
        return content[:max_len] + "..."
    except:
        return ""

def search(query, k=10, filter_dict=None):
    """Основная функция поиска."""
    # Проверка кэша
    cache_key = (query, k, str(filter_dict))
    cached = cache.get(cache_key)
    if cached and time.time() - cached['timestamp'] < CACHE_TTL:
        return cached['result']

    # Векторизация запроса
    embedding = encoder.encode(query).tolist()

    # Поиск в Chroma
    results = collection.query(
        query_embeddings=[embedding],
        n_results=k,
        where=filter_dict  # фильтр по метаданным
    )

    output = []
    for i in range(len(results['ids'][0])):
        doc_id = results['ids'][0][i]
        metadata = results['metadatas'][0][i]
        score = 1 - results['distances'][0][i]  # преобразуем расстояние в сходство (чем меньше расстояние, тем больше сходство)
        snippet = get_snippet(doc_id, query) if Path(doc_id).exists() else ""
        output.append({
            "id": doc_id,
            "path": metadata.get("path", ""),
            "title": metadata.get("title", ""),
            "source": metadata.get("source", "unknown"),
            "timestamp": metadata.get("timestamp", ""),
            "score": score,
            "snippet": snippet
        })

    # Сортировка по убыванию сходства
    output.sort(key=lambda x: x['score'], reverse=True)

    result = output
    cache[cache_key] = {'result': result, 'timestamp': time.time()}
    return result

# Flask-приложение для HTTP API
app = Flask(__name__)

@app.route('/search', methods=['POST'])
def search_api():
    data = request.get_json()
    query = data.get('query')
    k = data.get('k', 10)
    filter_dict = data.get('filter', {})
    if not query:
        return jsonify({"error": "Missing query"}), 400
    try:
        results = search(query, k, filter_dict)
        return jsonify(results)
    except Exception as e:
        logging.error(f"Search error: {e}")
        return jsonify({"error": str(e)}), 500

if __name__ == "__main__":
    # Если запущен как основной, стартуем HTTP-сервер
    app.run(host='0.0.0.0', port=5005)
```

- Поиск возвращает корректные результаты (проверяется тестовыми запросами).  
- Кэширование работает (повторный запрос быстрее).  
- Сниппеты генерируются.
