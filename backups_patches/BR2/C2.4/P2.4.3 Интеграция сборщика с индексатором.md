
### **P2.4.3: Интеграция сборщика с индексатором** (LEVEL 5)

**ID:** P2.4.3  
**Контейнер:** C2.4  
**Название:** `external_to_indexer.py` – передача внешних документов в индексатор C2.2

---

### 1. ЗАМЫСЕЛ ПАТЧА
Модуль, который принимает список файлов, собранных из внешних источников (например, из `latest_batch.json`), и передаёт их в индексатор C2.2 для добавления в векторное хранилище. Фактически это обёртка, которая для каждого файла вызывает функцию индексации, аналогичную той, что используется во внутреннем индексаторе.

---

### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Зависимости:** C2.2 (индексатор), библиотека `chromadb`, общий модуль эмбеддингов.
- **Алгоритм:**
  1. Загрузить список файлов из заданного источника (по умолчанию `00_ПАМЯТЬ/Внешние/latest_batch.json`).
  2. Для каждого файла:
     - Извлечь текст (аналогично `extract_text` в индексаторе).
     - Сгенерировать эмбеддинг.
     - Добавить в коллекцию Chroma с метаданными: `source="external"`, `path`, `timestamp` (из времени файла), `title` (первая строка).
  3. Логировать результаты.
- **Примечание:** Поскольку код индексации уже есть в `indexer.py`, можно переиспользовать его функции, вынеся их в общий модуль. Для простоты здесь напишем аналогичную функцию.

---

### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
external_to_indexer.py – передача внешних файлов в индексатор C2.2.
"""

import json
import logging
import re
from pathlib import Path
import chromadb
from embedding_model import get_encoder

VECTOR_STORE_DIR = Path("00_ПАМЯТЬ/ВЕКТОРЫ")
COLLECTION_NAME = "documents"
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/external_to_indexer.log")

LOG_FILE.parent.mkdir(parents=True, exist_ok=True)
logging.basicConfig(filename=LOG_FILE, level=logging.INFO,
                    format='%(asctime)s - %(levelname)s - %(message)s')

client = chromadb.PersistentClient(path=str(VECTOR_STORE_DIR))
collection = client.get_or_create_collection(COLLECTION_NAME)
encoder = get_encoder()

def extract_text(file_path: Path) -> str | None:
    """Упрощённое извлечение текста (аналогично индексатору)."""
    ext = file_path.suffix.lower()
    try:
        with open(file_path, "r", encoding="utf-8", errors="ignore") as f:
            content = f.read()
    except Exception as e:
        logging.error(f"Error reading {file_path}: {e}")
        return None

    if ext == ".md":
        content = re.sub(r'\[\[(.*?)\]\]', r'\1', content)
        content = re.sub(r'^#+\s*', '', content, flags=re.MULTILINE)
        content = re.sub(r'^[\*\-\+]\s+', '', content, flags=re.MULTILINE)
    return content

def get_title(content: str) -> str:
    for line in content.splitlines():
        line = line.strip()
        if line:
            return line[:100]
    return ""

def index_file(file_path: Path):
    if not file_path.exists():
        logging.warning(f"File {file_path} does not exist, skipping.")
        return
    text = extract_text(file_path)
    if text is None or not text.strip():
        return
    embedding = encoder.encode(text).tolist()
    metadata = {
        "source": "external",
        "path": str(file_path),
        "timestamp": str(file_path.stat().st_mtime),
        "title": get_title(text)
    }
    doc_id = str(file_path)
    # Удаляем старую запись, если есть
    try:
        collection.delete(ids=[doc_id])
    except:
        pass
    collection.add(ids=[doc_id], embeddings=[embedding], metadatas=[metadata])
    logging.info(f"Indexed external file {doc_id}")

def process_batch(batch_file: Path):
    if not batch_file.exists():
        logging.error(f"Batch file {batch_file} not found.")
        return
    with open(batch_file, "r") as f:
        file_list = json.load(f)
    for file_path_str in file_list:
        index_file(Path(file_path_str))
    logging.info(f"Processed {len(file_list)} external files.")

if __name__ == "__main__":
    import sys
    if len(sys.argv) > 1:
        batch_file = Path(sys.argv[1])
    else:
        batch_file = Path("00_ПАМЯТЬ/Внешние/latest_batch.json")
    process_batch(batch_file)
```

### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)

- Логируются ошибки и успехи.

### **P2.4.4: Фильтр качества** (LEVEL 5)

**ID:** P2.4.4  
**Контейнер:** C2.4  
**Название:** `source_filter.py` – фильтрация репозиториев по качеству

---

### 1. ЗАМЫСЕЛ ПАТЧА
Скрипт, который анализирует метаданные репозиториев (полученные через GitHub API) и отсеивает те, что не соответствуют критериям качества (количество звёзд, форков, дата последнего обновления, лицензия). Может использоваться как отдельный инструмент для очистки конфигурации.

---

### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Вход:** конфигурационный файл `sources.json`.
- **Выход:** отфильтрованный список репозиториев (можно обновить тот же файл или вывести отчёт).
- **Критерии (настраиваются):**
  - Минимальное количество звёзд (по умолчанию 1000).
  - Минимальное количество форков (по умолчанию 100).
  - Максимальный возраст последнего коммита (по умолчанию 1 год).
  - Разрешённые лицензии (список).
- **Логирование:** в `01_ЦЕХ/01_ЖУРНАЛЫ/source_filter.log`.

---

### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
source_filter.py – фильтрация репозиториев по качеству.
"""

import json
import logging
from pathlib import Path
from datetime import datetime, timedelta
from github import Github
import os

CONFIG_FILE = Path("00_КАНОН/Внешние_источники/sources.json")
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/source_filter.log")

logging.basicConfig(filename=LOG_FILE, level=logging.INFO,
                    format='%(asctime)s - %(levelname)s - %(message)s')

GITHUB_TOKEN = os.environ.get("GITHUB_TOKEN")
g = Github(GITHUB_TOKEN) if GITHUB_TOKEN else Github()

def filter_repos(config, min_stars=1000, min_forks=100, max_age_days=365, allowed_licenses=None):
    if allowed_licenses is None:
        allowed_licenses = ["MIT", "Apache-2.0", "BSD-3-Clause"]

    filtered = []
    for repo_info in config["repositories"]:
        url = repo_info["url"]
        owner, name = url.rstrip('/').split('/')[-2:]
        try:
            repo = g.get_repo(f"{owner}/{name}")
        except Exception as e:
            logging.error(f"Failed to fetch {url}: {e}")
            continue

        stars = repo.stargazers_count
        forks = repo.forks_count
        last_commit = repo.updated_at  # можно использовать pushed_at
        age = datetime.now() - last_commit

        license_name = repo.license.name if repo.license else None
        license_ok = license_name in allowed_licenses if allowed_licenses else True

        if stars >= min_stars and forks >= min_forks and age.days <= max_age_days and license_ok:
            filtered.append(repo_info)
            logging.info(f"Repo {url} passed filters.")
        else:
            logging.info(f"Repo {url} filtered out (stars={stars}, forks={forks}, age={age.days}, license={license_name})")
    return filtered

def main():
    with open(CONFIG_FILE, "r") as f:
        config = json.load(f)
    filtered = filter_repos(config)
    # Можно записать обратно или просто вывести
    print(f"Filtered repositories ({len(filtered)}):")
    for r in filtered:
        print(f"  {r['url']}")
    # По желанию: обновить конфиг
    # config["repositories"] = filtered
    # with open(CONFIG_FILE, "w") as f:
    #     json.dump(config, f, indent=2)

if __name__ == "__main__":
    main()
```
