
### **P2.1.3: Семантический поиск** (LEVEL 5)

**ID:** P2.1.3  
**Контейнер:** C2.3 (Semantic Search)  
**Название:** `semantic_search.py` – API семантического поиска

---

### 1. ЗАМЫСЕЛ ПАТЧА
Создание модуля, который предоставляет функцию поиска документов по текстовому запросу, используя векторное хранилище C2.1, и опционально HTTP-сервер для внешних вызовов. Модуль возвращает обогащённые результаты с метаданными и сниппетами.

---

### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ
- **Зависимости:**
  - Патч **P2.1.1** (инициализированное векторное хранилище Chroma).
  - Патч **P2.0.1** (общий модуль эмбеддингов `embedding_model.py`).
- **Функция поиска:**
  - Вход: `query` (строка), `k` (число, по умолчанию 10), `filters` (словарь, опционально) – фильтры по метаданным, например `{"source": "internal"}`.
  - Выход: список словарей с полями:
    - `id` – идентификатор документа (путь).
    - `path` – путь к файлу.
    - `title` – первая строка документа.
    - `source` – источник (`internal` или `external`).
    - `date` – время последнего изменения.
    - `score` – оценка релевантности (0..1).
    - `snippet` – фрагмент текста с ключевыми словами.
- **Кэширование:** LRU-кэш на 100 запросов с временем жизни 5 минут (используется `cachetools.TTLCache`).
- **HTTP-сервер:** опционально запускается на порту 5005 (настраивается) и предоставляет эндпоинт `/search`, принимающий POST-запросы с JSON-телом.
- **Логирование:** все запросы и ошибки записываются в `01_ЦЕХ/01_ЖУРНАЛЫ/semantic_search.log`.
- **Сниппеты:** для формирования сниппета читаются первые 4096 байт файла, ищется строка, содержащая ключевые слова запроса; если не найдено – возвращаются первые 200 символов.

### 3. РЕАЛИЗАЦИЯ (L6 — КОД)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
semantic_search.py – семантический поиск по векторному хранилищу.
Использует Chroma DB и модель all-MiniLM-L6-v2.
"""

import logging
import time
from pathlib import Path
from cachetools import TTLCache
import chromadb
from flask import Flask, request, jsonify
from embedding_model import get_encoder

# Конфигурация
VECTOR_STORE_DIR = Path("00_ПАМЯТЬ/ВЕКТОРЫ")
LOG_FILE = Path("01_ЦЕХ/01_ЖУРНАЛЫ/semantic_search.log")
COLLECTION_NAME = "documents"
CACHE_SIZE = 100
CACHE_TTL = 300  # секунд
HTTP_PORT = 5005

LOG_FILE.parent.mkdir(parents=True, exist_ok=True)
logging.basicConfig(
    filename=LOG_FILE,
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

# Инициализация клиента Chroma и модели
client = chromadb.PersistentClient(path=str(VECTOR_STORE_DIR))
collection = client.get_collection(COLLECTION_NAME)
encoder = get_encoder()

# Кэш
cache = TTLCache(maxsize=CACHE_SIZE, ttl=CACHE_TTL)

def get_snippet(file_path: Path, query: str, max_len: int = 200) -> str:
    """Возвращает фрагмент текста, содержащий ключевые слова запроса."""
    try:
        with open(file_path, 'r', encoding='utf-8') as f:
            content = f.read(4096)  # читаем только начало
        words = set(query.lower().split())
        lines = content.splitlines()
        for line in lines:
            if any(word in line.lower() for word in words):
                return line.strip()[:max_len]
        return content[:max_len] + "..."
    except Exception as e:
        logging.warning(f"Failed to generate snippet for {file_path}: {e}")
        return ""

def search(query: str, k: int = 10, filters: dict = None):
    """Основная функция поиска."""
    cache_key = (query, k, str(filters))
    if cache_key in cache:
        logging.info(f"Cache hit for query: {query[:50]}...")
        return cache[cache_key]

    # Векторизация запроса
    embedding = encoder.encode(query).tolist()

    try:
        results = collection.query(
            query_embeddings=[embedding],
            n_results=k,
            where=filters
        )
    except Exception as e:
        logging.error(f"Chroma query failed: {e}")
        return []

    output = []
    for i in range(len(results['ids'][0])):
        doc_id = results['ids'][0][i]
        metadata = results['metadatas'][0][i]
        distance = results['distances'][0][i]
        # Преобразование расстояния в оценку (чем меньше расстояние, тем выше сходство)
        score = 1 / (1 + distance)
        snippet = get_snippet(Path(doc_id), query) if Path(doc_id).exists() else ""
        output.append({
            "id": doc_id,
            "path": metadata.get("path", ""),
            "title": metadata.get("title", ""),
            "source": metadata.get("source", "unknown"),
            "date": metadata.get("timestamp", ""),
            "score": score,
            "snippet": snippet
        })

    # Сортировка по убыванию сходства
    output.sort(key=lambda x: x['score'], reverse=True)
    cache[cache_key] = output
    logging.info(f"Search for '{query[:50]}...' returned {len(output)} results")
    return output

# Flask-приложение для HTTP API
app = Flask(__name__)

@app.route('/search', methods=['POST'])
def search_api():
    data = request.get_json()
    if not data or 'query' not in data:
        return jsonify({"error": "Missing query"}), 400
    query = data['query']
    k = data.get('k', 10)
    filters = data.get('filters')
    try:
        results = search(query, k, filters)
        return jsonify(results)
    except Exception as e:
        logging.error(f"Search error: {e}")
        return jsonify({"error": str(e)}), 500

if __name__ == "__main__":
    # Если скрипт запущен напрямую, стартуем HTTP-сервер
    app.run(host='0.0.0.0', port=HTTP_PORT)
```

### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)
- Скрипт `semantic_search.py` может быть импортирован как модуль (функция `search`) и запущен как HTTP-сервер.
- При POST-запросе на `/search` с корректным JSON возвращается массив результатов.
- Результаты содержат все обязательные поля, оценка `score` в диапазоне (0,1].
- Кэширование работает (повторный запрос возвращается быстрее).
- Сниппеты генерируются из начала файла.
- Все запросы логируются в указанный файл.
- При ошибках (например, отсутствие коллекции) возвращается HTTP 500 с описанием.
