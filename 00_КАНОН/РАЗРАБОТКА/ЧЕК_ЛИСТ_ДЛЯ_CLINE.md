## ЧАСТЬ 2. ТРЕБОВАНИЯ К ОТЧЁТУ CLINE (обязательные артефакты)

Cline обязан предоставить **реальные выводы команд** (скопированные из терминала). Описания «тесты прошли» или «файлы созданы» не принимаются.

### 0. Проверка портов (шаг 0)
```bash
grep -E '"[0-9]+:[0-9]+"' docker-compose.yml | sed 's/.*"\([0-9]*\):[0-9]*".*/\1/' | sort -n | uniq -d
```
**Ожидаемый вывод:** пустая строка.

### 1. Файловая система (созданные/изменённые файлы)
```bash
ls -la <путь_к_папке_контейнера>/
ls -la <путь_к_навыку>/
```

### 2. Содержимое новых файлов (первые 20 строк)
```bash
head -20 <путь_к_файлу1>
head -20 <путь_к_файлу2>
```

### 3. Ключевые фрагменты кода (новые функции/эндпоинты)
```bash
grep -A 20 "def новая_функция" <путь_к_файлу>
grep -A 15 "@app.post" <путь_к_main.py>
```

### 4. Результаты тестов (полный вывод)
```bash
cd /Users/a1/Dev/ЗАВОД_АГЕНТОВ/ai-factory
python3 -m pytest <путь_к_тестам> -v
```
**Ожидаемый вывод:** все тесты PASSED (warnings допустимы, FAILED/ERROR – нет).

### 5. Версия паспорта контейнера
```bash
grep "version:" <путь_к_паспорту>
```
**Ожидаемый вывод:** `version: <новая_версия>`.

### 6. Индексация (если indexer доступен)
```bash
curl -s -X POST "http://localhost:8108/index" -H "Content-Type: application/json" -d '{"documents": [...]}'
```
**Ожидаемый вывод:** `{"status":"ok","indexed_count":N,"errors":[]}`.  
Если indexer недоступен – запись в `TECH_DEBT.md` (п.8).

### 7. Карта системы (если system-mapper доступен)
```bash
curl -s -X GET "http://localhost:8101/map?refresh=true" | jq '.containers[] | select(.id=="<ID>") | {version}'
```
**Ожидаемый вывод:** `{"version": "<новая_версия>"}`.  
Если недоступен – запись в `TECH_DEBT.md` (п.8).

### 8. Технический долг (если что-то не выполнено)
```bash
cat 01_ЦЕХ/ПРОТОКОЛЫ/TECH_DEBT.md
```
**Ожидаемый вывод:** запись о том, что не выполнено и почему.
