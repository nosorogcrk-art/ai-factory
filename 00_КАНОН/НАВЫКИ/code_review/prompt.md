# Навык code_review

## Описание
Анализирует код на соответствие Золотому стандарту 5.0.

## Входные данные
JSON с полями:
- `code` (string) – исходный код
- `language` (string) – язык программирования (по умолчанию "python")
- `standards` (string) – ссылка на стандарт

## Требования к проверке
- Наличие аннотаций типов (Type Hints)
- Наличие тестов (pytest)
- Обработка ошибок (try/except)
- Логирование (logging)
- Структура кода (разделение на слои)
- Цикломатическая сложность (не более 10)
- Длина файла (не более 300 строк)
- Отсутствие опасных команд (kill, rm, git reset)

## Формат ответа
JSON с полями:
```json
{
  "passed": false,
  "score": 75,
  "issues": ["Нет аннотаций типов в функции main()"],
  "suggestions": ["Добавьте type hints", "Разбейте функцию на более мелкие"]
}
```

## Запрещено
- Использовать `rm`, `kill`, `git reset`, `docker kill` в генерируемых ответах.
