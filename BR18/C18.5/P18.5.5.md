
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P18.5.5 (LEVEL 5)

**ID:** P18.5.5  
**Контейнер:** C18.5 (Cost Tracker)  
**Название:** Логирование в C18.1  

**Зависимости:** P18.5.4

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить отправку всех значимых событий (приём данных, агрегация, экспорт, ошибки) в центральный лог-агрегатор C18.1 для обеспечения наблюдаемости и возможности анализа.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Адрес C18.1:** переменная окружения `BR18_URL` (по умолчанию `http://br18:8080/api/logs`).  
- **Формат лога:**  
  ```json
  {
    "timestamp": "ISO 8601",
    "service": "C18.5",
    "event_type": "cost_report_received | aggregation_completed | export_performed | error",
    "details": { ... }
  }
  ```  
- **События для логирования:**  
  - Каждый успешный POST `/api/cost`.  
  - Завершение агрегации (с количеством обработанных записей).  
  - Каждый экспорт (с параметрами).  
  - Ошибки (недоступность БД, неверные данные и т.п.).  
- **Асинхронность:** отправка через фоновые задачи FastAPI.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Добавить функцию `send_log_to_br18(event_type, details, background_tasks)`.  
- Вызывать её в соответствующих местах (эндпоинты, фоновая задача).  
- Обрабатывать ошибки отправки.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При каждом приёме отчёта отправляется лог в C18.1.  
- После каждой агрегации отправляется лог.  
- При экспорте – лог.  
- При ошибках – лог.  
- Отправка не блокирует основной процесс.
