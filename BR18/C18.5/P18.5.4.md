
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P18.5.4 (LEVEL 5)

**ID:** P18.5.4  
**Контейнер:** C18.5 (Cost Tracker)  
**Название:** Интеграция с BR5  

**Зависимости:** P18.5.3

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Предоставить возможность экспорта данных о затратах в коммерческий модуль BR5 для выставления счетов и биллинга. Экспорт может выполняться по расписанию или по запросу в формате CSV или JSON.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Эндпоинт для экспорта:**  
  - `GET /api/cost/export` – принимает параметры `from`, `to`, `format` (csv или json). Возвращает данные за указанный период.  
  - `POST /api/cost/export` – запускает фоновую задачу экспорта с уведомлением по завершении (опционально).  
- **Интеграция с BR5:**  
  – Адрес BR5 задаётся переменной окружения `BR5_BILLING_URL`.  
  – При экспорте можно отправлять данные напрямую в BR5 через POST-запрос. Либо просто сохранять файл в общую папку, откуда BR5 его заберёт.  
- **Формат данных:**  
  - CSV: поля: `timestamp, agent, task_id, branch, model, prompt_tokens, completion_tokens, cost_usd, success`.  
  - JSON: массив объектов с теми же полями.  
- **Безопасность:** экспорт может требовать аутентификации (через заголовок X-API-Key).  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Добавить эндпоинты экспорта.  
- При получении запроса выполнять выборку из БД за указанный период и преобразовывать в запрошенный формат.  
- Если указан URL BR5, отправлять данные туда; иначе просто возвращать файл.  
- Логировать все экспортные операции.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- Экспорт в CSV и JSON работает.  
- Фильтрация по дате корректна.  
- При наличии URL BR5 данные отправляются (можно проверить заглушкой).  
- Логирование экспорта работает.
