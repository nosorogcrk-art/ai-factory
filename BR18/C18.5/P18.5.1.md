**ID:** P18.5.1

**Название:** Базовая структура и приём данных о затратах  

**Зависимости:** отсутствуют

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Создать FastAPI-приложение для учёта затрат на использование LLM. Реализовать эндпоинт для приёма отчётов о каждом вызове от агентов (или от Token Guard) и сохранять их в SQLite-базу данных. Это основа для дальнейшего анализа и агрегации.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Стек:** Python + FastAPI, SQLite, Uvicorn.  
- **Порт:** 8097 (настраивается через переменную окружения `PORT`).  
- **База данных:** файл `/data/costs.db` (монтируемый том).  
- **Таблица `cost_logs`:**  
  - `id` INTEGER PRIMARY KEY AUTOINCREMENT  
  - `timestamp` TEXT (ISO 8601)  
  - `agent` TEXT  
  - `task_id` TEXT  
  - `branch` TEXT  
  - `model` TEXT  
  - `prompt_tokens` INTEGER  
  - `completion_tokens` INTEGER  
  - `cost_usd` REAL  
  - `success` BOOLEAN  
  - `duration_ms` INTEGER (опционально)  
- **Эндпоинт:**  
  - `POST /api/cost` – принимает JSON-объект с полями: `agent`, `task_id`, `branch`, `model`, `prompt_tokens`, `completion_tokens`, `cost_usd`, `success`, `duration_ms` (опционально).  
  - Валидация через Pydantic: обязательные поля – все, кроме `duration_ms`.  
  - При успехе запись сохраняется в БД, возвращается `200 OK`.  
  - При ошибке валидации – 422.  
- **Локальное логирование:** все запросы и ошибки записываются в файл `01_ЦЕХ/01_ЖУРНАЛЫ/cost_tracker.log`.  
- **Эндпоинт /health** – возвращает `{"status": "ok"}`.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Создать файл `cost_tracker.py` с FastAPI-приложением.  
- При старте инициализировать БД (создать таблицу, если её нет).  
- Определить Pydantic-модель `CostReport`.  
- В эндпоинте `POST /api/cost` выполнить вставку в БД.  
- Добавить `/health`.

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)

- При отправке корректного отчёта данные сохраняются в БД.

- Эндпоинт `/health` отвечает `{"status": "ok"}`.
