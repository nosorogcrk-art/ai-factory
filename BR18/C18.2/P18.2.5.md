
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P18.2.5 (LEVEL 5)

**ID:** P18.2.5  
**Контейнер:** C18.2 (Metrics Dashboard)  
**Название:** Веб-интерфейс  

**Зависимости:** P18.2.4

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Создать простую HTML-страницу с графиками, которая будет опрашивать API метрик и отображать текущие значения и историю в реальном времени. Это обеспечит визуальный мониторинг для оператора.

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Эндпоинт:** `GET /` (или `/dashboard`) – отдаёт HTML-страницу.  
- **Технологии:**  
  - HTML, CSS (Bootstrap для минимальной стилизации).  
  - JavaScript для асинхронных запросов к API.  
  - Chart.js (подключается через CDN) для графиков.  
- **Функциональность:**  
  – При загрузке страницы запрашиваются текущие агрегаты (`/api/metrics`) и отображаются в виде карточек.  
  – Для выбранной метрики (например, по умолчанию `tasks_completed`) строится график истории за последние 24 часа (запрос к `/api/metrics/history/{name}`).  
  – Возможность переключения метрики через выпадающий список.  
  – Автообновление каждые 10 секунд (polling) для текущих значений.  
- **Дизайн:** минималистичный, но функциональный.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Создать HTML-шаблон и встроить его в FastAPI (можно через `return HTMLResponse`).  
- Написать JavaScript-код для опроса API и обновления DOM.  
- Для графиков использовать Chart.js, создавать/обновлять график при смене метрики.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При переходе на корневой URL отображается страница с карточками метрик.  
- Карточки показывают текущие значения (mean, max и т.д.).  
- График истории отображается для выбранной метрики.  
- Автообновление работает (данные меняются при поступлении новых метрик).  
- Нет ошибок в консоли браузера.
