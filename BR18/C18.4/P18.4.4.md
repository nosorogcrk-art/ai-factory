
### 📄 СПЕЦИФИКАЦИЯ ПАТЧА P18.4.4 (LEVEL 5)

**ID:** P18.4.4  
**Контейнер:** C18.4 (Traceability Index)  
**Название:** Интеграция с BR2 (семантический поиск)  

**Зависимости:** P18.4.3

---

#### 1. ЗАМЫСЕЛ ПАТЧА  
Добавить возможность семантического поиска по содержимому логов с использованием BR2 (C2.3 Semantic Search). При поступлении запроса на естественном языке он передаётся в C2.3 для получения списка релевантных документов (смыслов), а затем по этим документам (или их ID) выполняется поиск логов, связанных с ними. Это позволит отвечать на вопросы типа «покажи логи, где возникла ошибка при использовании навыка X».

---

#### 2. ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ  

- **Новый эндпоинт:** `GET /api/search?q=текст`  
  - `q` – строка запроса.  
  - Возвращает массив логов, релевантных запросу.  
- **Алгоритм:**  
  1. Отправить запрос `q` в C2.3 (семантический поиск) с фильтром на тип документа (например, только `skill` или `patch` – по желанию). Адрес C2.3 задаётся переменной окружения `SEMANTIC_SEARCH_URL` (по умолчанию `http://c2.3:5005`).  
  2. Получить список документов с их ID и оценками релевантности.  
  3. Для каждого документа (если его ID соответствует формату сущности, например, `SKILL-042`, `P1.2.3`) выполнить поиск логов через API `GET /api/trace/{entity_type}/{entity_id}` (можно внутренним вызовом).  
  4. Объединить все найденные логи, убрать дубликаты, отсортировать по времени и вернуть.  
- **Обработка ошибок:** если C2.3 недоступен, возвращать пустой результат с предупреждением.  

---

#### 3. РЕАЛИЗАЦИЯ (L6 — КОД) – ОПИСАНИЕ  

- Добавить эндпоинт `/api/search`.  
- Использовать `httpx` для асинхронного вызова C2.3.  
- Преобразовать полученные ID в вызовы внутреннего API (можно через функцию, вызывающую SQL напрямую, чтобы не делать лишние HTTP-запросы).  
- Собрать результаты.  

---

#### 4. КРИТЕРИЙ ПРИЕМКИ (DoD)  

- При запросе `GET /api/search?q=ошибка+рефакторинга` возвращаются логи, связанные с найденными C2.3 сущностями.  
- Если C2.3 недоступен, возвращается пустой массив с кодом 200 и предупреждением в логе.  
- Результаты не содержат дубликатов.
