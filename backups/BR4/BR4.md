### 📄 ПАСПОРТ ВЕТКИ BR4: ИНТЕРФЕЙС (VISUAL) – УЛУЧШЕННАЯ ВЕРСИЯ

**ID:** BR4  
**Ответственные:** АРХИ / ГЕФЕСТ  

**Замысел:** Визуализация структуры проекта (скелета), мониторинг прогресса и предоставление Владельцу инструментов прямого управления. Интерфейс должен отображать данные из системных реестров (BR0), графов смыслов (BR2) и метрик (BR18) в реальном времени.  

**Границы:**  
- **Отвечает за:**  
  – Разработку и поддержку веб-панели (Dashboard) с ключевыми метриками (статус патчей, затраты токенов, прогресс веток, состояние системного реестра BR0) на основе данных из BR18.  
  – Интерактивную визуализацию графа связей между документами, патчами, смыслами и навыками (Graph Visualizer), использующую данные семантической сети BR2 и хранилища навыков BR17.  
  – Создание консоли управления (Command Console) для отправки команд агентам, авторизации действий и ручного вмешательства; интеграция с системой эстафеты (BR7) и мониторингом (BR18) для логирования команд и отслеживания их результатов.  
  – **Создание диалоговой консоли (Dialogue Console) для ведения свободного диалога с системой в контексте выбранного проекта, с возможностью переключения между проектами и просмотра истории.**  
- **Не занимается:** Логикой работы продуктов (BR10), хранением данных (BR2) или безопасностью кода (BR6).  

**Валидация:**  
- Данные на Dashboard полностью синхронизированы с актуальными значениями из BR18 и BR0 (разница не более 1 секунды).  
- Graph Visualizer корректно отображает связи между смыслами (BR2) и зависимости между навыками (BR17), подтверждённые семантическим поиском.  
- Команды из Command Console успешно выполняются, что подтверждается появлением соответствующих записей в логах BR18 и изменением состояния системы (например, запущенный патч фиксируется в реестре задач BR7).  
- **Dialogue Console позволяет создавать проекты, вести диалог, переключаться между проектами и отображать историю диалогов.**  

**СОСТАВ УЗЛОВ (L3):**  
- **C4.1: Project Dashboard.** Панель ключевых метрик: статус патчей, затраты токенов, прогресс веток, состояние реестра BR0. Получает данные из BR18 (Metrics Dashboard, Cost Tracker) и напрямую из системных файлов (при необходимости).  
- **C4.2: Graph Visualizer.** Визуальное отображение связей смыслов и архитектуры (Miro-style), а также зависимостей между навыками. Использует данные семантической сети из BR2 (C2.3 Semantic Search) и граф зависимостей навыков из BR17 (C17.3 Skill Graph).  
- **C4.3: Command Console.** Графический интерфейс для ручного запуска патчей, авторизации действий агентов и мониторинга статусов. При выполнении команды отправляет запрос в соответствующую ветку (например, BR7 для управления задачами), логирует событие в BR18 и ожидает подтверждения изменения состояния (например, появления задачи в реестре).  
- **C4.4: Dialogue Console.** Веб-интерфейс для ведения диалога с системой в контексте выбранного проекта. Позволяет создавать проекты, переключаться между ними, просматривать историю диалогов и отправлять сообщения в C9.4 (Dialogue Manager).
