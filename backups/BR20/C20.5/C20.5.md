### 📄 ПАСПОРТ КОНТЕЙНЕРА C20.5: ENVIRONMENT MANAGER (МЕНЕДЖЕР ОКРУЖЕНИЙ)

**Ветка-родитель:** BR20 | **ID:** C20.5 | **Ответственный:** ГЕФЕСТ

---

#### 1. ФУНКЦИОНАЛЬНОЕ ПРЕДНАЗНАЧЕНИЕ
Управление несколькими окружениями (dev, staging, production) и их конфигурациями. Хранит параметры окружений (endpoint'ы, ключи доступа, лимиты, переменные окружения) и предоставляет их другим компонентам (C20.2, C20.3) для применения конфигураций. Позволяет продвигать изменения поэтапно: сначала на dev, после успешного тестирования — на staging, затем — на production. Интегрируется с BR0 для управления целевыми контейнерами.

---

#### 2. ТЕХНИЧЕСКАЯ ЛОГИКА (МЕХАНИКА)

- **Хранение данных об окружениях:**  
  – SQLite или JSON-файл с описанием окружений.  
  – Для каждого окружения хранятся:  
    * `name` (dev, staging, prod).  
    * `targets` – список компонентов, куда нужно деплоить (например, для навыков – API C17.5, для промптов – C7.1).  
    * `params` – специфичные параметры (URL, токены, таймауты).  
    * `current_version` – текущая версия развёрнутых конфигураций (опционально).  

- **API:**  
  – `GET /environments` – список окружений.  
  – `GET /environments/{name}` – параметры конкретного окружения.  
  – `POST /environments` – создать новое окружение.  
  – `PUT /environments/{name}` – обновить параметры.  
  – `DELETE /environments/{name}` – удалить окружение.  
  – `POST /environments/{name}/deploy` – инициировать деплой в это окружение (вызов C20.2).  

- **Интеграция с BR0:**  
  – При деплое может потребоваться обновление переменных окружения в контейнерах. Для этого Environment Manager может вызывать Docker API (через BR0) для рестарта или обновления конфигурации.  

- **Логирование:**  
  – Все изменения окружений и запросы к ним логируются в C18.1.

---

#### 3. ВХОДЫ И ВЫХОДЫ (INTERFACES)

- **REST API (внутри Docker-сети, порт 8109):**  
  – Пример получения параметров:  
    `GET /environments/staging`  
    ```json
    {
      "name": "staging",
      "targets": {
        "skills": "http://c17.5:8092",
        "prompts": "http://c7.1:8080"
      },
      "params": {
        "timeout": 30,
        "retries": 3
      }
    }
    ```

- **Исходящие вызовы:** к C20.2 для запуска деплоя, к BR0 (Docker API) для управления контейнерами.

---

#### 4. ИНТЕГРАЦИИ

- **C20.2 (Auto Deployer):** предоставляет параметры окружения.  
- **C20.3 (Rollback Manager):** также может запрашивать параметры.  
- **BR0 (Infrastructure):** для управления контейнерами (перезапуск, обновление переменных).  
- **BR18 (Monitoring):** логирование.  

---

#### 5. СТЕК ТЕХНОЛОГИЙ

- Python + FastAPI.  
- SQLite или JSON-файлы.  
- HTTP-клиент.  
- Docker SDK для Python (опционально).
