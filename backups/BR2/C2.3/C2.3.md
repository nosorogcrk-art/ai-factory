### **C2.3: Semantic Search (Семантический поиск)**

**Ветка-родитель:** BR2 | **ID:** C2.3 | **Ответственный:** МНЕМОСИНА

**1. ФУНКЦИОНАЛЬНОЕ ПРЕДНАЗНАЧЕНИЕ**  
Предоставление API для семантического поиска по всем индексированным документам (внутренние и внешние источники, а также описания навыков). Принимает текстовый запрос, преобразует его в вектор, выполняет поиск в векторном хранилище (C2.1) с учётом фильтров и возвращает список наиболее релевантных документов с расширенными метаданными. Все запросы логируются в BR18 для последующего анализа и оптимизации.

**2. ТЕХНИЧЕСКАЯ ЛОГИКА (МЕХАНИКА)**  
- **Векторизация запроса:** Использование единого модуля эмбеддингов (той же модели, что и при индексации).  
- **Поиск:** Вызов `search` C2.1 с параметрами:
  - вектор запроса;
  - количество результатов `k`;
  - опциональные фильтры (передаются как дополнительный аргумент, если векторное хранилище их поддерживает, либо применяются пост-фильтрацией).
- **Применение фильтров** (поддерживаются все перечисленные в п.3):
  - `source_type` (internal / external / all);
  - `source` (конкретный источник, например `github:anthropics/anthropic-cookbook`);
  - `date_from`, `date_to` (по полю `timestamp`);
  - `related_to` (по полю `related_entities`).
- **Обогащение результатов:** Для каждого найденного документа извлекаются метаданные, хранящиеся в векторной БД: `id`, `source`, `source_type`, `timestamp`, `title`, `related_entities`.  
- **Сниппет:** Из текста документа формируется сниппет – фрагмент, содержащий ключевые слова запроса (например, до 200 символов с подсветкой или просто первые N символов).  
- **Кэширование:** Реализуется LRU-кэш для часто повторяющихся запросов (размер кэша конфигурируется). Ключ кэша включает запрос и применённые фильтры.  
- **Логирование:** Каждый запрос асинхронно отправляется в Log Aggregator (C18.1) в формате JSON (см. п.5). Локальное логирование в файл может сохраняться для отладки.

**3. ВХОДЫ И ВЫХОДЫ (INTERFACES)**  
- **Input:** HTTP-запрос (JSON) с полями:
  ```json
  {
    "query": "текст запроса",
    "k": 10,
    "filters": {
      "source_type": "internal",          // "internal", "external" или null (все)
      "source": "github:anthropic/...",   // опционально
      "date_from": "2025-01-01",          // опционально, Unix timestamp или ISO
      "date_to": "2025-12-31",             // опционально
      "related_to": "SKILL-001"            // опционально
    }
  }
  ```
- **Output:** JSON-объект:
  ```json
  {
    "results": [
      {
        "id": "путь_к_файлу_или_ID",
        "source": "internal | github:owner/repo | arxiv:XXXX | ...",
        "source_type": "internal | external",
        "timestamp": 1234567890,
        "title": "Заголовок документа",
        "related_entities": ["SKILL-001", "P1.2.3", "[[ID_Замысел]]"],
        "score": 0.95,
        "snippet": "текстовый фрагмент с ключевыми словами"
      }
    ]
  }
  ```

**4. ИНТЕГРАЦИИ**  
- **C2.1 (Vector Store):** выполнение поиска и получение метаданных.  
- **C18.1 (Log Aggregator):** отправка логов в формате, описанном в п.5.  
- **BR3 (Citations Agent):** используется для автоматической простановки ссылок.  
- **BR17 (Skill Graph):** через поле `related_entities` предоставляет связи с навыками.  
- **BR19 (Self-Learning):** логи используются для анализа и оптимизации промптов.

**5. ФОРМАТ ЛОГА ДЛЯ BR18**  
Каждый запрос порождает событие, отправляемое в Log Aggregator:
```json
{
  "timestamp": "2026-03-18T10:00:00Z",
  "service": "C2.3",
  "query": "текст запроса",
  "user": "идентификатор_агента_или_пользователя",
  "result_count": 10,
  "response_time_ms": 150,
  "filters_applied": {
    "source_type": "internal",
    "date_from": "2026-01-01"
  },
  "status": "success"   // или "error"
}
```

**6. СТЕК ТЕХНОЛОГИЙ**  
- Python (Flask/FastAPI для HTTP-эндпоинта).  
- Единый модуль эмбеддингов (может использоваться `sentence-transformers` или аналоги).  
- Клиент для работы с векторной БД (Chroma/FAISS).  
- Библиотеки: `numpy`, `cachetools` (для кэша), `requests` (для отправки логов).  

**7. СПИСОК ПАТЧЕЙ И ИХ ФУНКЦИИ**
