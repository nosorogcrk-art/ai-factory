### 📄 ПАСПОРТ ВЕТКИ BR13: ЭКОСИСТЕМА И ШЛЮЗЫ (GATEWAYS)

**ID:** BR13

**Ответственные:** ГЕРМЕС / ГЕФЕСТ

**Замысел:** Унификация внешних интеграций через библиотеку готовых коннекторов, превращающая Завод во «всеядную» систему.

**Границы:** * **Отвечает за:** API-ключи, безопасность внешних соединений, форматирование входящих/исходящих данных и Webhook-маршрутизацию.

- **Не занимается:** Внутренними вызовами между агентами (BR1) или семантикой хранимых данных (BR2).
    
    **Валидация:** Любая внешняя интеграция проходит через «Песочницу» (Sandbox); зафиксировано отсутствие утечек сырых данных во внешнюю среду.
    
    **СОСТАВ УЗЛОВ (L3):** * **C13.1: Library of Connectors.** Набор модулей для связи с внешними API (TG, WhatsApp, платежные шлюзы и пр.).
    
- **C13.2: API Manager.** Централизованный пульт управления ключами доступа и лимитами соединений.
    
- **C13.3: Webhook Hub.** Узел приема и распределения сигналов из внешнего мира по внутренним веткам.
