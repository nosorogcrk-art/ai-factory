## 1. Замысел

Переработка сырых, абстрактных идей пользователя в детерминированные технологические задания и атомарные патчи. Включает интерактивный диалог для уточнения деталей, извлечение смыслов и генерацию структурированного описания задачи. **После завершения диалога автоматически запускает декомпозицию задачи на патчи и инициирует сборку.**

---

## 2. Границы

### 2.1. Отвечает за:
- Ведение диалога с пользователем для уточнения требований.
- Извлечение сути, целей и ограничений из диалога.
- Автоматизированную нарезку выявленных смыслов на атомарные патчи.
- Сверку итогового графика патчей с исходной идеей.
- **Автоматический вызов декомпозитора (C1.2) после создания задачи (через HTTP).**
- **Автоматический вызов интегратора (C10.1) после успешного создания патчей.**
- Интеграцию с Project Memory (C2.6) для сохранения диалогов и семантического поиска.

### 2.2. Не занимается:
- Написанием финального кода (BR10).
- Дизайном интерфейсов (BR4).
- Инфраструктурой (BR0).

---
